Utilise la tienne**Jeton d’accès système**Requêtes programmatiques**Son propre récit**des journaux d’utilisation qui peuvent être intégrés à vos systèmes de facturation, d’audit ou de surveillance.

- URL de base :`https://api.nexusapi.link`
- Cette interface est**Lecture seule**, ne retourne que les données du compte correspondant au jeton.

## Jian Quan

1. Dans la console NexusAPI,**Paramètres personnels → générer des jetons**« Acquis. »**Jeton d’accès système**(Note : Ce n’est pas pour appeler le modèle.) `sk-` API Key est un jeton au niveau du compte ; Si c’est une fuite, veuillez le régénérer comme obsolète).
2. Insérez l’en-tête de la requête lors de l’appel :

```http
Authorization: Bearer <你的系统访问令牌>
```

- Jeton**Seul l’en-tête de requête est placé**, ne l’épelez pas dans l’URL.
- Ce jeton est un attribut de compte ; l’ajout, la suppression ou la rotation des clés API ne l’affecte pas, ce qui le rend adapté à une intégration à long terme.

## Interroger le journal d’utilisation

```http
GET /v1/logs?page=1&page_size=50[&start_time=..&end_time=..]
```

### Paramètres de requête (tous optionnels)

| Paramètres | Type | Explication |
| --- | --- | --- |
| `page` | entier | Les numéros de page commencent à 1, par défaut est 1 |
| `page_size` | entier | Nombre d’entrées par page : par défaut 10, maximum 50 |
| `start_time` | string/int | Heure de démarrage, secondes Unix (par exemple, `1717200000`) ou RFC3339 (par exemple, `2026-06-01T00:00:00Z`） |
| `end_time` | string/int | Fin des temps, format comme ci-dessus |

Contraintes :`page × page_size ≤ 100000`(Limite de profondeur de tournure de page) ; Il n’y a pas de limite à la période de fenêtre.

### Retour d’exemple (200)

```json
{
  "data": [
    {
      "time": "2026-06-20T14:03:11Z", "token_name": "我的密钥", "group": "default",
      "model": "gpt-5.5", "use_time": 3, "first_byte": 0.8,
      "prompt_tokens": 1200, "completion_tokens": 800, "cost": 0.012,
      "ip": "1.2.3.4", "request_id": "2026xyzreq",
      "request_path": "/v1/chat/completions"
    }
  ],
  "page": 1, "page_size": 10
}
```

| Terrain | Explication |
| --- | --- |
| `time` | Temps de demande (UTC, RFC3339) |
| `token_name` | Le nom de la clé API utilisée cette fois-ci |
| `group` | Regroupement de jetons |
| `model` | Nom du modèle |
| `use_time` | Temps total passé (secondes) |
| `first_byte` | Temps du premier caractère (secondes) ; Ceci est utilisé lorsqu’il n’y a pas de caractère initial dans les formes non fluides `null` |
| `prompt_tokens` / `completion_tokens` | Nombre de jetons entrée/sortie |
| `cost` | Montant dépensé cette période (USD) |
| `ip` | Source : IP |
| `request_id` | Demande d’ID |
| `request_path` | Chemin d’appel |

**Une page retourne moins de « page_size » (ou vide), c’est-à-dire la dernière page.**

## Exemples d’appels

```bash
curl -H "Authorization: Bearer <你的系统访问令牌>" \
  "https://api.nexusapi.link/v1/logs?page=1&page_size=50&start_time=1717200000&end_time=1717804800"
```

Feuilletage de page en volume complet (pseudocode) :

```text
page = 1
while True:
    resp = GET /v1/logs?page=page&page_size=50
    处理 resp.data
    if len(resp.data) < 50: break   # 某页不满即最后一页
    page += 1
```

## Code d’erreur

| HTTP | Erreur | Signification |
| --- | --- | --- |
| 400 | `invalid_request` | Les paramètres sont invalides (page devient trop profonde / format temporel incorrect / ordre temporel incorrect) |
| 401 | `unauthorized` | Jeton manquant / invalide / compte désactivé |
| 429 | `rate_limited` | Les demandes sont trop fréquentes (bandes de réponse). `Retry-After`, veuillez suivre les consignes pour prendre du recul) |
| 503 | `unavailable` | Le service est temporairement indisponible (avec une bande d’argent). `Retry-After`） |
| 500 | `internal_error` | Erreurs internes |

## Recommandations d’utilisation

- Le moment est **UTC**；`cost` En dollars américains.
- Utilisation de la pagination (`page_size` Maximum 50) + tirage segmenté par fenêtre temporelle,**Ne pas faire de sondages fréquents**； Pour les scénarios d’audit, il est recommandé de taper « hier » une fois par jour.
- Seul le HTTPS est pris en charge.
