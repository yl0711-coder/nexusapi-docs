Recherchez le nom exact du modèle, puis choisissez le protocole indiqué. Conservez les majuscules, les dates et les suffixes.

Le tableau présente les modèles actuellement proposés et leurs protocoles recommandés. L’accès dépend du groupe de votre clé API.

## Choisir un protocole

| Modèles utilisés | Premier choix | Chemin de requête |
| --- | --- | --- |
| Claude | Anthropic Messages | `/v1/messages` |
| GPT dans un groupe compatible Responses | Responses | `/v1/responses` |
| Groupes GPT confirmés uniquement pour Chat Completions ; DeepSeek, GLM, Kimi, Qwen, Grok | Chat Completions | `/v1/chat/completions` |

<Warning>
Vérifiez que le modèle est disponible dans le groupe de votre clé API. Si votre client ne prend en charge qu’un protocole, choisissez un modèle et un groupe compatibles.
</Warning>

Pour le groupe `gpt-5.6x`, commencez par Chat Completions. Si vous avez besoin de Responses, demandez d’abord confirmation au support.

## Configuration du client et vérifications

1. Pour Claude Code, suivez le [guide](/fr/tools/claude-code) avec la base URL `https://nexusapi.link`.
2. Pour Codex CLI, suivez le [guide](/fr/tools/codex-cli) avec Responses. Le modèle et son groupe doivent le prendre en charge.
3. Pour Chat Completions, suivez les [exemples](/fr/developer/code-examples). Base URL du SDK OpenAI : `https://nexusapi.link/v1`.

Si le modèle ou le protocole manque, consultez la [matrice des capacités](/fr/developer/capability-matrix), puis envoyez au support le nom du modèle, le groupe, le client et le Request ID. Ne partagez jamais la clé complète.
