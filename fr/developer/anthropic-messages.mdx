title: "API Anthropic Messages"
description: "Appelez les modèles dont `supported_endpoint_types` contient anthropic avec le protocole natif Anthropic Messages."
---

Utilisez cette API lorsque `supported_endpoint_types` dans `/v1/models` pour votre clé actuelle contient `anthropic`. Consultez d'abord la [matrice des capacités](/fr/developer/capability-matrix) : **modèle, groupe de clé et protocole doivent correspondre**.

<Warning>
**Quand utiliser Messages**

Utilisez cet endpoint uniquement lorsque `supported_endpoint_types` contient `anthropic`. Une application compatible OpenAI doit utiliser [Chat Completions](/fr/developer/openai-compatible) ; si un modèle ne liste pas `anthropic`, choisissez l'un de ses endpoints compatibles. `not implemented` indique généralement une incompatibilité de protocole, pas une erreur temporaire.
</Warning>

## Endpoint et requête minimale

```text
POST https://nexusapi.link/v1/messages
```

```bash
curl 'https://nexusapi.link/v1/messages' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_API_KEY' \
  -H 'anthropic-version: 2023-06-01' \
  -d '{
    "model": "YOUR_ANTHROPIC_MODEL_ID",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Bonjour"}]
  }'
```

| Élément | Requis | Note |
| --- | --- | --- |
| `model` | Oui | ID exact visible par la clé, dont `supported_endpoint_types` contient `anthropic` |
| `max_tokens` | Oui | Nombre maximal de tokens en sortie |
| `messages` | Oui | Conversation au format Anthropic Messages |
| `anthropic-version` | Requis par le protocole natif | Géré par le SDK ; indiquez une version compatible pour un appel manuel |

Consultez la documentation de votre client Anthropic pour tous les champs, outils, flux et schémas de réponse. Les champs facultatifs dépendent toujours du modèle et de ses capacités actuelles.

## Utiliser le SDK Anthropic

Le SDK natif gère ses en-têtes de protocole. Passez-lui une clé NexusAPI et définissez l'URL de base **sans `/v1`** :

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link",
)

message = client.messages.create(
    model="YOUR_ANTHROPIC_MODEL_ID",
    max_tokens=256,
    messages=[{"role": "user", "content": "Bonjour"}],
)
```

Le SDK ajoute `/v1/messages`. N'utilisez pas `https://nexusapi.link/v1/messages` comme `base_url`, cela peut répéter le chemin ou produire une 404.

## Claude Code ou application maison

| Situation | Configuration |
| --- | --- |
| Claude Code | Suivez le [guide Claude Code](/fr/tools/claude-code) : `ANTHROPIC_BASE_URL=https://nexusapi.link` et `ANTHROPIC_AUTH_TOKEN` dans `~/.claude/settings.json` |
| SDK Anthropic / client natif | URL de base `https://nexusapi.link`, puis laissez le client envoyer Messages |
| Application avec SDK OpenAI | Utilisez [Chat Completions](/fr/developer/openai-compatible) |

## Dépannage

- `401` : vérifiez la clé, son état et l'absence de réinitialisation après exposition.
- `404` : vérifiez qu'un SDK n'a pas ajouté un second `/v1`.
- `400` : testez seulement `model`, `max_tokens` et `messages`, puis ajoutez les champs facultatifs un par un.
- `500, not implemented` : vérifiez que `supported_endpoint_types` contient `anthropic` et que la requête utilise l'endpoint correspondant.

En cas d'échec persistant, conservez le Request ID et une requête expurgée, puis suivez l'[auto-vérification](/fr/faq/self-check).
