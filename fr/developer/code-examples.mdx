Les exemples utilisent OpenAI Chat Completions. Vérifiez d'abord le modèle et le protocole dans la [matrice des capacités](/fr/developer/capability-matrix), puis copiez l'ID exact disponible à votre clé.

## Paramètres de base

- Base URL : `https://nexusapi.link/v1`
- Clé : créée dans la [console NexusAPI](https://nexusapi.link)
- Modèle : ID exact du catalogue ou de `/v1/models`

## Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link/v1",
)

response = client.chat.completions.create(
    model="YOUR_MODEL_ID",
    messages=[{"role": "user", "content": "Présente-toi brièvement."}],
)

print(response.choices[0].message.content)
```

## JavaScript

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.NEXUSAPI_API_KEY,
  baseURL: "https://nexusapi.link/v1",
});

const response = await client.chat.completions.create({
  model: "YOUR_MODEL_ID",
  messages: [{ role: "user", content: "Présente-toi brièvement." }],
});

console.log(response.choices[0].message.content);
```

## cURL

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"Tester la connexion"}]}'
```

Ne mettez jamais une vraie clé dans le code source. Ces exemples Chat Completions ne s'appliquent que si `supported_endpoint_types` contient `openai` ; s'il ne contient pas `openai-response`, ne considérez pas `/v1/responses` comme un substitut général. La génération d'images utilise un autre endpoint : consultez le [guide des images](/fr/guide/image-generation). Vérifiez la disponibilité des options dans le Catalogue de modèles.
