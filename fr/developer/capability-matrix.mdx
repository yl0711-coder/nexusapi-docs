Le modèle, le groupe de jetons et le protocole utilisés avec NexusAPI doivent correspondre. Le catalogue de modèles et la réponse de votre clé actuelle sont les sources de vérité.

<Info>
**À vérifier avant l'appel**

1. Vérifiez que le modèle est disponible dans le groupe de votre clé.
2. Vérifiez que `supported_endpoint_types` renvoyé par `/v1/models` contient le protocole nécessaire.
3. Consultez `/v1/models` avec la clé concernée, puis envoyez une requête minimale.
</Info>

## Capacités documentées publiquement

| Objectif | API / protocole | Utilisation | Limite importante |
| --- | --- | --- | --- |
| Lister les modèles visibles par la clé | [GET /v1/models](/fr/developer/api-basics) | Après la création d'une clé et avant le choix du modèle | Reflète les groupes et restrictions de cette clé uniquement. |
| Texte, chat et streaming | [POST /v1/chat/completions](/fr/developer/openai-compatible) | SDK OpenAI compatibles, scripts et la plupart des modèles texte | Utilisez uniquement un modèle dont `supported_endpoint_types` contient `openai`. |
| Claude Code ou client Anthropic natif | [POST /v1/messages](/fr/developer/anthropic-messages) | `supported_endpoint_types` contient `anthropic` | N'ajoutez pas une seconde fois `/v1` à l'URL de base de Claude Code. |
| Codex CLI | [POST /v1/responses](/fr/developer/responses) | Avec le fournisseur configuré dans le [guide Codex](/fr/tools/codex-cli) | Utilisez uniquement un modèle dont `supported_endpoint_types` contient `openai-response`. |
| Génération d'images | [POST /v1/images/generations](/fr/guide/image-generation) | `supported_endpoint_types` contient `image-generation` | N'envoyez que les options supportées par ce modèle. |

<Warning>
**Utilisez le périmètre des capacités publiquement documentées**

Utilisez les capacités indiquées ici, dans le catalogue de modèles ou dans une documentation officielle. L'édition ou les variations d'images, embeddings, audio, rerank et Gemini natif ne sont pas actuellement des capacités publiques générales : contactez le support avant de les utiliser en production.
</Warning>

## Vérifier les modèles avec la clé actuelle

```bash
curl 'https://nexusapi.link/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

Copiez l'ID dans `data[].id`. `data[].supported_endpoint_types` énumère les protocoles disponibles pour ce modèle : `openai` pour Chat Completions, `anthropic` pour Messages, `openai-response` pour Responses et `image-generation` pour la génération d'images. Un modèle peut lister plusieurs types ; choisissez selon ce champ et votre client, pas selon son nom.

`/v1/models` est une vue instantanée pour une clé. Le catalogue indique aussi prix, groupes et descriptions. En cas de différence, suivez la réponse de la clé et l'état actuel de la console.

## Choisir rapidement le protocole

| Vous utilisez | Point de départ |
| --- | --- |
| Python, JavaScript, cURL ou un SDK compatible OpenAI | `/v1/chat/completions` (vérifiez d'abord que le champ contient `openai`) |
| Claude Code | La configuration Messages du [guide Claude Code](/fr/tools/claude-code) (vérifiez d'abord que le champ contient `anthropic`) |
| Codex CLI | Le fournisseur Responses du [guide Codex CLI](/fr/tools/codex-cli) (vérifiez d'abord que le champ contient `openai-response`) |
| Un modèle d'image | Le [guide des modèles d'image](/fr/guide/image-generation) (vérifiez d'abord que le champ contient `image-generation`) |

Si le modèle est visible mais que l'appel échoue, vérifiez d'abord son ID, le groupe de jetons et le chemin. Conservez le Request ID, puis utilisez l'[auto-vérification](/fr/faq/self-check).
