Cette page couvre uniquement **OpenAI Chat Completions**. Avant l'appel, vérifiez le modèle, le groupe et le protocole dans la [matrice des capacités](/fr/developer/capability-matrix).

<Tip>
Le catalogue et la matrice indiquent la disponibilité actuelle des modèles. La [référence API Apifox](https://nexusapi.apifox.cn/) décrit les champs et les schémas de réponse.
</Tip>

## Endpoint

```text
POST https://nexusapi.link/v1/chat/completions
```

## Requête minimale

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "YOUR_MODEL_ID",
    "messages": [{"role": "user", "content": "Bonjour"}]
  }'
```

| En-tête | Obligatoire | Valeur |
| --- | --- | --- |
| `Content-Type` | Oui | `application/json` |
| `Authorization` | Oui | `Bearer YOUR_API_KEY` |

## Champs minimaux et streaming

| Champ | Obligatoire | Rôle |
| --- | --- | --- |
| `model` | Oui | ID exact visible par la clé actuelle et libellé `openai` |
| `messages` | Oui | Messages de conversation au format Chat Completions |
| `stream` | Non | Utilisez `true` pour consommer des événements de streaming seulement si le modèle et le client le prennent en charge |

Pour une réponse normale, le texte est généralement dans `choices[0].message.content`; pour une réponse en flux, lisez chaque `choices[0].delta.content`. Vérifiez d'abord le modèle et la clé avec la requête minimale sans streaming, puis activez `stream` ou ajoutez des champs facultatifs.

`temperature`, les appels d'outils, les entrées visuelles et les sorties structurées ne sont pas garantis pour tous les modèles parce qu'une API est « compatible OpenAI ». Consultez la [référence API Apifox](https://nexusapi.apifox.cn/) pour les Schema et la [matrice des capacités](/fr/developer/capability-matrix) ainsi que le Catalogue pour la disponibilité.

## Premiers contrôles en cas d'erreur

| Résultat | Vérification |
| --- | --- |
| 401 | Clé absente, invalide, expirée ou désactivée. |
| 429 | Débit, concurrence ou limitation temporaire en amont. |
| 500 / 502 / 503 | Incident de traitement temporaire ; attendez puis réessayez une seule fois. |
| 524 | Dépassement du délai d'attente. |

`status_code=500, not implemented` avec `/v1/responses` et un canal Claude de type Anthropic est une incompatibilité de protocole, pas un 500 transitoire. Utilisez Chat Completions pour une application personnalisée ou la configuration Messages de Claude Code. Conservez le Request ID et consultez l'[auto-vérification](/fr/faq/self-check).
