title: "Choisir un outil client"
description: "Choisissez le bon client NexusAPI sans mélanger protocole, URL ni identifiants."
---

Choisissez d'abord l'outil adapté à votre flux de travail, puis suivez son guide. Les clients utilisent Chat Completions, Messages natif ou Responses ; ne copiez pas une Base URL ou un fichier de configuration d'un outil vers un autre.

## Choix rapide

| Besoin | Guide | Usage |
| --- | --- | --- |
| Agent de code en terminal | [Claude Code](/fr/tools/claude-code) | Flux de travail Claude |
| Agent Codex en terminal | [Codex CLI](/fr/tools/codex-cli) | Flux Responses / Codex |
| Plusieurs fournisseurs locaux | [CC Switch](/fr/tools/cc-switch) | Changer de configuration CLI |
| Claude Code dans un éditeur | [VS Code / Cursor](/fr/tools/cursor-vscode) | Travail dans l'éditeur |
| Application ou script | [Aperçu d'intégration](/fr/guide/integration-overview) | SDK et automatisation |

## Avant une modification locale

1. Créez une clé avec une limite adaptée.
2. Vérifiez son groupe et le modèle cible.
3. Copiez l'ID exact depuis le catalogue ou `/v1/models`.
4. Sauvegardez le fichier de configuration existant.
5. Testez une petite requête en lecture seule, puis consultez le journal.

<Warning>
N'exécutez pas de script « en un clic » de source inconnue. Il peut modifier la configuration, enregistrer des identifiants ou installer du code tiers. Utilisez les sources officielles, lisez le script et ne collez jamais une clé dans un script non fiable.
</Warning>

| Type de client | Base URL habituelle | Protocole |
| --- | --- | --- |
| SDK OpenAI compatible / application | `https://nexusapi.link/v1` | Chat Completions |
| Claude Code | `https://nexusapi.link` | Messages |
| Codex CLI | `https://nexusapi.link/v1` | Provider Responses |

La disponibilité dépend encore du modèle et du groupe : consultez la [matrice des capacités](/fr/developer/capability-matrix).
