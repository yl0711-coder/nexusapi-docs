## 1. Choisir un logiciel

Si le logiciel est installé, ouvrez son guide ; sinon, commencez par son installation. CC Switch évite la modification manuelle des fichiers, mais ne remplace pas Claude Code ou Codex CLI.

| Vous utilisez | Guide |
| --- | --- |
| Claude Code | [Configuration](/fr/tools/claude-code) |
| Codex CLI | [Configuration](/fr/tools/codex-cli) |
| CC Switch | [Configuration](/fr/tools/cc-switch) |
| VS Code / Cursor | [Configuration](/fr/tools/cursor-vscode) |
| Votre propre programme | [Configuration](/fr/developer/code-examples) |

## 2. Avant de commencer

1. Préparez votre [clé API](/fr/guide/api-key).
2. Copiez l'adresse et le modèle du bon guide, sans mélanger les configurations.
3. Sauvegardez les réglages existants. Ne supprimez pas tout le dossier de configuration.

Logiciel absent ? Envoyez son nom et une capture de ses réglages au support. Masquez la clé.

## 3. Choisir un modèle compatible

| Utilisation | Choix |
| --- | --- |
| Claude Code ou son extension | Pour ces guides, un modèle Claude de votre groupe compatible avec Claude Code |
| Codex CLI | Un modèle GPT et un groupe confirmés compatibles avec Codex ; tous les groupes GPT ne le sont pas |
| CC Switch | Choisir selon l'application Claude Code ou Codex sélectionnée |
| Votre programme | Choisir l'interface selon les [protocoles des modèles](/fr/developer/model-protocols) |

Les noms exacts figurent dans les [protocoles](/fr/developer/model-protocols). Un modèle visible dans la Place des modèles n'est pas utilisable par votre clé dans tous les logiciels. En cas de doute, indiquez logiciel, modèle et groupe au support, sans la clé complète.
