---
title: "Configurer NexusAPI avec CC Switch"
description: "Installez, ajoutez un fournisseur personnalisé, activez et testez."
---

CC Switch gère les réglages. **Installez d'abord [Claude Code](/fr/tools/claude-code) ou [Codex CLI](/fr/tools/codex-cli), seulement l'étape d'installation, puis revenez ici.** Pas besoin de modifier aussi leurs fichiers manuellement.

## 1. Installer CC Switch

Ouvrez les [téléchargements officiels](https://github.com/farion1231/cc-switch/releases/latest) :

- Windows : `.msi` Windows ; pour ARM, choisissez `arm64`.
- macOS : ouvrez le `.dmg` macOS et suivez les instructions.
- Linux : choisissez le `.deb` ou `.AppImage` adapté.

## 2. Ajouter un fournisseur personnalisé

Sélectionnez **Claude Code** ou **Codex** à gauche, puis **+ / Ajouter un fournisseur** et **Configuration personnalisée**. Pas Claude Desktop ni le préréglage d'un autre site.

![CC Switch 4.0.21 : configuration personnalisée (interface chinoise)](/images/nexusapi/cc-switch-custom-entry-zh.png)

## 3. Remplir les champs

[Créez une clé](/fr/guide/api-key), sélectionnez son groupe dans la [Place des modèles](https://nexusapi.link/pricing) et copiez le modèle adapté. Saisissez les valeurs NexusAPI du tableau ci-dessous :

| Champ | Claude Code | Codex |
| --- | --- | --- |
| Nom | NexusAPI Claude | NexusAPI Codex |
| Adresse | `https://nexusapi.link` | `https://nexusapi.link/v1` |
| API Key | Votre clé NexusAPI complète | Votre clé NexusAPI complète |
| Modèle principal | Modèle Claude Code / Messages copié | Modèle Codex / Responses copié |

Claude Code : ouvrez les options avancées. Saisissez le modèle principal copié dans « 默认兜底模型 » (modèle de repli par défaut). Pour Haiku, utilisez un modèle auxiliaire confirmé par le support dans le champ du modèle réellement appelé. Remplacez les valeurs fictives illustrées.

Codex : utilisez le modèle indiqué dans le tableau, sans les correspondances Claude Code. Configurez uniquement votre application, choisissez Direct, laissez le reste par défaut, puis cliquez sur Add / Save.

![Exemple du formulaire Claude Code. Remplacez les valeurs fictives ; ce brouillon n’a été ni enregistré ni connecté.](/images/nexusapi/cc-switch-claude-form-zh.png)

## 4. Activer et tester

Cliquez sur **Switch / Activer** pour ce fournisseur NexusAPI. Enregistrer seul ne suffit pas. Rouvrez le terminal et lancez le bon outil :

<Tabs>
<Tab title="Claude Code">
```bash
claude
```
</Tab>
<Tab title="Codex">
```bash
codex
```
</Tab>
</Tabs>

Envoyez « Réponds seulement : connexion réussie. Ne modifie aucun fichier. » Vérifiez réponse complète, modèle et groupe dans les [journaux](https://nexusapi.link/usage-logs/common). Le test consomme un peu de crédit.

Commande introuvable : installez le CLI. Connexion officielle : vérifiez l'activation et redémarrez. Modèle indisponible : recopiez un modèle du groupe. Si l'erreur nomme un modèle auxiliaire, confirmez les noms Haiku / Sonnet / Opus disponibles. Masquez la clé avant d'envoyer une erreur au support.

Projet officiel : [CC Switch](https://github.com/farion1231/cc-switch). Les libellés des boutons peuvent varier selon la version.
