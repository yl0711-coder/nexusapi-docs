---
title: "Configurer CC Switch"
description: "Ajoutez des fournisseurs NexusAPI pour Claude Code et Codex dans CC Switch."
---

CC Switch gère des configurations locales de fournisseurs pour les outils CLI. Ajoutez NexusAPI manuellement, sélectionnez ce fournisseur, puis redémarrez le CLI concerné dans un nouveau terminal.

## Préparation

Préparez une clé activée, l'ID exact disponible dans son groupe et les endpoints suivants :

| Usage | Endpoint |
| --- | --- |
| Claude Code | `https://nexusapi.link` |
| Codex | `https://nexusapi.link/v1` |

Le [guide des capacités](/fr/developer/capability-matrix) permet de vérifier le couple modèle/protocole.

## Installer CC Switch

- macOS : `brew install --cask cc-switch`
- Windows / Linux : téléchargez le paquet correspondant depuis les [releases officielles](https://github.com/farion1231/cc-switch/releases).

<Warning>
Utilisez uniquement le [dépôt officiel CC Switch](https://github.com/farion1231/cc-switch) ou ses releases. Évitez tout site demandant paiement, compte ou identifiants NexusAPI.
</Warning>

## Ajouter un fournisseur

Dans **Gestion des fournisseurs → Ajouter**, choisissez l'application cible, renseignez endpoint, clé et modèle, enregistrez, puis activez le fournisseur.

### Claude Code

| Champ | Valeur |
| --- | --- |
| App | `Claude` |
| Nom | `NexusAPI Claude` |
| Endpoint | `https://nexusapi.link` |
| Modèle principal | Modèle Claude compatible avec le groupe de la clé |

N'ajoutez pas `/v1`. Lancez `claude`, utilisez `/status`, puis envoyez une courte question.

### Codex

| Champ | Valeur |
| --- | --- |
| App | `Codex` |
| Nom | `NexusAPI Codex` |
| Endpoint | `https://nexusapi.link/v1` |
| Modèle principal | Modèle Responses disponible au groupe |

Lancez `codex` et faites une demande de lecture seule. Pour confirmer la liste effective :

```bash
curl 'https://nexusapi.link/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

En cas de problème, vérifiez que CC Switch a réellement changé le fournisseur, redémarrez l'outil, contrôlez la différence `/v1`, le groupe et l'ID du modèle. Gardez le Request ID.
