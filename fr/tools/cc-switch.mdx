---
title: "Configurer CC Switch"
description: "Ajoutez des fournisseurs NexusAPI pour Claude Code et Codex dans CC Switch."
---

CC Switch gère des configurations locales de fournisseurs pour les outils CLI. Ajoutez NexusAPI manuellement, sélectionnez ce fournisseur, puis redémarrez le CLI concerné dans un nouveau terminal.

## Préparation

Préparez une clé activée, l'ID exact disponible dans son groupe et les endpoints suivants :

| Usage | Endpoint |
| --- | --- |
| Claude Code | `https://nexusapi.link` |
| Codex | `https://nexusapi.link/v1` |

Le [guide des capacités](/fr/developer/capability-matrix) permet de vérifier le couple modèle/protocole.

```text
Console NexusAPI
→ Gestion des jetons
→ Créer ou copier une clé API
```

## Installer CC Switch

### macOS

```bash
brew install --cask cc-switch
```

Ouvrez ensuite CC Switch depuis Applications.

### Windows

Téléchargez `.msi` ou l’archive portable `.zip` depuis les [releases officielles](https://github.com/farion1231/cc-switch/releases).

```text
https://github.com/farion1231/cc-switch/releases
```

### Linux

Téléchargez `.deb` ou `.AppImage` depuis les [releases officielles](https://github.com/farion1231/cc-switch/releases). Sur Arch Linux, le paquet AUR communautaire peut être installé ainsi :

```text
https://github.com/farion1231/cc-switch/releases
```

```bash
paru -S cc-switch-bin
```

<Warning>
Utilisez uniquement le [dépôt officiel CC Switch](https://github.com/farion1231/cc-switch) ou ses releases. Évitez tout site demandant paiement, compte ou identifiants NexusAPI.
</Warning>

## Ajouter un fournisseur

Dans **Gestion des fournisseurs → Ajouter**, choisissez l'application cible, renseignez endpoint, clé et modèle, enregistrez, puis activez le fournisseur.

```text
Ouvrir CC Switch
→ Ajouter un fournisseur
→ Choisir l’application
→ Saisir endpoint NexusAPI, clé API et ID de modèle
→ Enregistrer
→ Activer ce fournisseur
→ Démarrer le CLI correspondant dans un nouveau terminal
```

### Claude Code

| Champ | Valeur |
| --- | --- |
| App | `Claude Code` |
| Nom | `NexusAPI Claude` |
| Endpoint | `https://nexusapi.link` |
| Clé API | Votre clé NexusAPI |
| Modèle principal | Modèle Claude compatible avec le groupe de la clé |

Les champs Haiku, Sonnet et Opus sont facultatifs : laissez-les vides ou renseignez des modèles disponibles. Exemple minimal :

```text
App: Claude Code
Name: NexusAPI Claude
Endpoint: https://nexusapi.link
API Key: YOUR_NEXUSAPI_KEY
Primary Model: YOUR_CLAUDE_MODEL_ID
Sonnet Model: YOUR_CLAUDE_MODEL_ID
```

Dans les versions récentes, choisissez `Claude Code`; une ancienne interface peut indiquer `Claude`. Choisissez le Provider de Claude Code, jamais Claude Desktop, et n’ajoutez pas `/v1`. Après l’activation, ouvrez un nouveau terminal :

```bash
claude
```

Utilisez `/status` puis une courte question :

```text
Présente-toi en une phrase.
```

### Codex

| Champ | Valeur |
| --- | --- |
| App | `Codex` |
| Nom | `NexusAPI Codex` |
| Endpoint | `https://nexusapi.link/v1` |
| Clé API | Votre clé NexusAPI |
| Modèle principal | Modèle Responses disponible au groupe |

Exemple minimal :

```text
App: Codex
Name: NexusAPI Codex
Endpoint: https://nexusapi.link/v1
API Key: YOUR_NEXUSAPI_KEY
Primary Model: YOUR_CODEX_MODEL_ID
```

Codex exige `/v1` car il utilise l’endpoint compatible OpenAI. Lancez ensuite :

```bash
codex
```

Faites d’abord une demande de lecture seule.

## Confirmer les modèles de la clé

Pour confirmer la liste effective :

```bash
curl 'https://nexusapi.link/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

Copiez un identifiant depuis `data[].id` ; ne le devinez pas d’après le nom d’un Provider ou une ancienne capture.

## Résolution des problèmes

### L’outil appelle encore l’adresse officielle

Vérifiez que le Provider NexusAPI est réellement actif, ouvrez un nouveau terminal et vérifiez qu’une configuration locale du CLI ne remplace pas les réglages CC Switch.

### La clé API est invalide

Vérifiez qu’elle provient de la gestion des jetons NexusAPI, qu’elle est activée, non expirée, suffisamment créditée et non bloquée par une restriction de modèles. Copiez-la exactement.

### Le modèle est indisponible

Vérifiez le groupe, les restrictions et la réponse `/v1/models` de la même clé. Si le modèle n’y apparaît pas, utilisez un modèle visible ou contactez le support avec le nom du modèle et le Request ID.

### Claude Code demande `/login`

Pour ce Provider NexusAPI, ne vous connectez pas à un compte Claude officiel. Réactivez le Provider NexusAPI dans CC Switch et redémarrez le terminal.

## Méthode recommandée

1. Ajoutez le Provider manuellement.
2. Vérifiez les modèles accessibles avec `/v1/models`.
3. Faites une requête courte avant toute tâche complexe.
