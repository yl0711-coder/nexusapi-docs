Cette page utilise une clé NexusAPI pour Codex CLI, pas votre mot de passe ChatGPT.

## 1. Installer Codex

Ouvrez PowerShell sous Windows ou Terminal sur Mac. Utilisez seulement la commande de votre système ; passez si déjà installé.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Tab>
</Tabs>

Rouvrez le terminal et vérifiez la version. Corrigez d'abord l'installation si la commande manque.

```bash
codex --version
```

## 2. Enregistrer adresse et modèle

[Créez une clé](/fr/guide/api-key), sélectionnez son groupe dans la [Place des modèles](https://nexusapi.link/pricing) et copiez un modèle Codex / Responses. Ouvrez la configuration utilisateur :

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex" | Out-Null
notepad "$env:USERPROFILE\.codex\config.toml"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```
</Tab>
</Tabs>

Dans nano : `Ctrl + O`, Entrée, puis `Ctrl + X`. Dans le Bloc-notes : `Ctrl + S`. Gardez `config.toml`, pas `.txt`.

Collez dans un fichier vide et remplacez seulement `YOUR_MODEL_ID` :

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

Sauvegardez l'existant, gardez `model` et `model_provider` en haut puis ajoutez ou modifiez `[model_providers.nexusapi]`, sans doublon. [CC Switch](/fr/tools/cc-switch) est une alternative. Ne mettez pas la clé dans ce fichier.

## 3. Définir et conserver la clé

Remplacez seulement `YOUR_API_KEY`. Windows définit la clé pour le terminal actuel et pour l'utilisateur de façon durable.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
[Environment]::SetEnvironmentVariable("NEXUSAPI_API_KEY", $env:NEXUSAPI_API_KEY, "User")
```
</Tab>
<Tab title="macOS (Zsh)">
```bash
touch ~/.zshrc
nano ~/.zshrc
```

Ajoutez la ligne suivante en fin de fichier, ou remplacez l'ancienne valeur sans doublon. Enregistrez et rouvrez le terminal.

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
<Tab title="Linux / WSL (Bash)">
```bash
nano ~/.bashrc
```

Ajoutez la ligne suivante en fin de fichier, ou remplacez l'ancienne valeur sans doublon. Enregistrez et rouvrez le terminal.

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
</Tabs>

Exemples : Zsh par défaut sur Mac, Bash sous Linux. Pour un autre shell, utilisez son fichier de démarrage ; demandez si nécessaire. Pas de clé dans le projet ou les captures.

## 4. Démarrer et tester

Dans votre projet, ouvrez le terminal et lancez :

```bash
codex
```

Avec `/status`, vérifiez modèle et fournisseur NexusAPI. Envoyez « Réponds seulement : connexion réussie. Ne modifie aucun fichier. » Vérifiez la réponse et le [journal](https://nexusapi.link/usage-logs/common). Le test consomme un peu de crédit.

## 5. Blocages courants

`Missing environment variable` : refaites l'étape 3. Modèle indisponible : recopiez un modèle Codex de votre groupe. Autres erreurs : [dépannage](/fr/faq/self-check).

Sur Mac, l'éditeur lancé du Dock peut ne pas lire ces variables. Vérifiez d'abord le CLI ; pour l'extension Codex, lancez l'éditeur depuis le terminal configuré avec `code .` ou `cursor .`. Pas de clé dans les réglages du projet.

Installation et configuration officielles : [Codex CLI](https://learn.chatgpt.com/docs/cli) · [Custom providers](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers).
