---
title: "Configurer Codex CLI"
description: "Installez Codex CLI et utilisez NexusAPI comme fournisseur Responses personnalisé."
---

Les commandes et champs `config.toml` suivent le [dépôt officiel Codex](https://github.com/openai/codex) et la [référence des fournisseurs personnalisés](https://learn.chatgpt.com/docs/config-file/config-advanced). NexusAPI fournit l'URL, la clé et l'ID de modèle.

## 1. Installer Codex

Choisissez une installation officielle :

### Windows PowerShell

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

### macOS, Linux ou WSL

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

### Utilisateur ayant déjà Node.js

```bash
npm install -g @openai/codex
codex --version
```

Après l’installation, vérifiez aussi la version dans un nouveau terminal :

```bash
codex --version
```

## 2. Créer une clé compatible

Dans **Gestion des jetons → Ajouter un jeton**, choisissez un groupe contenant le modèle destiné à Codex / Responses. Consultez la [matrice des capacités](/fr/developer/capability-matrix) : un canal Claude de type Anthropic n'est pas automatiquement compatible Responses.

## 3. Ajouter le fournisseur

| Système | Fichier |
| --- | --- |
| Windows | `%USERPROFILE%\\.codex\\config.toml` |
| macOS / Linux | `~/.codex/config.toml` |

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

N'enregistrez pas une vraie clé dans ce fichier ni dans `~/.codex/auth.json`, qui est le cache de connexion OpenAI de Codex.

## 4. Définir la variable de clé

### Windows PowerShell

```powershell
setx NEXUSAPI_API_KEY "YOUR_NEXUSAPI_KEY"
```

### macOS, Linux ou WSL

```bash
export NEXUSAPI_API_KEY='YOUR_NEXUSAPI_KEY'
```

`setx` nécessite un nouveau terminal ; `export` ne vaut que pour le shell courant. Utilisez le coffre ou la gestion d'environnement du système pour une conservation durable.

## 5. Vérifier

Dans le répertoire du projet, lancez :

```bash
cd your-project-folder
codex
```

Commencez par une tâche sans écriture :

```text
Explique la structure du dépôt sans modifier de fichiers.
```

Vérifiez ensuite le journal d’utilisation de la console. En cas d'échec, vérifiez la nouvelle session de terminal, la clé, le groupe et l'ID de modèle, puis conservez le Request ID pour l'[auto-vérification](/fr/faq/self-check).

## Résolution des problèmes

1. Utilisez un terminal ouvert après la définition de `NEXUSAPI_API_KEY`.
2. Vérifiez que la clé est activée, que le compte est crédité et que le groupe contient le modèle.
3. Recopiez l’ID exact depuis le catalogue ou `/v1/models`.
4. Conservez l’erreur d’origine et le Request ID, puis utilisez l’[auto-vérification](/fr/faq/self-check).

## VS Code / Cursor

Installez l’[extension Codex publiée par OpenAI](https://marketplace.visualstudio.com/items?itemName=OpenAI.chatgpt) depuis le marketplace. Elle utilise la même configuration Codex au niveau de l’utilisateur ; n’ajoutez pas les anciens paramètres `chatgpt.apiBase` ou `chatgpt.config` dans VS Code.
