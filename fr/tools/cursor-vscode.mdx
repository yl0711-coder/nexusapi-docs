---
title: "Claude Code dans VS Code ou Cursor"
description: "Utilisez l'extension officielle Claude Code avec votre configuration utilisateur NexusAPI."
---

L'extension officielle Claude Code offre le chat, les aperçus de diff, les références de fichiers et les demandes d'autorisation. VS Code et Cursor partagent la configuration utilisateur de Claude Code.

## 1. Installer l'extension officielle

Vérifiez d'abord que vous utilisez VS Code 1.94 ou une version ultérieure, puis terminez la [configuration Claude Code](/fr/tools/claude-code). Dans les extensions de l'éditeur, recherchez **Claude Code** et vérifiez que l'éditeur est **Anthropic**. Consultez aussi le [guide officiel VS Code](https://code.claude.com/docs/en/vs-code).

Ouvrez les extensions avec <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> sur macOS, ou <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> sous Windows et Linux.

<Warning>
Des extensions tierces similaires peuvent exister. Installez uniquement celle publiée par Anthropic et ne placez jamais une clé dans les réglages d'une extension tierce.
</Warning>

## 2. Réutiliser la configuration NexusAPI

L'extension lit le même `~/.claude/settings.json` que le CLI (ou son équivalent Windows). Ne dupliquez pas la clé dans les réglages de projet VS Code ou Cursor.

Si l'éditeur demande encore une connexion : ouvrez les réglages, recherchez `Claude Code login`, activez **Disable Login Prompt**, puis redémarrez complètement l'éditeur.

Ne copiez pas la clé NexusAPI dans `.vscode/settings.json` du projet et ne synchronisez, capturez ou versionnez jamais un réglage contenant la clé. Conservez-la uniquement dans `~/.claude/settings.json` au niveau utilisateur.

Si cette version de Cursor ne peut pas installer l’extension, exécutez `claude` dans son terminal intégré avec la même configuration utilisateur.

## 3. Ouvrir Claude Code

Ouvrez Claude Code depuis son icône, la barre d’activité, la palette de commandes ou la barre d’état. Si l’icône en haut à droite n’apparaît pas, ouvrez d’abord un fichier de code.

## 4. Vérifier sans écrire

![Extension officielle Claude Code affichée dans VS Code](/images/nexusapi/claude-code-vscode-official.jpg)

> Cet exemple provient de la [documentation officielle Claude Code pour VS Code](https://code.claude.com/docs/en/vs-code). La position des boutons peut évoluer avec l’extension.

Envoyez une requête sans écriture :

```text
Explique ce que fait le fichier actuellement ouvert sans modifier le code.
```

Exécutez ensuite `/status`, vérifiez que **Anthropic base URL** vaut `https://nexusapi.link`, puis vérifiez le journal NexusAPI correspondant.

## Résolution des problèmes

### L’extension n’apparaît pas après l’installation

Exécutez **Developer: Reload Window** depuis la palette de commandes, ou redémarrez complètement l’éditeur.

### Le CLI fonctionne mais pas l’extension

Vérifiez que `~/.claude/settings.json` est dans le répertoire utilisateur et non dans le projet, puis vérifiez l’URL et la clé. Activez **Disable Login Prompt** et redémarrez entièrement l’éditeur.

### Cursor ne trouve pas l’extension

Utilisez le point d’entrée Cursor du [guide officiel VS Code](https://code.claude.com/docs/en/vs-code). Si la version actuelle ne la prend pas en charge, utilisez `claude` dans le terminal intégré de Cursor.

Pour un incident persistant, conservez les versions de l’éditeur, de l’extension et de Claude Code, l’erreur d’origine et le Request ID, puis effectuez l’[auto-vérification](/fr/faq/self-check). Ne transmettez jamais une clé complète, un secret d’espace de travail ou du code confidentiel.
