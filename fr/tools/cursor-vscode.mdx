**Il s'agit de l'extension Claude Code, pas du chat intégré de Cursor.** [Créez une clé](/fr/guide/api-key), sélectionnez son groupe dans la [Place des modèles](https://nexusapi.link/pricing) et copiez un modèle compatible Claude Code.

## 1. Installer l'extension

Appuyez sur `Ctrl + Shift + X` (Mac : `Command + Shift + X`), recherchez `Claude Code`, vérifiez l'éditeur **Anthropic** puis installez.

![Marketplace officiel : Claude Code for VS Code, éditeur Anthropic](/images/nexusapi/claude-extension-marketplace.png)

Cette fiche officielle permet de vérifier le nom et l’éditeur. Installez ensuite la même extension depuis votre éditeur.

## 2. Ouvrir les réglages utilisateur

Avec `Ctrl + Shift + P` (Mac : `Command + Shift + P`), choisissez **Preferences: Open User Settings (JSON)**. Pas les réglages du projet, de l'espace de travail ou les valeurs par défaut.

## 3. Saisir les réglages NexusAPI

Remplacez `YOUR_API_KEY` par votre clé complète et `YOUR_MODEL_ID` par le modèle copié. Ne changez pas le reste.

```json
{
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "https://nexusapi.link"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

Sauvegardez d'abord les réglages existants et fusionnez les entrées `claudeCode` sans supprimer les autres. Si le fichier contient seulement `{}`, remplacez-le.

Enregistrez, sans connexion au compte officiel pour ces appels. Ces réglages contiennent votre clé : ne les mettez pas dans un projet et ne les partagez ni ne les synchronisez avec d'autres.

![Exemple des paramètres utilisateur : configurez uniquement les deux entrées `claudeCode`. Les réglages d’apparence et de fenêtre de démonstration ne sont pas nécessaires. Remplacez les valeurs fictives ; cette image ne prouve pas la connexion.](/images/nexusapi/vscode-user-settings-demo.png)

Exemple des paramètres utilisateur : configurez uniquement les deux entrées `claudeCode`. Les réglages d’apparence et de fenêtre de démonstration ne sont pas nécessaires. Remplacez les valeurs fictives ; cette image ne prouve pas la connexion.

## 4. Redémarrer et tester

Quittez complètement l'éditeur et rouvrez-le. Dans Claude Code, créez une conversation et envoyez « Réponds seulement : connexion réussie. Ne modifie aucun fichier. » Vérifiez la réponse complète et les [journaux](https://nexusapi.link/usage-logs/common). Le test consomme un peu de crédit.

Connexion officielle toujours affichée ? Vérifiez les réglages utilisateur, les valeurs remplacées, puis mettez à jour et redémarrez. Dans VS Code, installez depuis le [marché officiel des extensions](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code). Si Cursor ne trouve pas l'extension, utilisez le terminal avec le [guide Claude Code](/fr/tools/claude-code).
