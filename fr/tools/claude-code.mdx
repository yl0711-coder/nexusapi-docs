---
title: "Installer et configurer Claude Code"
description: "Installez, saisissez clé et modèle, puis testez un message."
---

Ces appels utilisent votre clé NexusAPI, sans connexion au compte officiel Claude.

## 1. Préparer et installer

[Créez une clé](/fr/guide/api-key), choisissez son groupe dans la [Place des modèles](https://nexusapi.link/pricing) et copiez un modèle Claude Code / Messages. Windows : cherchez `PowerShell` dans Démarrer. Mac : `Command + Espace`, puis Terminal.

Exécutez uniquement la commande de votre système. Si Claude Code est déjà installé, passez l'installation.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

Rouvrez le terminal et vérifiez la version. Si la commande manque, rouvrez le terminal ; si le problème persiste, envoyez l'erreur d'installation au support.

```bash
claude --version
```

## 2. Ouvrir le fichier de configuration

Ouvrez la configuration utilisateur avec la commande de votre système :

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

Dans nano : `Ctrl + O`, Entrée pour enregistrer, puis `Ctrl + X` pour quitter. Dans le Bloc-notes Windows : `Ctrl + S`. Le fichier doit rester `settings.json`, pas `.json.txt`.

## 3. Saisir clé et modèle

Dans un fichier vide, collez ce bloc. Remplacez `YOUR_API_KEY` et `YOUR_MODEL_ID` par votre clé complète et le modèle copié. Gardez les guillemets et virgules.

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

Sauvegardez un fichier existant et fusionnez seulement `model` et `env`, sans effacer le reste. Vous pouvez utiliser [CC Switch](/fr/tools/cc-switch). Ne placez pas la clé dans le projet ou les captures.

## 4. Démarrer et vérifier

Enregistrez, rouvrez le terminal dans votre projet et exécutez :

```bash
claude
```

Saisissez `/status`. Vérifiez `Anthropic base URL` = `https://nexusapi.link`, la source `ANTHROPIC_AUTH_TOKEN` et le modèle choisi.

Envoyez « Réponds seulement : connexion réussie. Ne modifie aucun fichier. » Vérifiez la réponse et le [journal](https://nexusapi.link/usage-logs/common). Le test consomme un peu de crédit.

Pour `/login` ou une clé invalide, vérifiez le fichier utilisateur et les valeurs remplacées, puis redémarrez. Voir le [dépannage](/fr/faq/self-check). Ne supprimez pas tout le dossier `.claude`.

Projet officiel : [Claude Code](https://github.com/anthropics/claude-code).
