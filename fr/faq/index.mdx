Choisissez le symptôme le plus proche. Lors d'un échec, enregistrez d'abord le message complet et le Request ID avant de modifier une configuration ou de réessayer.

## Intégration et configuration

- **Par où commencer ?** Consultez le [démarrage rapide](/fr/guide/quick-start).
- **Quelle Base URL utiliser ?** Elle dépend du client ; lisez l'[aperçu d'intégration](/fr/guide/integration-overview).
- **Pourquoi une erreur 404 ?** Vérifiez une URL du type `/v1/v1/...` et si le client construit déjà le chemin.
- **Pourquoi une nouvelle clé échoue-t-elle ?** Vérifiez son statut, le crédit, le groupe, l'ID du modèle et le format `Authorization: Bearer`.

## Modèles et coûts

- **Comment confirmer qu'un groupe peut utiliser un modèle ?** Filtrez le [catalogue de modèles](https://nexusapi.link/pricing) par groupe ou appelez `/v1/models` avec la clé.
- **Combien coûte une requête ?** Lisez l'entrée de console et le guide [usage et facturation](/fr/billing/usage-and-billing).
- **Une erreur peut-elle être facturée ?** Oui, selon le traitement en amont ou une nouvelle tentative du client. Rapprochez les Request ID.
- **Pourquoi le solde est-il suffisant mais la clé refuse-t-elle ?** Vérifiez aussi la limite de la clé, son expiration et son groupe.

## Erreurs d'API et d'outils

- **Que signifient 400, 401, 429, 500, 502, 503, 504 ou 524 ?** Voir les [erreurs courantes](/fr/faq/common-errors).
- **Une longue conversation ne continue plus ?** Conservez l'erreur, commencez une nouvelle session et évitez de renvoyer rapidement le même contenu.
- **La génération d'image expire ?** Ne soumettez pas immédiatement la même tâche ; conservez le Request ID et lisez le [guide des images](/fr/guide/image-generation).
- **`fetch failed` dans Claude Code ?** Testez d'abord un court message normal, puis suivez le [guide Claude Code](/fr/tools/claude-code).

## Contacter le support efficacement

Après l'[auto-vérification](/fr/faq/self-check), envoyez le Request ID, l'heure et le fuseau, le client et sa version, le modèle, l'endpoint, l'erreur complète et le caractère intermittent ou permanent du problème. N'envoyez jamais une clé complète, un mot de passe ou du contenu confidentiel.
