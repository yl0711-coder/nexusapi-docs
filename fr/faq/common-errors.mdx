description: "Diagnostiquez les erreurs NexusAPI à partir du code, du protocole et du Request ID."
---

Conservez d'abord l'erreur complète, le Request ID, l'heure, le modèle et l'endpoint. Les erreurs de paramètres, de protocole ou de session ne se corrigent pas par des tentatives répétées.

## `status_code=500, not implemented`

Avec `/v1/responses` sur un canal Claude de type Anthropic, ce message indique une **incompatibilité de protocole**, pas une panne temporaire.

1. Pour une application, utilisez `/v1/chat/completions`.
2. Pour Claude Code, utilisez la configuration Messages du [guide Claude Code](/fr/tools/claude-code).
3. Ne renvoyez pas la même demande sans la modifier.

## Codes HTTP

| Code | Cause probable | Première action |
| --- | --- | --- |
| 400 | Modèle, endpoint, paramètre ou session invalide | Vérifiez le protocole et faites un test neuf minimal. |
| 401 | Clé manquante, invalide, expirée ou désactivée | Recopiez la clé et le format Bearer. |
| 403 | Groupe, restriction, liste d'IP, compte ou refus amont | Vérifiez les réglages de la clé. |
| 404 | Mauvais chemin ou `/v1` en double | Contrôlez l'URL réellement appelée. |
| 429 | Limite de fréquence ou concurrence | Réduisez la concurrence et suivez `Retry-After`. |
| 500 / 502 / 503 | Incident temporaire de traitement ou d'amont | Attendez 10 à 30 secondes puis essayez une seule fois. |
| 504 / 524 | Dépassement d'attente | Réduisez si possible le contexte ou la sortie, et gardez le Request ID. |

## Autres messages fréquents

- **`no available channel`** : aucun canal activé pour ce modèle dans le groupe de la clé. Vérifiez l'ID exact, le groupe et le catalogue ; recréer des clés ou recharger du crédit ne résout pas ce point.
- **`Concurrency limit exceeded for user`** : attendez la fin des requêtes en cours et réduisez la concurrence du client.
- **`Content block not found`** : fréquent dans une longue session, un appel d'outil ou un flux interrompu. Lire [Content block not found](/fr/faq/content-block-not-found).
- **Erreur ou délai d'image** : vérifiez le modèle, l'endpoint Images et les paramètres ; ne soumettez pas immédiatement la même image.

Pour un coût inattendu, rapprochez les Request ID et les journaux de la même période. Ne supposez pas qu'une requête ordinaire est automatiquement rejouée par la plateforme.
