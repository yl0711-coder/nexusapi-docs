title: "Que faire en cas d’erreur"
description: "Conservez l’erreur, vérifiez la configuration et contactez le support si nécessaire."
---

**Faites d’abord une capture. Suivez ces vérifications ou contactez directement le support en cas de doute.**

## 1. Conserver l’erreur

Gardez le nom de l’application, l’heure, le modèle, le groupe et une capture. Copiez le Request ID s’il est disponible. Masquez la clé complète, les mots de passe et les données privées.

## 2. Suivre le message

| Message | Action |
| --- | --- |
| Clé / 401 | Recopier la clé complète, puis redémarrer l’application |
| 403 | Faire vérifier le modèle et le groupe par le support |
| 404 | Recopier l’adresse du [guide de l’application](/fr/tools) |
| 400 / not implemented | Faire confirmer la compatibilité du modèle avec l’application |
| 429 / limite simultanée | Attendre la fin des requêtes, réduire les tâches simultanées et essayer une fois |
| 500 / 502 / 503 / délai dépassé | Attendre 10–30 secondes, essayer une fois, puis contacter le support |
| no available channel | Vérifier le modèle du groupe ; contacter le support, sans recharger pour cette erreur |
| Crédit insuffisant | Vérifier solde, limite et expiration de la clé |

## 3. Tester un seul message court

Sauvegardez le contenu important, ouvrez une nouvelle conversation et envoyez « Réponds : bonjour ». Utilisez-la si la réponse est complète ; sinon, contactez le support. **Le test peut consommer des crédits. Ne réessayez pas en boucle et ne supprimez pas le dossier de configuration.**

## 4. Copier ce message au support

```text
Application :
Heure :
Modèle et groupe :
Erreur ou capture :
Request ID (si disponible) :
```

Laissez les champs inconnus vides. N’envoyez ni clé complète, ni mot de passe, ni code de vérification.

## La configuration reste sans effet

| Symptôme | Première vérification |
| --- | --- |
| Connexion au service officiel toujours demandée | Vérifier le guide, les réglages utilisateur et les valeurs d'exemple remplacées, puis redémarrer complètement. Ne pas utiliser la clé NexusAPI comme mot de passe officiel |
| CC Switch enregistré, ancien fournisseur utilisé | Activer NexusAPI pour la bonne application, puis redémarrer ; enregistré ne signifie pas actif |
| Le modèle ne change pas | Vérifier la configuration active, redémarrer, ouvrir une nouvelle conversation et consulter les journaux NexusAPI ; sans trace, vérifier d'abord le passage par la plateforme |
| Terminal fonctionnel, éditeur en échec | Distinguer extension Claude Code et IA intégrée. Suivre le [guide extension](/fr/tools/cursor-vscode) ou vérifier l'environnement de lancement du [guide Codex](/fr/tools/codex-cli). Ne pas mettre la clé dans le projet |
| Solde disponible, crédit insuffisant | Vérifier quota, expiration et groupe de la clé ; pour un forfait, vérifier validité, reste et groupes autorisés avant de recharger |

Faites un seul test court. En cas d'échec, envoyez les informations ci-dessus au groupe d'assistance ou à la personne qui a ouvert le compte. N'envoyez pas de fichier de configuration contenant une clé.
