---
title: "Auto-vérification"
description: "Conservez les informations minimales et isolez une erreur NexusAPI avant de contacter le support."
---

La plupart des erreurs de configuration ou incidents temporaires peuvent être circonscrits en quelques minutes. Préservez d'abord les preuves, puis faites un seul test minimal à faible fréquence.

## 1. Conserver les preuves

Avant de fermer le client ou de réessayer, notez :

- le texte complet de l'erreur et le Request ID ;
- l'heure et le fuseau horaire ;
- l'ID du modèle, l'endpoint et l'usage ou non du streaming ;
- le client / SDK et sa version.

Ne partagez pas une clé complète, un mot de passe, des données privées ou le contenu complet d'une demande métier.

## 2. Identifier la catégorie

| Symptôme | À vérifier en premier |
| --- | --- |
| 401 | Clé, préfixe `Bearer` et URL. |
| 403 | Groupe, restriction de modèle, liste d'IP, compte ou refus en amont. |
| 404 | Base URL, chemin, `/v1` absent ou dupliqué. |
| 400 | Modèle, protocole, paramètres ou état de session. |
| 429 | Concurrence et fréquence ; respectez `Retry-After`. |
| 500 / 502 / 503 | Attendez 10 à 30 secondes puis réessayez une seule fois. |
| 504 / 524 | Taille de demande, délai et état de service. |
| `500, not implemented` | Vérifiez que `supported_endpoint_types` du modèle contient le protocole utilisé par la requête. |
| `no available channel` | ID de modèle, groupe de jetons et disponibilité actuelle. |

Voir les [erreurs API courantes](/fr/faq/common-errors) pour le détail.

## 3. Faire un test minimal

1. Confirmez le solde et le statut de la clé dans la console.
2. Copiez à nouveau l'ID du modèle depuis le catalogue.
3. Ouvrez une nouvelle session et envoyez un court texte.
4. Réessayez au plus une fois en gardant le nouveau Request ID.
5. Vérifiez l'entrée correspondante dans le journal.

Si une session neuve fonctionne, l'état ou le contenu de la conversation initiale est probablement impliqué. Si le test minimal échoue aussi, envoyez les preuves ci-dessus.

## Contacter le support

Envoyez ces éléments dans un même message :

```text
Heure (avec fuseau) :
Request ID :
Client et version :
Modèle :
Endpoint :
Erreur complète :
Intermittent ou permanent :
Testé dans une nouvelle session :
```

Si l'identification d'une clé est nécessaire, ne donnez que ses six derniers caractères.
