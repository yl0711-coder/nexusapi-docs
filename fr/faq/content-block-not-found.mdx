---
title: "Bloc de contenu non trouvé"
---

`API Error: Content block not found` Cela signifie que le client n’a pas trouvé le fragment de contenu attendu, que l’on voit couramment dans les longs CV de session, les appels d’outils ou les réponses qui ne s’arrêtent pas complètement.

## Étapes de traitement recommandées

1. Créez une nouvelle session et renvoyez le contenu nécessaire.
2. Mettez à jour Claude Code, Codex, Cursor ou plugins associés.
3. Désactivez temporairement les appels d’outils inutiles et les fonctionnalités expérimentales.
4. Raccourcir le contenu d’une seule entrée et éviter de porter des archives historiques trop longues.
5. Testez si le même modèle peut répondre correctement avec une question simple.

## Quand devez-vous nous contacter ?

Veuillez soumettre votre question dans les situations suivantes :

- Même après avoir créé une nouvelle session, cela réapparaît toujours.
- Même les problèmes simples ne peuvent pas être résolus.
- Plusieurs modèles présentent simultanément la même erreur.
- Une consommation anormale survient après une erreur.

Veuillez fournir :

- Demande d’ID。
- Erreur d’heure et fuseau horaire.
- Outils et versions utilisés.
- Nom du modèle.
- Erreur de texte ou capture d’écran originale.
- Toutes les sessions ont-elles échoué, ou seulement la session originale l’a été ?

Merci de ne pas envoyer de clés API complètes ni de contenu de session complète contenant des informations privées.
