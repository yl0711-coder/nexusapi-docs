## 1. Trouver votre logiciel

| Votre besoin | Guide |
| --- | --- |
| Claude Code | [Claude Code](/fr/tools/claude-code) |
| Codex CLI | [Codex CLI](/fr/tools/codex-cli) |
| Changer de service avec CC Switch | [CC Switch](/fr/tools/cc-switch) |
| VS Code / Cursor | [Éditeur](/fr/tools/cursor-vscode) |
| Votre propre programme | [Exemples de code](/fr/developer/code-examples) |

## 2. Préparer trois informations

| À saisir | Où le trouver |
| --- | --- |
| Clé API | Créez et copiez-la dans [Clés API](https://nexusapi.link/keys) |
| Modèle | Dans la [Place des modèles](https://nexusapi.link/pricing), choisissez le groupe de votre clé et copiez le nom |
| Adresse API | Copiez-la du guide correspondant, sans la reconstruire |

Claude Code utilise généralement `https://nexusapi.link` ; Codex CLI et le SDK OpenAI utilisent généralement `https://nexusapi.link/v1`. **Suivez le guide de votre logiciel.**

## 3. Vérifier le résultat

Envoyez « Réponds : connexion réussie. » Une réponse complète confirme la configuration. Sinon, consultez le [dépannage](/fr/faq/self-check) ou envoyez une capture de l'erreur au support. Masquez la clé complète.
