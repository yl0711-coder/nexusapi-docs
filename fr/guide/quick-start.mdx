title: "Démarrer en 5 minutes"
description: "Connectez-vous, créez une clé et configurez votre logiciel."
---

**Suivez ces 4 étapes. Passez celles que vous avez déjà terminées.**

## 1. Se connecter et vérifier le crédit

[Connectez-vous](https://nexusapi.link/sign-in). Contactez le support si vous n'avez pas de compte.

Ouvrez le [Portefeuille](https://nexusapi.link/wallet). Si vous avez du crédit utilisable ou un forfait, continuez. Sinon, [ajoutez des fonds](/fr/guide/recharge).

## 2. Créer et copier une clé API

1. Ouvrez [Clés API](https://nexusapi.link/keys), puis **Créer une clé API**.
2. Donnez un nom, choisissez le groupe fourni par le support et indiquez `1` pour la quantité. Gardez les autres réglages par défaut, sauf besoin particulier.
3. Cliquez sur **Enregistrer les modifications**.
4. Dans la liste, cliquez sur le bouton de copie de la nouvelle clé.

Besoin d'images ? Voir le [guide des clés](/fr/guide/api-key). **Ne partagez pas votre clé complète.**

## 3. Configurer votre logiciel

Vérifiez ces quatre éléments avant d'ouvrir un guide :

| Élément | Comment vérifier |
| --- | --- |
| Logiciel | Identifiez le terminal, l'extension ou votre propre programme |
| Groupe | Celui de la nouvelle clé ; utilisez d'abord le groupe fourni par le support |
| Modèle | Sélectionnez ce groupe dans la Place des modèles et copiez un modèle compatible |
| Adresse API | Copiez celle du guide du logiciel, sans ajouter de chemin |

| Votre logiciel | Guide à suivre |
| --- | --- |
| Claude Code | [Configuration Claude Code](/fr/tools/claude-code) |
| Codex CLI | [Configuration Codex CLI](/fr/tools/codex-cli) |
| CC Switch | [Configuration CC Switch](/fr/tools/cc-switch) |
| VS Code / Cursor | [Configuration de l'éditeur](/fr/tools/cursor-vscode) |
| Votre propre programme | [Exemples à copier](/fr/developer/code-examples) |

Pour éviter de modifier les fichiers, utilisez [CC Switch](/fr/tools/cc-switch), après avoir installé Claude Code ou Codex CLI. Une même clé ou un même groupe ne rend pas tous les modèles compatibles avec tous les logiciels. Consultez les [protocoles](/fr/developer/model-protocols), ou demandez au support avec logiciel, modèle et groupe.

**Recopiez l'adresse et le modèle du guide correspondant, puis votre propre clé API. L'adresse peut varier selon le logiciel.**

## 4. Envoyer un message de test

Dans une nouvelle conversation, envoyez : **« Réponds uniquement : connexion réussie. Ne modifie aucun fichier. »**

Après une réponse complète, vérifiez la présence de l'appel, son modèle et son groupe dans les [journaux](https://nexusapi.link/usage-logs/common). La réponse seule ne prouve pas le passage par NexusAPI. Le test consomme un peu de crédit.

En cas d'échec, transmettez logiciel, capture, heure, modèle et groupe. Masquez la clé complète.
