## Besoin d'aide ?

Envoyez au support :

- Le logiciel utilisé.
- L'heure, le modèle et le groupe.
- Le texte d'erreur ou une capture, et l’identifiant de requête (Request ID) s'il est disponible.

**Masquez les clés API complètes. N'envoyez jamais de mot de passe ni de code de vérification.** Inutile de deviner : commencez par l'erreur affichée.
