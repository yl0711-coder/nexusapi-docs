## Les trois informations nécessaires

| Information | Où l'obtenir | Rôle |
| --- | --- | --- |
| Base URL | Cette documentation | Envoie les requêtes à NexusAPI |
| Clé API | Console → Gestion des jetons | Identifie l'appelant et les groupes disponibles |
| ID de modèle | Console → Catalogue de modèles | Sélectionne le modèle à appeler |

<Warning>
Ne divulguez jamais une clé API dans une conversation, une capture d'écran, un dépôt frontend ou une configuration publique. En cas de doute, supprimez ou réinitialisez immédiatement la clé dans la console.
</Warning>

## Pour demander de l'aide, joignez aussi

- L'heure de l'incident et le fuseau horaire
- L'ID du modèle, l'endpoint et l'utilisation ou non du streaming
- Le message d'erreur complet et le Request ID
- La plus petite reproduction déjà tentée

Ces éléments évitent les allers-retours et accélèrent le diagnostic.
