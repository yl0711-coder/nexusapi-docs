**サイトではアカウントと利用状況を管理します。Claude CodeやCodexの接続設定は[アプリ別手順](/ja/tools)を確認してください。**

## 1. やりたいことから探す

| やりたいこと | 開くページ | 操作 |
| --- | --- | --- |
| アカウントの概要を見る | [概要](https://nexusapi.link/dashboard/overview) | 利用概況を確認。個別の呼び出しはログで確認 |
| 期間内の呼び出しを集計する | [ダッシュボード](https://nexusapi.link/dashboard/models) | 期間を選んで自分の統計を見る。単一リクエストの明細ではありません |
| キーの作成・コピー・制限・無効化 | [APIキー](https://nexusapi.link/keys) | [キー手順](/ja/guide/api-key)に沿って操作 |
| 呼び出しと料金を調べる | [利用ログ](https://nexusapi.link/usage-logs/common) | 時刻、モデル、グループ、トークン名で検索。[利用と請求](/ja/billing/usage-and-billing)を参照 |
| 残高確認、チャージ、支払履歴 | [ウォレット](https://nexusapi.link/wallet) | [チャージ手順](/ja/guide/recharge)を参照 |
| モデルとグループの料金を見る | [モデル広場](https://nexusapi.link/pricing) | キーと同じグループを選んでモデル名をコピー。[モデルと料金](/ja/billing/models-pricing)を参照 |
| 言語や残高通知を変更 | [プロフィール](https://nexusapi.link/profile) | [表示とメニュー](/ja/guide/account-security#personal-settings) · [残高通知](/ja/guide/account-security#balance-reminders) |
| パスワードやログイン端末を確認 | [セキュリティとアクセス](https://nexusapi.link/security) | [アカウントの安全](/ja/guide/account-security)を参照 |

メニューはアカウントの権限、サイト設定、個人の表示設定で異なります。見つからない場合は第3節を確認し、別の管理画面URLを推測しないでください。

### 一定期間の利用統計を見る

1. [ダッシュボード](https://nexusapi.link/dashboard/models)を開き、「フィルター」をクリックします。
2. 「クイック範囲」を選ぶか開始・終了時刻を指定します。時間別・日別などに集計する場合は「時間の粒度」を変更します。
3. 「フィルターを適用」を押して呼び出し回数、消費量、モデル別の推移を確認します。既定の期間に戻すには、フィルターを開き直してリセットします。

一般アカウントは自分の統計を確認します。グラフは集計であり、個別の請求ではありません。料金の疑問は同じ期間の[利用ログ](/ja/billing/usage-and-billing)で確認してください。

## 2. 残高、キーのクォータ、利用額の違い

- **ウォレット残高**：アカウントで使えるクレジット。チャージ後はここで確認します。
- **キーの残りクォータ**：そのキーが今後使える量。別のチャージ残高ではありません。
- **ログの料金**：1回の呼び出しに記録された利用額。
- **概要とダッシュボード**：集計結果。個別のエラーや料金は該当ログで確認します。

残高があっても、キーが期限切れ、無効、クォータ不足なら使えない場合があります。再チャージする前に[キー設定](/ja/guide/api-key#key-limits)を確認してください。

## 3. メニューが見つからない場合

1. [プロフィール](https://nexusapi.link/profile)を開き、「サイドバー個人設定」があれば自分で機能を非表示にしていないか確認する。
2. 該当項目を有効にして「変更を保存」を押す。不明ならその欄の「デフォルトにリセット」を使い、保存する。
3. 設定欄や項目がない、または改善しない場合は、既存のサポート窓口や担当者に連絡する。

個人設定で表示できるのは、アカウントに開放された機能だけです。他の機能は解放できません。ウォレットのプランなども実際に表示される内容に従ってください。

## 4. 問い合わせに必要な情報

ページ、やりたい操作、発生時刻、エラーまたは画像を伝えます。リクエストIDがあれば添え、不明な項目は空欄で構いません。

**キー全文、パスワード、認証コード、復旧コードは送らないでください。画像では個人・支払・業務情報を隠してください。**
