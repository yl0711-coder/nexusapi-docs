title: "接続方法の概要"
description: "クライアントとモデルの対応に合わせて、NexusAPI の URL とプロトコルを選択します。"
---

NexusAPI は自作アプリ、OpenAI 互換クライアント、開発ツールから利用できます。ただし、クライアントごとに URL の組み立て方とプロトコルは異なります。別のツールの設定をそのままコピーせず、用途から選んでください。

## 接続前の三つの確認

1. コンソールで API Key を作成し、適切な上限を設定します。
2. その Key のトークングループに対象モデルがあることを確認します。
3. モデルマーケットプレイスまたは `/v1/models` から正確なモデル ID をコピーします。

## URL とプロトコル

| 場面 | Base URL | 開始点 | 注意 |
| --- | --- | --- | --- |
| OpenAI 互換 SDK / 一般アプリ | `https://nexusapi.link/v1` | Chat Completions | SDK が通常 `/chat/completions` を追加します。 |
| Claude Code | `https://nexusapi.link` | Anthropic Messages | `/v1` を追加しないでください。 |
| Codex CLI | `https://nexusapi.link/v1` | Responses | Codex のカスタムプロバイダーを使用します。 |
| 画像モデル | `https://nexusapi.link/v1` | Images | 明示的に画像対応のモデルだけで使用します。 |

<Warning>
モデルが見えても、すべてのプロトコルで使えるとは限りません。公開されている endpoint の範囲は、必ず [API とモデル対応マトリクス](/ja/developer/capability-matrix)で確認してください。
</Warning>

## 最小確認手順

1. 現在の Key で `GET /v1/models` を呼び出します。
2. 返却された、プロトコルに合うモデル ID を選びます。
3. 短いテキストで一度だけテストします。
4. コンソールの利用ログで該当リクエストを確認します。

失敗時はエラー全文と Request ID を保存し、[問題の自己確認](/ja/faq/self-check)へ進んでください。同じタスクを連続送信しないでください。
