## 1. 使うアプリを選ぶ

| やりたいこと | 手順 |
| --- | --- |
| Claude Codeを使う | [Claude Code](/ja/tools/claude-code) |
| Codex CLIを使う | [Codex CLI](/ja/tools/codex-cli) |
| CC Switchでサービスを切り替える | [CC Switch](/ja/tools/cc-switch) |
| VS Code / Cursorで使う | [エディター設定](/ja/tools/cursor-vscode) |
| 自作プログラム | [コード例](/ja/developer/code-examples) |

## 2. 3つの情報を用意

| 入力するもの | 入手先 |
| --- | --- |
| APIキー | [APIキー](https://nexusapi.link/keys)で作成してコピー |
| モデル名 | [モデル広場](https://nexusapi.link/pricing)でキーと同じグループを選び、名前をコピー |
| APIアドレス | 上の対応する手順からコピー。自分で組み立てない |

Claude Codeは通常 `https://nexusapi.link`、Codex CLIとOpenAI SDKは通常 `https://nexusapi.link/v1` を使います。**アプリ別の手順を優先してください。**

## 3. 動作を確認

「接続成功、と返信してください」と送ります。最後まで返答があれば完了です。失敗したら[トラブル対処](/ja/faq/self-check)を確認するか、エラー画面をサポートへ送ってください。キーの全文は隠してください。
