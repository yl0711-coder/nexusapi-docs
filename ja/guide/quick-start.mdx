---
title: "5分で始める"
description: "ログイン、キー作成、アプリ設定の順に進めます。"
---

**次の4ステップで設定します。済んでいる手順は飛ばしてください。**

## 1. ログインして残高を確認

[ログイン画面](https://nexusapi.link/sign-in)を開きます。アカウントがない場合はサポートに連絡してください。

[ウォレット](https://nexusapi.link/wallet)を開きます。利用できる残高やプランがあれば次へ。なければ[チャージ](/ja/guide/recharge)してください。

## 2. APIキーを作成してコピー

1. [APIキー](https://nexusapi.link/keys)で「APIキーを作成」をクリック。
2. 名前を入力し、サポートに案内されたグループを選択。個数は `1`、特別な指定がなければ他は初期設定のまま。
3. 保存ボタンをクリック。
4. 一覧に戻り、作成したキーのコピーボタンをクリック。

迷ったら[画像付き手順](/ja/guide/api-key)を確認してください。**キーの全文を他人に渡さないでください。**

## 3. 使うアプリの手順を開く

手順を開く前に、次の4項目を確認します。

| 項目 | 確認方法 |
| --- | --- |
| アプリ | ターミナル、エディター拡張、自作プログラムのどれか |
| グループ | 作ったキーのグループ。初回はサポートが案内したもの |
| モデル名 | モデル広場で同じグループを選び、対応するモデル名をコピー |
| APIアドレス | アプリの手順からコピー。自分でパスを追加しない |

| 使うもの | 設定手順 |
| --- | --- |
| Claude Code | [Claude Code](/ja/tools/claude-code) |
| Codex CLI | [Codex CLI](/ja/tools/codex-cli) |
| CC Switch | [CC Switch](/ja/tools/cc-switch) |
| VS Code / Cursor | [エディター設定](/ja/tools/cursor-vscode) |
| 自作プログラム | [コピーできるコード例](/ja/developer/code-examples) |

設定ファイルの編集が難しければ [CC Switch](/ja/tools/cc-switch)を利用できます。先に使う Claude Code または Codex CLI をインストールしてください。同じキーやグループでも、全モデルが全アプリに対応するわけではありません。[推奨プロトコル](/ja/developer/model-protocols)を確認するか、アプリ・モデル・グループをサポートに伝えてください。

**アドレスとモデル名は対応する手順からコピーし、APIキーは自分のものを入力します。アプリごとにアドレスが違う場合があります。**

## 4. 一言送って確認

新しい会話で、**「接続成功、とだけ返信してください。ファイルは変更しないでください」**と送ります。

完全な返信が届いたら、[利用履歴](https://nexusapi.link/usage-logs/common)に今回の記録があり、モデルとグループも正しいことを確認します。返信だけでは NexusAPI を通った証明になりません。テストには少量のクレジットを使います。

失敗したらアプリ名、エラー画像、時刻、モデル、グループをサポートへ。キー全文は隠してください。
