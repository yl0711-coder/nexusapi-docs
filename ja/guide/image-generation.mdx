title: 画像モデルの利用方法
description: NexusAPI で画像生成モデルを呼び出す方法。

画像モデルはテキストモデルとは呼び出し方法が異なります。リクエスト前に[モデルマーケットプレイス](https://nexusapi.link/pricing)で、モデル名、現在の API Key のグループ、および画像生成対応の表示を確認してください。

<Warning>
**先にモデルの対応機能を確認してください**

画像生成パラメータをテキストチャットのエンドポイントへ送ったり、テキストモデルの ID を画像エンドポイントで使ったりしないでください。モデル、エンドポイント、またはパラメータが不一致のまま再試行しても解決しません。
</Warning>

## 呼び出し方法

画像生成には OpenAI 形式の Images エンドポイントを使用します。

```text
POST https://nexusapi.link/v1/images/generations
```

最小リクエストに必要なのはモデル ID とプロンプトだけです。

```bash
curl 'https://nexusapi.link/v1/images/generations' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "YOUR_IMAGE_MODEL_ID",
    "prompt": "白い背景に、シンプルな青い幾何学的テクノロジー企業アイコン"
  }'
```

`YOUR_IMAGE_MODEL_ID` は、モデルマーケットプレイスで現在のグループに表示され、画像生成に対応している正確なモデル ID に置き換えてください。

## パラメータと結果

対応するサイズ、品質、画像数、戻り形式はモデルごとに異なります。`size`、`quality`、`n`、`response_format` などのオプションは、モデルマーケットプレイスで対応が明示されている場合だけ送信してください。共通の認証、モデル取得、プロトコル選択は [API 基本](/ja/developer/api-basics)を参照してください。

画像結果は通常 `data` 配列で返ります。URL か Base64 データか、1 回に何枚生成できるかは、選択したモデルの仕様と実際のレスポンスに従います。

## 待ち時間とタイムアウト

公開されている `/v1/images/generations` は**同期 HTTP リクエスト**です。クライアントはこのリクエストの結果を待つ必要があります。この公開 endpoint には、汎用画像生成向けの統一されたタスク ID / ポーリング API はありません。実際の戻り形式は上流プロバイダーごとに異なる場合があります。

- 画像生成には数十秒以上かかることがあります。クライアント、社内プロキシ、ブラウザ拡張のタイムアウトが短すぎると、上流の応答前に失敗することがあります。
- 結果を確認する前に同じ画像タスクを繰り返し送信しないでください。重複生成・重複課金の原因になります。
- `504`、`524`、またはクライアントのタイムアウト時は、Request ID と発生時刻を保存してサポートへ連絡してください。タスクが必ず成功した、または実行されなかったとは判断しないでください。

## よくある問題

| 現象 | 最初に確認すること |
| --- | --- |
| `Image generation is not enabled` | モデルの画像対応、画像エンドポイントの使用、現在のグループの利用可否 |
| `model not supported` | モデル ID が正確か、画像エンドポイントにテキストモデルを使っていないか |
| `400` / パラメータエラー | 未確認のオプションを外し、最小リクエストで確認する |
| `504` / `524` / クライアントのタイムアウト | Request ID を保存し、すぐに同じ生成を繰り返さない |
| 画像結果を受け取れない | クライアントが `data` フィールドと戻り形式を正しく読んでいるか |

サポートが必要な場合は、モデル名、Request ID、発生時刻、マスク済みのリクエストパラメータ、完全なエラー文を送ってください。API Key 全体は送らないでください。
