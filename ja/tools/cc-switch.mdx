title: "CC SwitchでNexusAPIを設定"
description: "インストール、カスタム追加、有効化、テストの順です。"
---

CC Switchは設定を管理します。**先に [Claude Code](/ja/tools/claude-code) または [Codex CLI](/ja/tools/codex-cli) のインストール手順だけ済ませて戻ってください。** 別途手動で設定ファイルを変える必要はありません。

## 1. CC Switchを入れる

[公式ダウンロード](https://github.com/farion1231/cc-switch/releases/latest)でOS別に選びます：

- Windows：Windows `.msi`。ARM端末は `arm64` 版。
- macOS：macOS `.dmg` を開いてインストール。
- Linux：対応する `.deb` または `.AppImage`。

## 2. カスタム設定を追加

左側で **Claude Code** または **Codex** を選択し、右上の **+ / Add provider** からカスタム設定を追加。Claude Desktopや他社プリセットは選びません。

![CC Switch 4.0.21：カスタム設定を選択（中国語UI）](/images/nexusapi/cc-switch-custom-entry-zh.png)

## 3. 表どおりに入力

[キーを作成](/ja/guide/api-key)し、[モデル広場](https://nexusapi.link/pricing)で同じグループから対象ツール用モデル名をコピー。次の表のNexusAPI設定値を入力します。

| 項目 | Claude Code | Codex |
| --- | --- | --- |
| 名前 | NexusAPI Claude | NexusAPI Codex |
| アドレス | `https://nexusapi.link` | `https://nexusapi.link/v1` |
| APIキー | 自分の完全なNexusAPIキー | 自分の完全なNexusAPIキー |
| 主モデル | コピーしたClaude Code / Messagesモデル | コピーしたCodex / Responsesモデル |

Claude Code：詳細設定を開き、「默认兜底模型」（デフォルトのフォールバックモデル）にコピーした主モデル名を入力します。Haikuの実リクエストモデルにはサポートが確認した補助モデル名を指定します。画像の仮の値は必ず置き換えてください。

Codex：表のモデル名を使い、Claude Codeのモデル設定は不要です。使うアプリだけを設定し、Directを選択。ほかは初期値のまま、Add / Saveで保存します。

![Claude Codeの入力例。仮の値は置き換えてください。未保存・未接続の画面です。](/images/nexusapi/cc-switch-claude-form-zh.png)

Claude Codeの入力例。仮の値は置き換えてください。未保存・未接続の画面です。

![Claude Codeのモデル設定例（中国語UI）](/images/nexusapi/cc-switch-claude-models-zh.png)

## 4. 有効化して確認

このNexusAPI設定の **Switch / 有効化** をクリック。保存だけでは切り替わりません。ターミナルを開き直して対象を起動：

<Tabs>
<Tab title="Claude Code">
```bash
claude
```
</Tab>
<Tab title="Codex">
```bash
codex
```
</Tab>
</Tabs>

「接続成功、とだけ返信し、ファイルを変更しないでください」と送り、完全な返信と[利用履歴](https://nexusapi.link/usage-logs/common)のモデル・グループを確認。少量のクレジットを使います。

コマンドがなければCLIをインストール。公式サービスに接続するなら有効化と再起動を確認。モデルがなければ同じグループから再コピー。補助モデルのエラーなら利用可能なHaiku / Sonnet / Opus名を確認。問い合わせ画像のキーは隠してください。

公式プロジェクト：[CC Switch](https://github.com/farion1231/cc-switch)。ボタン名はバージョンによって異なる場合があります。
