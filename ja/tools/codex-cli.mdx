title: "Codex CLIのインストールと設定"
description: "アドレス、モデル、キーを設定して動作を確認します。"
---

NexusAPIキーでCodex CLIを設定します。ChatGPTのパスワードは使いません。

## 1. Codexを入れる

WindowsはPowerShell、Macはターミナルを開き、OS別のコマンドだけを実行。インストール済みなら飛ばします。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Tab>
</Tabs>

ターミナルを開き直し、バージョンを確認。コマンドがなければ先にインストールを直してください。

```bash
codex --version
```

## 2. アドレスとモデルを保存

[キーを作成](/ja/guide/api-key)し、[モデル広場](https://nexusapi.link/pricing)で同じグループからCodex / Responses対応名をコピーして、ユーザー設定を開きます：

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex" | Out-Null
notepad "$env:USERPROFILE\.codex\config.toml"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```
</Tab>
</Tabs>

nanoは `Ctrl + O`、Enterで保存、`Ctrl + X` で終了。メモ帳は `Ctrl + S`。名前は `config.toml` で `.txt` を付けません。

空のファイルに貼り付け、`YOUR_MODEL_ID` だけを置き換えます：

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

既存設定はバックアップし、`model` と `model_provider` を最上部に置き、`[model_providers.nexusapi]` を一つだけ追加・更新します。[CC Switch](/ja/tools/cc-switch)も使えます。このファイルにキーは書きません。

## 3. APIキーを設定・保存

`YOUR_API_KEY` だけをキーの全文に置き換えます。Windowsは現在の端末とユーザー環境変数の両方に保存します。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
[Environment]::SetEnvironmentVariable("NEXUSAPI_API_KEY", $env:NEXUSAPI_API_KEY, "User")
```
</Tab>
<Tab title="macOS (Zsh)">
```bash
touch ~/.zshrc
nano ~/.zshrc
```

次の行をファイル末尾に追加します。同じ変数があれば重複させず置き換えます。保存後ターミナルを開き直してください。

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
<Tab title="Linux / WSL (Bash)">
```bash
nano ~/.bashrc
```

次の行をファイル末尾に追加します。同じ変数があれば重複させず置き換えます。保存後ターミナルを開き直してください。

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
</Tabs>

Macの標準Zsh、LinuxのBashの例です。別のシェルでは対応する起動ファイルを使い、不明ならサポートへ。キーをプロジェクトや画像に載せないでください。

## 4. 起動して確認

自分のプロジェクトのターミナルで実行：

```bash
codex
```

`/status` でモデルとNexusAPIプロバイダーを確認。「接続成功、とだけ返信し、ファイルを変更しないでください」と送り、返信と[利用履歴](https://nexusapi.link/usage-logs/common)を確認します。テストは少量のクレジットを使います。

## 5. よくあるつまずき

`Missing environment variable` は手順3へ。モデルがない場合は自分のグループのCodex対応名を再コピー。ほかは[エラー対処](/ja/faq/self-check)。

MacのDockから開いたエディターは変数を引き継がない場合があります。CLIを先に確認し、Codex拡張機能は設定済み端末から `code .` や `cursor .` で起動してください。プロジェクトにキーを保存しないでください。

公式インストール・設定：[Codex CLI](https://learn.chatgpt.com/docs/cli) · [Custom providers](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers)。
