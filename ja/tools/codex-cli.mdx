---
title: "Codex CLI の設定"
description: "Codex CLI をインストールし、NexusAPI をカスタム Responses Provider として設定します。"
---

コマンドと `config.toml` の項目は [OpenAI Codex 公式リポジトリ](https://github.com/openai/codex)と[カスタム Provider リファレンス](https://learn.chatgpt.com/docs/config-file/config-advanced)に基づきます。NexusAPI は URL、API Key、モデル ID を提供します。

## 1. インストール

公式の方法を一つ選びます。

### Windows PowerShell

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

### macOS、Linux、WSL

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

### Node.js がすでにある場合

```bash
npm install -g @openai/codex
codex --version
```

インストール後は新しいターミナルでバージョンを個別に確認できます。

```bash
codex --version
```

## 2. 対応する Key を作成する

**トークン管理 → トークンを追加**で、目的のモデルを含むグループを選びます。作成後に `/v1/models` と[対応マトリクス](/ja/developer/capability-matrix)を確認し、`supported_endpoint_types` に `openai-response` が含まれることを確認してください。

## 3. カスタム Provider を設定する

| OS | ファイル |
| --- | --- |
| Windows | `%USERPROFILE%\\.codex\\config.toml` |
| macOS / Linux | `~/.codex/config.toml` |

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

実際の Key はこのファイルに保存しないでください。この設定は `env_key` を通じて `NEXUSAPI_API_KEY` から Key を読み取ります。`auth.json` には Codex の認証状態が含まれる場合がありますが、NexusAPI Key を書き込む必要はありません。実際の Key を含むファイルを共有・コミットしないでください。

## 4. 環境変数を設定する

### Windows PowerShell

```powershell
setx NEXUSAPI_API_KEY "YOUR_NEXUSAPI_KEY"
```

### macOS、Linux、WSL

```bash
export NEXUSAPI_API_KEY='YOUR_NEXUSAPI_KEY'
```

`setx` 後は新しいターミナルが必要です。`export` は現在の Shell だけに有効です。長期保管には OS の資格情報または管理された環境変数を使い、リポジトリに書かないでください。

## 5. 確認

プロジェクトディレクトリで次を実行します。

```bash
cd your-project-folder
codex
```

最初はファイルを変更しないタスクを送ります。

```text
リポジトリの構成を説明し、ファイルは変更しないでください。
```

その後、コンソールの利用ログを確認します。失敗時は Key、グループ、モデル ID、新しいターミナルを確認し、Request ID を保存して[自己確認](/ja/faq/self-check)を行います。

## トラブルシューティング

1. `NEXUSAPI_API_KEY` を設定した後に開いた新しいターミナルを使用します。
2. Key が有効で、アカウントのクレジットがあり、グループに選択モデルがあることを確認します。
3. モデルマーケットプレイスまたは `/v1/models` から正確な ID をコピーし直します。
4. エラー本文と Request ID を保存して、[自己確認](/ja/faq/self-check)を確認します。

## VS Code / Cursor

拡張機能マーケットプレイスから [OpenAI 公開の Codex 拡張機能](https://marketplace.visualstudio.com/items?itemName=OpenAI.chatgpt)をインストールできます。ユーザーレベルの Codex 設定を共用するため、VS Code に旧式の `chatgpt.apiBase` や `chatgpt.config` を追加しないでください。
