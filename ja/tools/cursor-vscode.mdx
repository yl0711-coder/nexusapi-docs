---
title: "VS Code / CursorでClaude Codeを使う"
description: "拡張機能を入れ、ユーザー設定にキーを入力して確認します。"
---

**Claude Code拡張機能の設定です。Cursor内蔵AIチャットではありません。** [キーを作成](/ja/guide/api-key)し、[モデル広場](https://nexusapi.link/pricing)で同じグループからClaude Code対応モデル名をコピーします。

## 1. 拡張機能を入れる

`Ctrl + Shift + X`（Mac：`Command + Shift + X`）で拡張機能を開き、`Claude Code` を検索。発行元 **Anthropic** を確認して入れます。

![公式Marketplace：Claude Code for VS Code、発行元Anthropic](/images/nexusapi/claude-extension-marketplace.png)

公式Marketplaceの画像で名前と発行元を確認し、エディターの拡張機能一覧から同じものをインストールしてください。

## 2. ユーザー設定を開く

`Ctrl + Shift + P`（Mac：`Command + Shift + P`）から **Preferences: Open User Settings (JSON)** を選択。ワークスペース、既定値、プロジェクトの設定ではなくユーザー設定です。

## 3. NexusAPIを設定

`YOUR_API_KEY` を自分のキーの全文、`YOUR_MODEL_ID` をコピーしたモデル名に置き換えます。ほかは変えません。

```json
{
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "https://nexusapi.link"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

既存設定は先にバックアップし、`claudeCode` の項目だけを追加・変更します。ほかの設定を消さないでください。空の `{}` だけなら置き換えられます。

保存後、この接続に公式アカウントへのログインは不要です。キーを含む設定をプロジェクトに入れたり、他人と共有・同期しないでください。

![ユーザー設定例：必要なのは2つの `claudeCode` 項目だけです。下の外観・デモ用ウィンドウ設定はコピー不要です。仮の値は置き換えてください。接続成功を示す画像ではありません。](/images/nexusapi/vscode-user-settings-demo.png)

ユーザー設定例：必要なのは2つの `claudeCode` 項目だけです。下の外観・デモ用ウィンドウ設定はコピー不要です。仮の値は置き換えてください。接続成功を示す画像ではありません。

## 4. 再起動して確認

エディターを完全に終了して開き直し、Claude Codeで新規会話を作ります。「接続成功、とだけ返信し、ファイルを変更しないでください」と送り、完全な返信と[利用履歴](https://nexusapi.link/usage-logs/common)を確認。テストは少量のクレジットを使います。

公式ログインが出る場合はユーザー設定と置き換えた値を確認し、拡張機能を更新・再起動してください。VS Code は[公式拡張機能マーケット](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)からインストールできます。Cursorで見つからない場合は、ターミナルで[CLI手順](/ja/tools/claude-code)を使ってください。

公式リンク：[Claude Code プロジェクト](https://github.com/anthropics/claude-code) · [VS Code 拡張機能](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)。
