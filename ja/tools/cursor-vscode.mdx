---
title: "VS Code / Cursor で Claude Code を使う"
description: "既存の NexusAPI ユーザー設定で、公式 Claude Code 拡張を使用します。"
---

公式 Claude Code 拡張は、チャット、差分プレビュー、ファイル参照、権限確認を提供します。VS Code と Cursor は Claude Code のユーザー設定を共有します。

## 1. 公式拡張をインストールする

先に [Claude Code の設定](/ja/tools/claude-code)を完了してください。拡張機能画面で **Claude Code** を検索し、発行元が **Anthropic** であることを確認します。[公式 VS Code ガイド](https://code.claude.com/docs/en/vs-code)も参照できます。

<Warning>
類似する第三者拡張がある場合があります。Anthropic が公開したものだけを使い、第三者設定画面に Key を貼り付けないでください。
</Warning>

## 2. NexusAPI 設定を共有する

拡張は CLI と同じ `~/.claude/settings.json`（Windows はユーザープロファイルの対応パス）を読みます。VS Code / Cursor のワークスペース設定に Key を重複保存しないでください。

ログイン画面が出る場合は、設定で `Claude Code login` を検索し、表示されている場合は **Disable Login Prompt** を有効にしてからエディターを完全に再起動します。デスクトップ起動で環境を継承しない場合は、設定済みターミナルから `code .` を実行します。

## 3. 安全に確認する

サイドバーまたはコマンドパレットから Claude Code を開き、「現在のファイルの内容を説明し、変更しないでください」のような読み取り専用テストを送ります。成功後、NexusAPI の利用ログで対応リクエストを確認します。

問題時はエディター、拡張、Claude Code を更新し、完全に再起動してから試してください。エラーと Request ID を保存し、[自己確認](/ja/faq/self-check)へ進みます。完全な Key、ワークスペースの秘密、機密ソースコードを送らないでください。
