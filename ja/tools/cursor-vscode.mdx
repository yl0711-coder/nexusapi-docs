---
title: "VS CodeとカーソルでClaudeコードを使いましょう"
---

公式のClaude Code拡張機能は、グラフィカルダイアログ、コードの多様性プレビュー、ファイル参照、許可確認を提供します。
VS Codeはカーソルと似た構成になっています。

## 1. 拡張機能をインストールする

始める前に必ず確認してください:

- VS Codeのバージョンは1.98以上です。
- プレス [Claude Code チュートリアル](/ja/tools/claude-code) NexusAPIを設定してください。
- `~/.claude/settings.json` APIキーと基本URLは現在アクティブです。

拡張ストアを開く:

- macOS:`Cmd + Shift + X`
- Windows / Linux:`Ctrl + Shift + X`

検索 `Claude Code`出版社は確定しました **人格的** その後、再インストールしてください。 また、
[Claude Code 公式 VS Code ガイド](https://code.claude.com/docs/en/vs-code)
VS CodeまたはCursorのインストールポータルに入力してください。

<Warning>
**出版社を確認してください**

拡張ストアには似た名前のサードパーティの拡張機能があるかもしれません。 設置前に、拡張機能名が
`Claude Code`、出版社: `Anthropic`。
</Warning>
## 2. 拡張機能はNexusAPIを使うようにする

Claude Code拡張はCLIと共有されています `~/.claude/settings.json`。 通常なら、そこにいる必要はありません
VSコードまたはカーソル `settings.json` APIキーを繰り返し中央に入力します。

拡張機能にログインプロンプトが表示されている場合:

1. エディター設定を開きます。
2. 検索 `Claude Code login`。
3. 発足 **ログインプロンプトを無効にする**。
4. 完全に終了してエディタを再起動してください。

エディターがターミナル環境を読み取らない場合は、設定済みのターミナルからプロジェクトディレクトリに入り、実行できます:

```bash
code .
```

カーソルユーザーはカーソルを再起動したり、カーソルの統合端末で直接実行したりできます `claude`。

## 3. クロードコードを開く

インストール後は、以下のいずれかの方法で開くことができます。

- エディター右上にあるClaude Codeのスターアイコンをクリックしてください。
- 左側のアクティビティバーにあるClaude Codeアイコンをクリックしてください。
- コマンドパネルを開いて検索してください `Claude Code`。
- 右下のステータスバーをクリックしてください `Claude Code`。

右上にアイコンがない場合は、まずコードファイルを開いてください。 このアイコンはファイルを開く後にのみ表示されます。

![VS Codeにおける公式のClaude Code拡張インターフェースの例](/images/nexusapi/claude-code-vscode-official.jpg)

> インターフェースの例
> [Claude Code 公式 VS Code ドキュメント](https://code.claude.com/docs/en/vs-code)。
> 特定のボタン位置は拡張版で更新されることがあります。

## 4. 構成の検証

例えば、拡張機能内でシンプルなリクエストを送信します:

```text
请解释当前打开文件的作用，不要修改代码。
```

正常に戻る場合は、拡張機能がNexusAPIの設定を読み取ったことを意味します。 エラーに遭遇した場合は、以下を保持してください:

- エディターおよび拡張版
- クロードコード版
- 誤った原文
- リクエストID

それなら参照してください[自己確認](/ja/faq/self-check)。

## よくある質問

### 拡張された設置後は登場しませんでした

実行メニューのコマンドパネルを実行してください `Developer: Reload Window`またはエディターを完全に再起動する。

### CLIは動作しますが、拡張機能はできません

拡大の確認 **ログインプロンプトを無効にする** 有効化・チェック済み
`~/.claude/settings.json` 有効なJSONですか? 拡張機能とCLIは同じ構成を共有するべきです。

### カーソル拡張ストアが見つかりません

公式のClaude Code VS Codeガイドからカーソルインストールのエントリーにアクセスできます。 現在のカーソルが存在する場合
このバージョンはこの拡張機能をサポートしておらず、Cursorの統合端末で動作可能です `claude`。
