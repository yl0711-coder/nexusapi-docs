## 1. アプリを選ぶ

インストール済みなら対応する手順へ。未導入なら先にインストール手順を実行します。CC Switch は手動編集の代わりに設定を管理しますが、Claude Code や Codex CLI 自体の代わりにはなりません。

| 使うもの | 手順 |
| --- | --- |
| Claude Code | [設定手順](/ja/tools/claude-code) |
| Codex CLI | [設定手順](/ja/tools/codex-cli) |
| CC Switch | [設定手順](/ja/tools/cc-switch) |
| VS Code / Cursor | [設定手順](/ja/tools/cursor-vscode) |
| 自作プログラム | [設定手順](/ja/developer/code-examples) |

## 2. 始める前に

1. 自分の[APIキー](/ja/guide/api-key)を用意します。
2. 対応する手順からアドレスとモデル名をコピーします。他のアプリの設定を混ぜないでください。
3. 既存の設定を先にバックアップします。設定フォルダー全体を削除しないでください。

使っているアプリが一覧にありませんか？アプリ名と設定画面をサポートへ送ってください。キーは隠してください。

## 3. 対応するモデルを選ぶ

| 利用方法 | 選ぶもの |
| --- | --- |
| Claude Code またはそのエディター拡張 | この手順では、現在のグループで Claude Code 対応の Claude モデル |
| Codex CLI | Codex 対応が確認された GPT モデルとグループ。全 GPT グループが対応するわけではない |
| CC Switch | 内部で選んだ Claude Code または Codex に合わせて選ぶ |
| 自作プログラム | [推奨プロトコル](/ja/developer/model-protocols)でインターフェースを選ぶ |

正確な名前は[推奨プロトコル](/ja/developer/model-protocols)で確認できます。モデル広場に表示されても、キーで全アプリから使えるとは限りません。不明ならアプリ・モデル・グループをサポートへ。キー全文は送らないでください。
