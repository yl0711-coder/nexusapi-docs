---
title: "Claude Codeのインストールと設定"
description: "OS別に入れ、キーとモデルを設定して一言で確認します。"
---

NexusAPIキーを使う手順です。この接続にClaude公式アカウントへのログインは不要です。

## 1. 準備とインストール

[キーを作成](/ja/guide/api-key)し、[モデル広場](https://nexusapi.link/pricing)で同じグループからClaude Code / Messages対応モデル名をコピー。Windowsはスタートから `PowerShell`、Macは `Command + Space` からターミナルを開きます。

自分のOSのコマンドだけを使います。インストール済みなら飛ばしてください。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

ターミナルを開き直してバージョンを確認。コマンドが見つからなければ再度開き直し、解決しなければインストールのエラーをサポートへ送ってください。

```bash
claude --version
```

## 2. 設定ファイルを開く

OS別のコマンドでユーザー設定を開きます：

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

nanoは `Ctrl + O`、Enterで保存し、`Ctrl + X` で終了。Windowsメモ帳は `Ctrl + S`。名前は `settings.json` のままにし、`.json.txt` にしないでください。

## 3. キーとモデルを入力

空のファイルなら全文を貼り付け、`YOUR_API_KEY` をキーの全文、`YOUR_MODEL_ID` をコピーしたモデル名に置き換えます。引用符とカンマは残してください。

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

既存ファイルは先にバックアップし、`model` と `env` のみを追加・変更します。ほかを消さず、不安なら [CC Switch](/ja/tools/cc-switch) を使ってください。キーをプロジェクトや画像に載せないでください。

## 4. 起動して確認

保存後ターミナルを開き直し、自分のプロジェクトで実行：

```bash
claude
```

`/status` で `Anthropic base URL` が `https://nexusapi.link`、認証元が `ANTHROPIC_AUTH_TOKEN`、モデル名が設定どおりか確認します。

「接続成功、とだけ返信し、ファイルを変更しないでください」と送り、完全な返信と[利用履歴](https://nexusapi.link/usage-logs/common)を確認。テストは少量のクレジットを使います。

`/login` やキーエラーはユーザー設定の場所と置き換えを確認して再起動。[エラー対処](/ja/faq/self-check)も参照。`.claude` 全体は削除しないでください。

公式プロジェクト：[Claude Code](https://github.com/anthropics/claude-code)。
