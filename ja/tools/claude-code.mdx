---
title: "Claude Code の設定"
description: "Claude Code をインストールし、Anthropic ネイティブ設定で NexusAPI に接続します。"
---

Claude Code は Anthropic のネイティブ Messages 設定を使います。NexusAPI の Base URL は `https://nexusapi.link` で、**`/v1` は追加しません**。

## 1. Claude Code をインストールする

公式インストーラーを使ってください。

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell
irm https://claude.ai/install.ps1 | iex
```

Windows では `winget install Anthropic.ClaudeCode`、macOS では `brew install --cask claude-code` も使えます。確認コマンド：

```bash
claude --version
claude doctor
```

## 2. NexusAPI Key を作成する

コンソールの **トークン管理 → トークンを追加** で、対象 Claude モデルを含むグループを選び、上限を設定します。モデル名だけで判断せず、マーケットプレイスまたは[対応マトリクス](/ja/developer/capability-matrix)で確認してください。

## 3. ユーザー設定を作成する

| OS | パス |
| --- | --- |
| macOS / Linux / WSL | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\\.claude\\settings.json` |

macOS、Linux、WSL、Git Bash では以下を実行します。

```bash
mkdir -p ~/.claude
touch ~/.claude/settings.json
```

既存設定を上書きせず、次の `env` を統合します。

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_NEXUSAPI_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

ユーザーディレクトリに保存し、プロジェクトリポジトリには置かないでください。

## 4. 起動と確認

新しいターミナルで `claude` を実行し、`/status` で **Anthropic base URL** が `https://nexusapi.link` であることを確認してから、短い質問を送ります。

## よくある問題

### `Invalid API Key · Please run /login`

二つの環境値、Key の有効状態、ターミナルの再起動を確認します。Claude の内部ログイン状態ファイルを直接変更しないでください。

### `fetch failed`

1. まず通常の短い質問を送ります。成功する場合は、WebFetch など別のネットワーク機能の問題の可能性があります。
2. すべてのモデル呼び出しが失敗する場合は、`claude doctor` と `/status` で Base URL を確認します。
3. DNS、ファイアウォール、社内ネットワーク、信頼済みプロキシが `nexusapi.link` を遮断していないか確認します。
4. 新しいターミナルで一度だけ試します。継続する場合は、バージョン、doctor 出力、エラー全文、Request ID を保存し、[自己確認](/ja/faq/self-check)へ進みます。

### `offline` と表示される

補助機能が別サービスを確認している場合があります。`/status` と短いモデルリクエストで実際のゲートウェイ呼び出しを確認してください。
