以下は OpenAI Chat Completions の例です。先に[対応マトリクス](/ja/developer/capability-matrix)でプロトコルを確認し、モデルマーケットプレイスまたは `/v1/models` から現在の Key で使える ID をコピーしてください。

## 基本設定

- Base URL: `https://nexusapi.link/v1`
- API Key: [NexusAPI コンソール](https://nexusapi.link)のトークン管理で作成
- Model ID: 現在の Key で利用可能な正確な ID

## Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link/v1",
)

response = client.chat.completions.create(
    model="YOUR_MODEL_ID",
    messages=[{"role": "user", "content": "簡単に自己紹介してください。"}],
)

print(response.choices[0].message.content)
```

## JavaScript

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.NEXUSAPI_API_KEY,
  baseURL: "https://nexusapi.link/v1",
});

const response = await client.chat.completions.create({
  model: "YOUR_MODEL_ID",
  messages: [{ role: "user", content: "簡単に自己紹介してください。" }],
});

console.log(response.choices[0].message.content);
```

## cURL

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"接続テスト"}]}'
```

実際の Key をソースコードに書いたりリポジトリにコミットしたりしないでください。画像生成は別 endpoint です。[画像モデルガイド](/ja/guide/image-generation)を参照してください。
