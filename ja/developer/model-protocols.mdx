下の一覧で正確なモデル名を探し、推奨プロトコルを選んでください。大文字小文字、日付、接尾辞は変更しないでください。

以下は現在選択できるモデルと推奨プロトコルです。利用可能な範囲は API キーのグループによって異なります。

## プロトコルの選び方

| 使用するモデル | 最初に選ぶプロトコル | リクエストパス |
| --- | --- | --- |
| Claude | Anthropic Messages | `/v1/messages` |
| Responses 対応グループの GPT | Responses | `/v1/responses` |
| Chat Completions のみ確認済みの GPT グループ、DeepSeek、GLM、Kimi、Qwen、Grok | Chat Completions | `/v1/chat/completions` |

<Warning>
モデルが API キーのグループで利用できることを確認してください。クライアントが一つのプロトコルにしか対応していない場合は、そのプロトコルに対応するモデルとグループを選んでください。
</Warning>

`gpt-5.6x` グループでは、まず Chat Completions を選択してください。Responses が必要な場合は、事前にサポートへ確認してください。

## クライアント設定と確認

1. Claude Code は[設定ガイド](/ja/tools/claude-code)に従い、Base URL に `https://nexusapi.link` を指定します。
2. Codex CLI は[設定ガイド](/ja/tools/codex-cli)に従って Responses を使用します。モデルとグループの両方が対応している必要があります。
3. Chat Completions のプログラムは[コード例](/ja/developer/code-examples)を参照し、OpenAI SDK の Base URL を `https://nexusapi.link/v1` にします。

モデルやプロトコルが見つからない場合は[機能一覧](/ja/developer/capability-matrix)を確認し、モデル名、キーのグループ、クライアント、Request ID をサポートへ送ってください。キー全体は送らないでください。
