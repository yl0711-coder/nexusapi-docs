もっとも近い症状を選んでください。エラーが出たら、設定変更や再試行の前にエラー全文と Request ID を保存します。

## 接続と設定

- **どこから始める？** [5 分で始める](/ja/guide/quick-start)を参照してください。
- **Base URL はどれ？** クライアントごとに異なります。[接続方法の概要](/ja/guide/integration-overview)を確認してください。
- **なぜ 404？** `/v1/v1/...` になっていないか、クライアントがパスを自動追加するかを確認します。
- **新しい API Key が使えない？** Key の状態、残高、グループ、モデル ID、`Authorization: Bearer` 形式を確認します。

## モデルと料金

- **グループでモデルを使えるか？** [モデルマーケットプレイス](https://nexusapi.link/pricing)でグループを絞るか、Key で `/v1/models` を呼びます。
- **1 回の料金は？** コンソールログと[利用量と請求](/ja/billing/usage-and-billing)を確認します。
- **失敗したリクエストも課金される？** 上流処理やクライアント再送の状況次第です。Request ID で照合してください。
- **残高があるのに拒否される？** Key の上限、有効期限、グループも確認します。

## API とツールのエラー

- **400、401、429、500、502、503、504、524 とは？** [よくある API エラー](/ja/faq/common-errors)を参照してください。
- **長い会話が続けられない？** エラーを保存して新しい会話で確認し、同じ内容を連続再送しないでください。
- **画像生成がタイムアウト？** 同じジョブをすぐ送らず、Request ID を保存して[画像モデルガイド](/ja/guide/image-generation)を確認します。
- **Claude Code で `fetch failed`？** まず短い通常会話を試し、[Claude Code ガイド](/ja/tools/claude-code)に従います。

## サポートへの連絡前

[自己確認](/ja/faq/self-check)を行い、Request ID、時刻とタイムゾーン、クライアントとバージョン、モデル、endpoint、エラー全文、再現性をまとめて送ってください。完全な Key、パスワード、機密コンテンツは送らないでください。
