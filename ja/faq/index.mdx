該当する質問の回答どおりに操作してください。不明な場合は、キー全体を隠したエラー画像をサポートに送ってください。

## 接続と設定

- **どこから始める？**<br />
  [クイックスタート](/ja/guide/quick-start)の最初の手順から進めます。

- **Base URL はどれ？**<br />
  [利用するソフトの手順](/ja/tools)からアドレスをコピーします。`/v1` を自分で足さないでください。

- **なぜ 404？**<br />
  [利用するソフトの手順](/ja/tools)からアドレスをコピーし直します。続く場合は画像をサポートへ送ります。

- **`status_code=500, not implemented` が出るのは？**<br />
  繰り返し再試行せず、ソフト名・モデル・グループ・エラーを送り、その組み合わせで使えるかサポートに確認します。

- **新しい APIキーが使えない？**<br />
  [APIキー](https://nexusapi.link/keys)からキー全体をコピーし直し、貼り付けてソフトを再起動します。伏せ字はコピーしません。

## モデルと料金

- **グループでモデルを使えるか？**<br />
  [モデル広場](https://nexusapi.link/pricing)でキーと同じグループを選び、モデル名をコピーします。見つからなければサポートへ。

- **1 回の料金は？**<br />
  [利用ログ](https://nexusapi.link/usage-logs/common)で該当記録の料金を見ます。人民元での費用は[割引の例](/ja/billing/multipliers-and-discounts)を参照してください。

- **失敗したリクエストも課金される？**<br />
  エラー表示だけでは判断できません。該当ログの料金を確認し、不明なら画像をサポートへ送ります。

- **残高があるのに拒否される？**<br />
  残高、キーの上限・有効期限を確認します。不明なまま追加チャージせず、サポートへ相談します。

## API とツールのエラー

- **400、401、429、500、502、503、504、524 の意味は？**<br />
  [エラー対処](/ja/faq/common-errors)で同じメッセージを探し、手順に従います。

- **長い会話を続けられなくなったら？**<br />
  重要な内容を保存し、新しい会話で短いメッセージを一度だけ試します。テストはクレジットを消費する場合があります。

- **エラーの後で成功したように見えるのは？**<br />
  ソフトで完全な応答を受け取れたか確認し、利用ログと料金を照合します。不明ならサポートへ。

## サポートに送る情報

- ソフト名。
- 発生時刻、モデル、グループ。
- エラー全文または画像。Request ID があれば添付。

**不明な項目は空欄で構いません。原因を自分で判断する必要はありません。パスワード、認証コード、キー全体は送らないでください。**
