---
title: "Content block not found"
description: "長い会話、ツール呼び出し、ストリームで起きる不完全なコンテンツブロックのエラーを解決します。"
---

`API Error: Content block not found` は、クライアントが期待したコンテンツブロックを取得できなかったことを示します。長い会話の再開、ツール呼び出し、ストリームの中断後に発生しやすいエラーです。

## 推奨手順

1. 新しい会話を作り、必要なコンテキストだけを渡します。
2. Claude Code、Codex、Cursor、関連拡張を更新します。
3. 必須でないツールや実験的機能を一時的に無効にします。
4. 1 回の入力と持ち越す履歴を短くします。
5. 同じモデルに非常に短い質問を送ります。

## サポートへ連絡する場面

新しい会話と短いリクエストでも継続する、複数モデルで同時に起きる、または異常請求を伴う場合は、Request ID、時刻とタイムゾーン、ツールとバージョン、モデル、エラーまたは画面、元の会話だけかすべての会話かを送ってください。

完全な API Key や機密会話の全文は送らないでください。
