---
title: "エラーが出たときの対処"
description: "エラーを保存し、設定を確認して、解決しなければサポートへ。"
---

**まず画像を保存します。以下を確認するか、不明なら直接サポートへ連絡してください。**

## 1. エラーを保存

ソフト名、時刻、モデル、グループ、エラー画像を保存します。Request ID があればコピーし、不明な内容は推測しません。キー全体、パスワード、業務の機密情報は隠してください。

## 2. メッセージに沿って確認

| 表示 | 操作 |
| --- | --- |
| キーエラー / 401 | キー全体をコピーし直し、ソフトを再起動 |
| 403 | モデルとグループをサポートに確認 |
| 404 | [ソフトの手順](/ja/tools)からアドレスをコピーし直す |
| 400 / not implemented | そのソフトでモデルを使えるかサポートに確認 |
| 429 / 同時実行の上限 | 実行中の処理を待ち、同時タスクを減らして一度試す |
| 500 / 502 / 503 / タイムアウト | 10～30秒待って一度だけ試し、続くならサポートへ |
| no available channel | グループにモデルがあるか確認。不明なら追加チャージせずサポートへ |
| 残高不足 | 残高、キー上限、有効期限を確認 |

## 3. 短いメッセージを一度だけ試す

重要な内容を保存して新しい会話を開き、「こんにちはとだけ返して」と送ります。完全な応答があれば新しい会話を使い、失敗ならサポートへ。**テストでクレジットを消費する場合があります。連続再試行や設定フォルダー全体の削除はしないでください。**

## 4. これをコピーしてサポートへ

```text
ソフト名：
発生時刻：
モデルとグループ：
エラー全文または画像：
Request ID（あれば）：
```

不明な項目は空欄で構いません。キー全体、パスワード、認証コードは送らないでください。

<span id="setup-not-applied"></span>

## 設定が反映されない

| 症状 | 最初に確認すること |
| --- | --- |
| 公式サービスのログインを求められる | アプリの手順でユーザー設定と仮の値の置換を確認し、完全終了して再起動。NexusAPI キーを公式アカウントのパスワードにしない |
| CC Switch で保存したが元のサービスを使う | 対応アプリで NexusAPI を切り替え・有効化して再起動。保存だけでは有効にならない |
| モデル変更が反映されない | 有効な設定のモデル名を確認し、再起動して新しい会話へ。NexusAPI 履歴にない場合は本サービスを通ったか先に確認 |
| ターミナルでは動くがエディターでは動かない | Claude Code 拡張と内蔵 AI を区別。[拡張手順](/ja/tools/cursor-vscode)か[Codex 手順](/ja/tools/codex-cli)の起動環境を確認。キーをプロジェクトに保存しない |
| 残高があるのに不足と出る | キー上限・期限・グループを確認。プラン利用時は有効期間・残量・対象グループも確認してから追加チャージを判断 |

短いテストは1回だけ。解決しなければ上の情報をサポート用グループか開設担当者へ送ります。キー入りの設定ファイルは送らないでください。
