先在下面找到模型名称，再选择对应协议。模型名称保留大小写、日期和后缀，不要自行改写。

下表列出当前可选模型及推荐协议。实际可用范围以你的 API Key 分组为准。

## 协议怎么选

| 你使用的模型 | 先选协议 | 请求路径 |
| --- | --- | --- |
| Claude | Anthropic Messages | `/v1/messages` |
| GPT 且所在分组支持 Responses | Responses | `/v1/responses` |
| GPT 仅确认 Chat Completions 的分组；DeepSeek、GLM、Kimi、Qwen、Grok | Chat Completions | `/v1/chat/completions` |

<Warning>
先确认模型在你的 API Key 分组中可用。软件只支持一种协议时，请选择同时支持该协议的模型和分组。
</Warning>

使用 `gpt-5.6x` 分组时，先选择 Chat Completions；如需 Responses，请先联系客服确认。

## 软件配置和核对

1. 使用 Claude Code，按[配置教程](/tools/claude-code)填写，Base URL 用 `https://nexusapi.link`。
2. 使用 Codex CLI，按[配置教程](/tools/codex-cli)选择 Responses；仅使用支持该协议的模型和分组。
3. 使用 Chat Completions 程序，按[代码示例](/developer/code-examples)填写，OpenAI SDK 的 Base URL 用 `https://nexusapi.link/v1`。

找不到模型或所需协议时，先查看[模型与接口能力](/developer/capability-matrix)，再把模型名、Key 分组、所用软件及 Request ID 发给客服。不要发送完整 Key。
