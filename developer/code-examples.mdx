NexusAPI 支持主流 OpenAI SDK 的兼容调用方式。以下示例使用 Chat Completions；调用前请在[接口与模型能力矩阵](/developer/capability-matrix)确认模型与协议匹配。

## 核心接入参数

- **接口地址（Base URL）**：`https://nexusapi.link/v1`
- **API Key**：在 [NexusAPI 控制台](https://nexusapi.link)创建；通常以 `sk-` 开头。
- **模型 ID**：使用当前 API Key 可见的准确模型 ID。

请求时，将 API Key 放入 HTTP 请求头：`Authorization: Bearer YOUR_API_KEY`。

## Python

将现有客户端的 `api_key` 和 `base_url` 替换为 NexusAPI 参数即可。

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link/v1"
)

response = client.chat.completions.create(
    model="YOUR_MODEL_ID",
    messages=[
        {"role": "user", "content": "你好，请自我介绍。"}
    ]
)

print(response.choices[0].message.content)
```

## JavaScript

```js
import OpenAI from "openai";

const openai = new OpenAI({
    apiKey: "YOUR_API_KEY",
    baseURL: "https://nexusapi.link/v1"
});

async function main() {
    const response = await openai.chat.completions.create({
        model: "YOUR_MODEL_ID",
        messages: [{ role: "user", content: "你好，请自我介绍。" }],
    });
    console.log(response.choices[0].message.content);
}
main();
```

## cURL

```bash
curl "https://nexusapi.link/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {
        "role": "user",
        "content": "测试一下 API 是否连通"
      }
    ]
  }'
```

将 `YOUR_MODEL_ID` 替换为模型广场中、当前 API Key 分组可见的准确模型 ID。本页示例适用于 `supported_endpoint_types` 包含 `openai` 的模型；如需使用 Responses，请仅在其中包含 `openai-response` 时改用 [Responses 接口与 Codex](/developer/responses)。请先阅读[接入方式总览](/guide/integration-overview)。
