找到你遇到的问题，照着答案操作。不知道怎么处理，直接把报错截图发给客服，记得遮盖完整 Key。

## 接入与配置

- **第一次使用，从哪里开始？**<br />
  打开[快速开始](/guide/quick-start)，从第 1 步操作。

- **Base URL 应该填哪个？**<br />
  打开[软件教程](/tools)，复制你所用软件的地址，不要自己加 `/v1`。

- **为什么出现 404？**<br />
  重新复制[对应软件教程](/tools)里的地址，替换原地址。仍报错就把截图发给客服。

- **出现 `status_code=500, not implemented`？**<br />
  先不要反复重试。把软件名称、模型、分组和报错发给客服，确认这个模型能否在该软件中使用。

- **API Key 创建后不能使用？**<br />
  在 [API 密钥](https://nexusapi.link/keys)页重新复制完整 Key，粘贴后重启软件；不要抄带星号的文字。

## 模型、分组与费用

- **怎么确认某个分组能否使用目标模型？**<br />
  在[模型广场](https://nexusapi.link/pricing)选中 Key 对应的分组，再复制模型名称。找不到就问客服。

- **一次请求消耗了多少？**<br />
  打开[使用日志](https://nexusapi.link/usage-logs/common)，找到这次记录，看“费用”。人民币成本见[折扣说明](/billing/multipliers-and-discounts)。

- **失败请求是否扣费？**<br />
  不能只凭报错判断。打开使用日志看对应记录的“费用”；有疑问，把日志截图发给客服核对。

- **为什么余额正常却提示额度不足？**<br />
  先看钱包余额，再看 API 密钥是否到期、额度是否用完。仍提示不足，就把报错发给客服，不要急着重复充值。

## 调用错误

- **400、401、429、500、502、503、504、524 是什么？**<br />
  打开[报错处理](/faq/common-errors)，找到同样的报错，按下面的步骤做。

- **长会话突然无法继续？**<br />
  先保存重要内容，再新建一个对话，只发一句简短的话测试。不要连续重试；测试可能消耗额度。

- **错误后任务又成功了？**<br />
  看软件是否收到了完整回复，再到使用日志核对记录和费用。不确定就把相关记录发给客服。

## 找客服时发什么

- 软件名称。
- 出问题的时间、模型和分组。
- 报错原文或截图；有 Request ID（请求编号）就一起发。

**不知道的信息留空即可，不用自己判断原因。不要发送密码、验证码或完整 Key。**
