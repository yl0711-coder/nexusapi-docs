先选择最接近的现象。遇到调用错误时，请优先保存 Request ID 和完整错误原文。

## 接入与配置

- **第一次使用，从哪里开始？**<br />
  阅读[5 分钟快速开始](/guide/quick-start)。

- **Base URL 应该填哪个？**<br />
  不同客户端可能不同，请查看[接入方式总览](/guide/integration-overview)。

- **为什么出现 404？**<br />
  404 通常是地址或接口路径错误。检查是否形成 `/v1/v1/...`，以及客户端是否自动拼接请求路径；模型不可用更常表现为 `no available channel` / `503`。

- **出现 `status_code=500, not implemented`？**<br />
  若模型的 `supported_endpoint_types` 未包含当前请求所需协议，这是协议不兼容，不要重试；请改用模型标明支持的接口，详见[常见错误说明](/faq/common-errors)。

- **API Key 创建后不能使用？**<br />
  检查 Key 状态、额度、分组、模型 ID 和 `Authorization: Bearer` 格式。

## 模型、分组与费用

- **怎么确认某个分组能否使用目标模型？**<br />
  在[模型广场](https://nexusapi.link/pricing)按分组筛选并复制准确模型 ID。

- **一次请求消耗了多少？**<br />
  在控制台使用日志中查看输入、输出、缓存和花费。字段说明见[用量与日志说明](/billing/usage-and-billing)。

- **失败请求是否扣费？**<br />
  没有生成有效内容的错误记录通常为 0；存在中断或后续尝试时，需要按 Request ID 核对。

- **为什么余额正常却提示额度不足？**<br />
  同时检查账号余额、API Key 额度和分组；持续出现时提交 Request ID。

## 调用错误

- **400、401、429、500、502、503、504、524 是什么？**<br />
  查看[API 调用常见问题](/faq/common-errors)。

- **长会话突然无法继续？**<br />
  保存错误原文，新建会话验证；不要高频重复提交同一请求。

- **图片生成很慢或超时？**<br />
  图片请求为同步请求，不要立即重复提交同一任务；先保存 Request ID，并查看[图片模型使用说明](/guide/image-generation)。

- **错误后任务又成功了？**<br />
  不要默认认为平台会自动重试；请核对客户端是否发起了新请求及对应 Request ID。

## 快速获得帮助

如果无法确定问题类型，按[问题自查](/faq/self-check)完成最小验证，并一次性提交：

- Request ID
- 发生时间和时区
- 客户端及版本
- 模型和请求接口
- 完整错误原文
- 问题是偶发还是持续发生

请勿提交完整 API Key、密码或隐私数据。
