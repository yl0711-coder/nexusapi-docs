**先截图，再按下面检查。不会处理就直接联系客服，不用先弄懂报错原因。**

## 1. 留下报错

记下软件名称、发生时间、模型和分组，保存报错截图。有 Request ID（请求编号）就一起复制；找不到不用猜。

截图请遮盖完整 Key、密码和业务隐私。

## 2. 按报错检查

| 看到什么 | 怎么做 |
| --- | --- |
| Key 错误 / 401 | 在 [API 密钥](https://nexusapi.link/keys)页重新复制完整 Key，粘贴后重启软件 |
| 403 / 无权限 | 把模型和 Key 的分组发给客服确认，不要反复换 Key |
| 404 / 地址错误 | 重新复制[对应软件教程](/tools)里的地址，不要自己加路径 |
| 400 / not implemented | 把软件、模型和报错发给客服，确认这个模型能否在该软件中使用 |
| 429 / 并发超限 | 等正在进行的请求结束，暂停其他同时调用的程序，再试一次 |
| 500 / 502 / 503 / 超时 | 保存报错，等 10～30 秒后只试一次；仍失败就联系客服 |
| no available channel | 在模型广场确认当前分组有这个模型；仍报错就联系客服，不要因此重复充值 |
| 余额 / 额度不足 | 查看钱包余额、Key 额度和到期时间；不清楚就先问客服 |

## 3. 只做一次简短测试

先保存重要内容，再新建一个对话，发送“请回复：你好”。能收到完整回复，就先用新对话；仍失败，把报错发给客服。

**测试可能消耗额度。不要连续重试，也不要删除整个软件配置目录。**

## 4. 复制这段发给客服

```text
软件名称：
发生时间：
模型和分组：
报错原文或截图：
请求编号（有就填）：
```

不知道的留空即可。不要发送完整 Key、密码或验证码。

## 配置没有生效

| 看到的现象 | 先做什么 |
| --- | --- |
| 仍要求官方登录 | 回对应软件教程确认配置保存到了用户设置、占位符已替换，再完全退出并重开；不要把 NexusAPI Key 填到官方账号密码处 |
| CC Switch 已保存，但仍走原供应商 | 在对应应用下确认 NexusAPI 配置已“切换／启用”，再重启工具；保存不等于启用 |
| 改模型后没有变化 | 核对当前启用配置里的模型名，重启并新建对话，再查 NexusAPI 使用日志；没有记录时，先确认这次请求是否走了本平台 |
| 终端能用，编辑器不能用 | 区分 Claude Code 扩展和编辑器自带 AI。Claude 扩展按[扩展教程](/tools/cursor-vscode)配置；Codex 扩展按[Codex 教程](/tools/codex-cli)检查启动环境，不要把 Key 写进项目 |
| 钱包有余额，却提示额度不足 | 同时检查 Key 自身额度、到期时间和分组；使用套餐时再检查套餐有效期、余量和适用分组，不要先重复充值 |

只做一次简短验证，仍失败就把上面的报障信息发到原服务群；没有服务群，联系为你开通账号的对接人。不要直接发送含 Key 的配置文件。
