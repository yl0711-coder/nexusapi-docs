---
title: "Content block not found"
description: "NexusAPI：Content block not found"
---

`API Error: Content block not found` 表示客户端没有找到预期的内容片段，常见于长会话恢复、工具调用或响应没有完整结束。

## 建议处理步骤

1. 新建会话后重新发送必要内容。
2. 更新 Claude Code、Codex、Cursor 或相关插件。
3. 暂时关闭非必要的工具调用和实验性功能。
4. 缩短一次性输入的内容，避免携带过长历史记录。
5. 用一个简单问题测试同一模型能否正常回复。

## 什么时候需要联系我们？

出现以下情况时，请提交问题：

- 新建会话后仍然重复出现。
- 简单问题也无法完成。
- 多个模型同时出现相同错误。
- 错误发生后出现异常消费。

请提供：

- Request ID。
- 报错时间和时区。
- 使用的工具及版本。
- 模型名称。
- 错误原文或截图。
- 是所有会话都失败，还是只有原会话失败。

请不要发送完整 API Key 或包含隐私信息的完整会话内容。
