---
title: "在 VS Code 或 Cursor 使用 Claude Code"
description: "以既有的 NexusAPI 使用者設定，在官方 Claude Code 編輯器擴充套件中工作。"
---

官方 Claude Code 擴充套件提供聊天、差異預覽、檔案參考和權限提示；VS Code 和 Cursor 共用 Claude Code 的使用者層級設定。

## 1. 安裝官方擴充套件

請先確認 VS Code 為 1.94 或更新版本，並完成 [Claude Code 設定](/zh-TW/tools/claude-code)。在編輯器擴充套件搜尋 **Claude Code**，並確認發佈者為 **Anthropic**；也可查看[官方 VS Code 教學](https://code.claude.com/docs/en/vs-code)。

<Warning>
搜尋結果可能有第三方同名擴充套件。只安裝 Anthropic 發佈的版本，且不要把 API Key 貼入第三方設定面板。
</Warning>

## 2. 共用 NexusAPI 設定

擴充套件會讀取與 CLI 相同的 `~/.claude/settings.json`（Windows 為使用者目錄對應路徑）。不要在 VS Code 或 Cursor 的工作區設定中重複保存 Key。

若仍顯示登入提示：

1. 開啟編輯器設定並搜尋 `Claude Code login`。
2. 啟用 **Disable Login Prompt**。
3. 完全重啟編輯器。

## 3. 安全驗證

從側欄、命令面板或狀態列開啟 Claude Code，送出「說明目前檔案做什麼，不要修改檔案」等唯讀測試。成功後在 NexusAPI 使用紀錄確認對應請求。

排查時請更新編輯器、擴充套件和 Claude Code，於整個編輯器重啟後再測試，並保存錯誤與 Request ID 後依[問題自查](/zh-TW/faq/self-check)處理。請勿傳送完整 Key、工作區密鑰或私密原始碼。
