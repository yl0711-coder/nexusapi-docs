title: "在 VS Code / Cursor 使用 Claude Code"
description: "安裝正確擴充套件，在使用者設定填入 Key 和位址，再測試。"
---

**本頁設定 Claude Code 擴充套件，不是 Cursor 內建 AI 聊天。** 先[建立 Key](/zh-TW/guide/api-key)，到[模型廣場](https://nexusapi.link/pricing)選同一分組，複製支援 Claude Code 的模型名稱。

## 1. 安裝擴充套件

Windows / Linux 按 `Ctrl + Shift + X`；Mac 按 `Command + Shift + X`。搜尋 `Claude Code`，確認發行者是 **Anthropic**，再安裝。

![官方擴充套件市場：Claude Code for VS Code，發佈者 Anthropic](/images/nexusapi/claude-extension-marketplace.png)

此圖用來核對官方名稱與發佈者，再到編輯器擴充套件商店找到同一項安裝。

## 2. 開啟使用者設定

按 `Ctrl + Shift + P`（Mac 用 `Command + Shift + P`），選 **Preferences: Open User Settings (JSON)**。必須是使用者設定，不是工作區、預設或專案的 `.vscode/settings.json`。

## 3. 填入 NexusAPI 設定

把 `YOUR_API_KEY` 換成自己的完整 Key，`YOUR_MODEL_ID` 換成模型名稱，其他不變。

```json
{
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "https://nexusapi.link"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

已有設定先備份，只合併上方的 `claudeCode` 設定，不要清空原檔。若只有空的 `{}`，可直接替換。

儲存後不必登入官方帳號。設定含個人 Key，不要放入專案、共用或同步給別人。

![使用者設定示例：只需設定兩個 `claudeCode` 項目，下方外觀與示範視窗設定不用複製。請替換佔位符；此圖不表示連線成功。](/images/nexusapi/vscode-user-settings-demo.png)

使用者設定示例：只需設定兩個 `claudeCode` 項目，下方外觀與示範視窗設定不用複製。請替換佔位符；此圖不表示連線成功。

## 4. 重啟並測試

完全關閉並重新開啟編輯器，點 Claude Code 圖示建立對話，傳送「請只回覆：連線成功，不要修改檔案」。收到完整回覆後，在[使用日誌](https://nexusapi.link/usage-logs/common)確認紀錄。測試會消耗少量額度。

仍出現官方登入？確認設定寫在使用者設定、預留文字已替換，更新擴充套件後重啟。VS Code 可從[官方擴充套件市集](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)安裝；Cursor 找不到時，在編輯器終端機按 [Claude Code 教學](/zh-TW/tools/claude-code)使用。

官方入口：[Claude Code 專案](https://github.com/anthropics/claude-code) · [VS Code 擴充套件市集](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)。
