本頁設定 Codex CLI。使用 NexusAPI Key，不要將 ChatGPT 密碼當作 Key。

## 1. 安裝 Codex

Windows 開 PowerShell；Mac 開終端機。只執行自己系統的安裝指令，已安裝可跳過。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Tab>
</Tabs>

安裝後重開終端機，執行下方指令。看到版本號再繼續；找不到指令先處理安裝問題。

```bash
codex --version
```

## 2. 儲存位址和模型

先[建立 Key](/zh-TW/guide/api-key)，在[模型廣場](https://nexusapi.link/pricing)選同一分組，複製支援 Codex / Responses 的模型名。再按系統開啟個人設定：

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex" | Out-Null
notepad "$env:USERPROFILE\.codex\config.toml"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```
</Tab>
</Tabs>

nano 用 `Ctrl + O`、Enter 儲存，`Ctrl + X` 離開。Windows 記事本用 `Ctrl + S`，檔名是 `config.toml`，不能加 `.txt`。

空檔案貼下方內容，只替換 `YOUR_MODEL_ID` 為模型名稱：

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

已有設定先備份；`model`、`model_provider` 放最上方，再新增或更新 `[model_providers.nexusapi]`，不要重複同名區段。可改用 [CC Switch](/zh-TW/tools/cc-switch)。本檔不填 Key。

## 3. 設定並儲存 API Key

只將 `YOUR_API_KEY` 換成自己的完整 Key。Windows 指令同時設定目前終端機和使用者環境變數。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
[Environment]::SetEnvironmentVariable("NEXUSAPI_API_KEY", $env:NEXUSAPI_API_KEY, "User")
```
</Tab>
<Tab title="macOS (Zsh)">
```bash
touch ~/.zshrc
nano ~/.zshrc
```

在檔案末尾加入下一行；已有同名變數就替換，不要重複。儲存後重開終端機。

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
<Tab title="Linux / WSL (Bash)">
```bash
nano ~/.bashrc
```

在檔案末尾加入下一行；已有同名變數就替換，不要重複。儲存後重開終端機。

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
</Tabs>

Mac 以預設 Zsh、Linux 以 Bash 示範。其他 Shell 請放對應啟動檔，不確定問客服。Key 不要放進專案或截圖。

## 4. 啟動驗證

在自己的專案目錄開終端機，執行：

```bash
codex
```

輸入 `/status`，確認模型和 NexusAPI Provider。再傳「請只回覆：連線成功，不要修改檔案」。收到完整回覆並在[使用日誌](https://nexusapi.link/usage-logs/common)看到紀錄即完成。測試消耗少量額度。

## 5. 常見卡點

`Missing environment variable` 回第 3 步；模型不可用就重新複製目前分組支援 Codex 的名稱。其他見[問題自查](/zh-TW/faq/self-check)。

Mac 從 Dock 開的編輯器不一定讀到終端機變數。先用 CLI 驗證；需用 Codex 擴充套件時，在已設定終端機用 `code .` 或 `cursor .` 啟動。不要把 Key 放進專案設定。

官方安裝與設定：[Codex CLI](https://learn.chatgpt.com/docs/cli) · [Custom providers](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers)。
