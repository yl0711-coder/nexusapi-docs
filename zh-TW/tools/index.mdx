不同的工具服務不同的工作方式。 請根據你的用途選擇，然後進入相應教學，以避免地址和設定檔混淆。

## 快速選擇

| 你的需求 | 推薦入選 | 誰適合你就去哪 |
| --- | --- | --- |
| 讓 AI 在終端機中處理程式碼和專案任務 | [克勞德密碼](/zh-TW/tools/claude-code) | 使用 Claude 工作流程的開發者 |
| 使用 Codex 終端代理 | [Codex CLI](/zh-TW/tools/codex-cli) | 開發者使用 Responses / Codex 工作流程 |
| 在多個供應商配置間切換 | [CC 交換器](/zh-TW/tools/cc-switch) | 同時管理多個 CLI 設定的使用者 |
| 在 VS Code 或游標中使用 Claude 程式碼 | [VS Code / 游標](/zh-TW/tools/cursor-vscode) | 偏好編輯器介面的使用者 |
| 寫你自己的程式來呼叫 API | [存取方法概述](/zh-TW/guide/integration-overview) | 應用程式開發者與自動化腳本 |

## 設定前請先確認

1. API 金鑰已建立，並設定了合理的限制。
2. API 金鑰群組包含目標模型。
3. 從模型方格複製出精確的模型 ID。
4. 備份工具已有設定檔;請勿直接刪除整個設定目錄。
5. 完成後，發送簡短的測試請求並檢查使用紀錄。

<Warning>
**請勿直接執行來源不明的一鍵腳本**

自動安裝或設定腳本可能會修改本地設定、撰寫 API 金鑰，或安裝第三方元件。 執行前，先驗證原始碼、閱讀腳本內容，並備份現有設定。
</Warning>
## 為什麼每個工具的地址都不同？

有些工具需要被納入 `/v1` API 位址，有些工具會自動串接路徑，而另一些則使用原生訊息或回應協定。

請使用對應教學中提供的地址;請勿複製 Claude Code、Codex CLI 或通用 OpenAI SDK 的設定。 詳見詳細說明[存取方法概述](/zh-TW/guide/integration-overview)。

## 你的工具不包含在教學中

如果客戶端支援自訂的 OpenAI 相容位址，你可以先參考它[5分鐘內快速開始](/zh-TW/guide/quick-start)以及客戶的官方文件。

設定前請確認：

- 客戶端是否支援自訂的 Base URL？
- 客戶會使用聊天完成還是回應？
- 客戶端是否會自動完成資料 `/v1`。
- 型號ID是否可以手動輸入。

未經驗證的客戶端不會被納入官方教學中，目的是為了增加頁面數量。
