## 1. 選你的軟體

已安裝軟體就開啟對應教學；尚未安裝，先完成其安裝步驟。不想手改設定檔可選 CC Switch，但它不取代 Claude Code 或 Codex CLI 本身。

| 你在用什麼 | 開啟教學 |
| --- | --- |
| Claude Code | [設定教學](/zh-TW/tools/claude-code) |
| Codex CLI | [設定教學](/zh-TW/tools/codex-cli) |
| CC Switch | [設定教學](/zh-TW/tools/cc-switch) |
| VS Code / Cursor | [設定教學](/zh-TW/tools/cursor-vscode) |
| 自己寫程式 | [設定教學](/zh-TW/developer/code-examples) |

## 2. 開始前

1. 準備自己的 [API Key](/zh-TW/guide/api-key)。
2. 按對應教學複製位址和模型名稱，不要混用不同軟體設定。
3. 已有設定請先備份，不要刪除整個設定目錄。

沒有你的軟體？把名稱和設定畫面截圖傳給客服，請遮住 Key。

## 3. 模型怎麼選

| 使用方式 | 選模型時注意 |
| --- | --- |
| Claude Code 或其編輯器擴充功能 | 本套教學先選目前分組中支援 Claude Code 的 Claude 模型 |
| Codex CLI | 選已確認支援 Codex 的 GPT 模型和分組，不是所有 GPT 分組都適用 |
| CC Switch | 依裡面選擇的 Claude Code 或 Codex 應用程式選，不是依 CC Switch 名稱選模型 |
| 自己寫程式 | 按[模型推薦協定](/zh-TW/developer/model-protocols)選介面 |

具體名稱見[模型推薦協定](/zh-TW/developer/model-protocols)。模型廣場看得到，不代表你的 Key 能在所有軟體呼叫；不確定時，把軟體、模型和分組傳給客服，不要傳完整 Key。
