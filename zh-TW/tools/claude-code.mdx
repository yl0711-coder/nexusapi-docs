---

Claude Code 是一款強大的 AI 程式設計助理，讓你能直接在裝置上與 AI 協作。 本教學將引導你完成安裝與設定流程。

## 系統需求

- 支援作業系統：macOS 13+、Ubuntu 20.04+、Debian 10+ 或 Windows 10 1809+
- 硬體：超過 4 GB 記憶體，x64 或 ARM64 處理器
- Windows 安裝為選用 [Windows 版 Git](https://git-scm.com/install/windows)所以你可以使用 Git Bash
- 網路：通常存取 NexusAPI 服務的網路連線

## 1. 安裝 Claude 程式碼

優先使用Claude Code提供的原生安裝方法。 原生安裝不需要預先安裝Node.js。

### macOS、Linux 或 WSL

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

### Windows PowerShell

```powershell
irm https://claude.ai/install.ps1 | iex
```

你不需要以管理員身份執行 PowerShell。 Windows 也可以透過 WinGet 安裝：

```powershell
winget install Anthropic.ClaudeCode
```

### macOS 自製軟體

```bash
brew install --cask claude-code
```

安裝後，執行以下指令以執行唯讀檢查：

```bash
claude --version
claude doctor
```

## 2. 配置 API 標記

### 步驟 1：取得 API 令牌
登入主控台，然後在左側點選 Enter`令牌管理`從以下選單中選擇`添加令牌`建立一個新代幣，並提供以下代幣建議選項：

> - 名稱：代幣名稱
> - 配額：根據專案使用設定合理的上限
> - 分組：選擇與 Claude 相關的群組
> - 其他選項：維持預設設定


### 步驟 2：打開設定檔目錄

根據你的系統，找到 Claude Code 設定檔的儲存目錄 `.claude` ，通常位於：

- 視窗： `C:\\Users\\用户名文件夹\\.claude`
- macOS： `~/.claude` 或者 `.claude`
- Linux： `~/.claude`

在 macOS 中，請在 Finder 介面按下「Command+Shift+G」並輸入路徑 `~/.claude` 按 Enter 鍵即可開啟設定目錄
如果該目錄不存在，你可以執行以下指令來建立設定檔（適用於 macOS / Linux / WSL / Git Bash）
```
mkdir -p ~/.claude
touch ~/.claude/settings.json
```
Windows 可以先建立設定目錄，然後用記事本開啟設定檔：

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude"
notepad "$env:USERPROFILE\.claude\settings.json"
```

如果該檔案已經存在，請補充以下內容 `env` 欄位應合併到欄位中，且不得覆寫原始 MCP、權限或其他設定。


### 步驟 3：修改設定檔

在設定目錄中，建立或修改settings.json設定檔，寫入以下設定資訊，其中 `ANTHROPIC_AUTH_TOKEN` 用你自己的 API 代幣取代它

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-您的 API 令牌",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link",
    "CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS": "1"
  }
}
```
Ubuntu / macOS 也可以直接透過 vi 或 vim 建立或修改 `settings.json` 文件

```bash
vim  ~/.claude/settings.json
```

## 3. 啟動 Claude 程式碼

完成設定修改後，重新啟動終端機，然後進入專案目錄：

```bash
cd your-project-folder
```

請將它輸入你的專案目錄 `claude` 這將啟動並執行 Claude 程式碼：

```bash
claude
```
初次運行後，你會看到以下設定步驟：

1. **選擇一個主題** → 選擇你最喜歡的主題 + 按 Enter 鍵
2. **安全通知** → 確認安全指示 + 按 Enter
3. **終端配置** → 使用預設設定 + 按 Enter 鍵
4. **相信工作目錄** → 信任目前的目錄 + 按 Enter 鍵

現在你可以開始用你的 AI 程式助理寫程式了！

## 無法連接 Anthropic 服務
跑 `claude` 若發生以下錯誤：

```text
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR BAD REQUEST
Please check your internet connection and network settings.
Note: Claude Code might not be available in your country.
```
先跑 `claude doctor`然後確認 `~/.claude/settings.json` 中間
`ANTHROPIC_AUTH_TOKEN` 且 `ANTHROPIC_BASE_URL` 已儲存且格式正確的 JSON 格式。
修改設定後，關閉並重新開啟終端機，再執行一次 `claude`。

不要強行用腳本重寫 `.claude.json` 內部狀態欄位。 這些欄位可能會根據版本而改變，
直接覆寫檔案可能會導致原始登入狀態與設定遺失。 如果問題仍然存在，請保持原位
`claude --version`、`claude doctor` 輸出錯誤原文後請聯絡客服。


## 常見問題

### 問：遇到「無效 API 金鑰」· 請執行 /login」錯誤嗎？

**A:** 這表示 Claude Code 尚未偵測到環境變數。 請檢查：
- 是否設定正確 `ANTHROPIC_AUTH_TOKEN` 且 `ANTHROPIC_BASE_URL`
- 環境變數值是否正確（標記為 `sk-` 開場）
- 如果是永久配置，終端機有重新啟動嗎？

### 問：PowerShell 無法安裝腳本並遇到政策執行錯誤？

**A:** 你可以先切換到 Windows CMD 或官方的 WinGet 安裝方法。 確實需要調整
使用 PowerShell 政策時，僅修改目前的使用者範圍：

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

執行前請確認問題是由本地政策引起;請勿修改整台電腦的全域政策。

### 問：為什麼會顯示「離線」狀態？

**A:** Claude Code 透過連接 Google 來檢查網路狀態。 顯示「離線」並不影響正常使用，只是表示無法連接 Google。

### 問：為什麼 Fetch 在瀏覽網頁時會失敗？

**A:** 在存取網頁之前，Claude Code 需要先呼叫 Claude 服務進行安全檢查。 你需要：
- 維持穩定的國際網路連線
- 必要時使用全域代理

### 問：請求是否總是顯示「取回失敗」？

**A:** 這可能是網路環境造成的問題。 解決方案：
1. 試著使用代理工具


### 問：我該如何處理 API 錯誤？

**A:** 可能是網路連線或服務暫時無法使用。建議：
- Exit Claude Code （Ctrl+C）
- 重播 `claude` 秩序
- 如果問題持續，儲存請求 ID 並參考它[自我檢查問題](/zh-TW/faq/self-check)

### 問：網頁登入錯誤？

**A:** 試著清除網站的 Cookie，然後再登入一次。
