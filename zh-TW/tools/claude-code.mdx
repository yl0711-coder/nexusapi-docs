---
title: "Claude Code 安裝與設定"
description: "按系統安裝，填 Key 和模型，再傳訊息驗證。"
---

本流程使用 NexusAPI Key，不必登入 Claude 官方帳號。

## 1. 準備並安裝

先[建立 API Key](/zh-TW/guide/api-key)。到[模型廣場](https://nexusapi.link/pricing)選同一分組，複製支援 Claude Code / Messages 的模型名稱。Windows 在開始選單找 `PowerShell`；Mac 按 `Command + 空白鍵` 找「終端機」。

只執行自己的系統指令。已安裝 Claude Code 可跳過。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

安裝後重開終端機，執行下方指令，看到版本號再繼續。找不到指令先重開終端機；仍失敗，把安裝錯誤傳給客服。

```bash
claude --version
```

## 2. 開啟設定檔

按系統執行指令，開啟使用者設定檔：

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

macOS / Linux 用 nano：貼上後按 `Ctrl + O`、Enter 儲存，再按 `Ctrl + X` 離開。Windows 記事本按 `Ctrl + S`，檔名必須是 `settings.json`，不能成為 `.json.txt`。

## 3. 填入 Key 和模型

空檔案可直接貼下方內容。將 `YOUR_API_KEY` 換成完整 Key，`YOUR_MODEL_ID` 換成模型名稱，保留英文引號與逗號。

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

已有內容請先備份，只合併 `model` 和 `env`，不要清空。可改用 [CC Switch](/zh-TW/tools/cc-switch) 管理設定。不要將 Key 放入專案或截圖。

## 4. 啟動並確認成功

儲存後重開終端機，進入自己的專案資料夾，執行：

```bash
claude
```

輸入 `/status`，確認 `Anthropic base URL` 是 `https://nexusapi.link`、認證來源是 `ANTHROPIC_AUTH_TOKEN`、模型與剛填寫的一致。

傳送「請只回覆：連線成功，不要修改檔案」。收到完整回覆並在[使用日誌](https://nexusapi.link/usage-logs/common)看到紀錄即完成。測試消耗少量額度。

出現 `/login` 或 Key 錯誤，確認檔案在使用者目錄、預留文字已替換，再重啟。其他錯誤見[問題自查](/zh-TW/faq/self-check)。不要刪除整個 `.claude` 目錄。

官方專案：[Claude Code](https://github.com/anthropics/claude-code)。
