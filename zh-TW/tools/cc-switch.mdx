CC Switch 管理設定。**先安裝 [Claude Code](/zh-TW/tools/claude-code) 或 [Codex CLI](/zh-TW/tools/codex-cli)，只做對應安裝步驟，再回本頁。** 已安裝就繼續，不必再手動修改設定檔。

## 1. 安裝 CC Switch

開啟[官方下載頁](https://github.com/farion1231/cc-switch/releases/latest)，按系統選安裝檔：

- Windows：一般電腦選 Windows `.msi`；ARM 電腦選 `arm64` 的 `.msi`。
- macOS：選 macOS `.dmg`，依提示安裝。
- Linux：依系統選 `.deb` 或 `.AppImage`。

## 2. 新增自訂供應商

在左側選 **Claude Code** 或 **Codex**，點右上 **+ / 新增供應商**，選**自訂設定**。不要選 Claude Desktop 或其他網站的預設。

![CC Switch 4.0.21：選擇自訂設定（簡體中文介面）](/images/nexusapi/cc-switch-custom-entry-zh.png)

## 3. 照表填寫

先[建立 Key](/zh-TW/guide/api-key)，在[模型廣場](https://nexusapi.link/pricing)選同分組並複製適用模型。請依下表填寫 NexusAPI 參數：

| 欄位 | Claude Code | Codex |
| --- | --- | --- |
| 名稱 | NexusAPI Claude | NexusAPI Codex |
| 位址 / Endpoint | `https://nexusapi.link` | `https://nexusapi.link/v1` |
| API Key | 自己的完整 NexusAPI Key | 自己的完整 NexusAPI Key |
| 主模型 | 複製的 Claude Code / Messages 模型名 | 複製的 Codex / Responses 模型名 |

Claude Code：開啟進階選項，在「默认兜底模型」填入複製的主模型名稱；Haiku 的實際請求模型請填客服確認可用的輔助模型名稱。不要照抄下圖佔位符。

Codex：主模型照表填寫，不用設定 Claude Code 的模型對應。只設定要用的應用，選直連 / Direct，其餘維持預設，再按新增／儲存。

![Claude Code 填寫示例：請替換佔位符；畫面尚未儲存或連線。](/images/nexusapi/cc-switch-claude-form-zh.png)

Claude Code 填寫示例：請替換佔位符；畫面尚未儲存或連線。

![Claude Code 模型對應示例（簡體中文介面）](/images/nexusapi/cc-switch-claude-models-zh.png)

## 4. 啟用並驗證

儲存後點這筆 NexusAPI 設定的**切換 / Switch**，只儲存不會切換。重開終端機並啟動對應工具：

<Tabs>
<Tab title="Claude Code">
```bash
claude
```
</Tab>
<Tab title="Codex">
```bash
codex
```
</Tab>
</Tabs>

傳送「請只回覆：連線成功，不要修改檔案」。收到完整回覆，在[使用日誌](https://nexusapi.link/usage-logs/common)確認模型和分組。測試消耗少量額度。

找不到指令先安裝 CLI；仍連官方就確認已啟用並重啟。模型不可用時重選同分組主模型；錯誤提到輔助模型時再確認 Haiku / Sonnet / Opus 可用名稱。其他錯誤截圖給客服，遮住 Key。

官方專案：[CC Switch](https://github.com/farion1231/cc-switch)。按鈕名稱可能隨版本變更。
