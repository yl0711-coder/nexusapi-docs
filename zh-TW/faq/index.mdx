找到你的問題，照答案操作。不會處理就把報錯截圖傳給客服，請遮住完整 Key。

## 串接與設定

- **第一次使用從哪裡開始？**<br />
  開啟[快速開始](/zh-TW/guide/quick-start)，從第 1 步操作。

- **Base URL 要填哪個？**<br />
  開啟[軟體教學](/zh-TW/tools)，複製對應軟體的位址，不要自行加 `/v1`。

- **為什麼會 404？**<br />
  重新複製[對應教學](/zh-TW/tools)的位址。仍報錯就傳截圖給客服。

- **出現 `status_code=500, not implemented`？**<br />
  先不要反覆重試。把軟體名稱、模型、分組與報錯傳給客服，確認模型能否用於該軟體。

- **新 API Key 為何不能用？**<br />
  到 [API 金鑰](https://nexusapi.link/keys)頁重新複製完整 Key，貼上後重啟軟體，不要抄有星號的文字。

## 模型與費用

- **如何確認分組能否使用模型？**<br />
  在[模型廣場](https://nexusapi.link/pricing)選 Key 對應的分組，再複製模型名稱。找不到就問客服。

- **一次請求花多少？**<br />
  開啟[使用日誌](https://nexusapi.link/usage-logs/common)，找到該次紀錄，看費用。人民幣成本見[折扣說明](/zh-TW/billing/multipliers-and-discounts)。

- **錯誤請求也可能計費嗎？**<br />
  不能只憑報錯判斷。查看對應日誌的費用；有疑問就傳日誌截圖給客服核對。

- **有餘額卻提示額度不足？**<br />
  先看錢包餘額，再查 Key 額度與到期日。仍提示不足就問客服，不要急著重複儲值。

## API 與工具錯誤

- **400、401、429、500、502、503、504、524 代表什麼？**<br />
  開啟[報錯處理](/zh-TW/faq/common-errors)，找到同樣的報錯照著做。

- **長對話突然無法繼續？**<br />
  先保存重要內容，再開新對話，只發一句短訊息測試。不要連續重試；測試可能消耗額度。

- **錯誤後任務又成功了？**<br />
  看軟體是否收到完整回覆，再核對使用日誌與費用。不確定就把紀錄傳給客服。

## 找客服時傳什麼

- 軟體名稱。
- 發生時間、模型與分組。
- 報錯原文或截圖；有 Request ID（請求編號）就一起傳。

**不知道的留空，不用自己判斷原因。不要傳密碼、驗證碼或完整 Key。**
