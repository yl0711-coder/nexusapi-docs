請先選擇最接近的現象。發生錯誤時，先保存完整錯誤原文與 Request ID，再修改設定或重試。

## 接入與設定

- **第一次使用從哪裡開始？** 讀取[5 分鐘快速開始](/zh-TW/guide/quick-start)。
- **Base URL 要填哪個？** 依用戶端而異，請看[接入方式總覽](/zh-TW/guide/integration-overview)。
- **為什麼會 404？** 檢查是否組成 `/v1/v1/...`，以及用戶端是否自動拼接路徑。
- **新 API Key 為何不能用？** 檢查 Key 狀態、帳戶額度、群組、模型 ID 和 `Authorization: Bearer` 格式。

## 模型與費用

- **如何確認群組能否使用模型？** 在[模型廣場](https://nexusapi.link/pricing)按群組篩選，或用目前 Key 呼叫 `/v1/models`。
- **一次請求花多少？** 查看控制台紀錄，並閱讀[用量與帳單](/zh-TW/billing/usage-and-billing)。
- **錯誤請求也可能計費嗎？** 有可能。請按 Request ID 和最終日誌核對，不要只看用戶端是否收到內容。
- **有餘額卻提示額度不足？** 同時檢查帳戶餘額、Key 額度、到期日和群組。

## API 與工具錯誤

- **400、401、429、500、502、503、504、524 是什麼？** 看[常見 API 錯誤](/zh-TW/faq/common-errors)。
- **長對話無法繼續？** 保存錯誤後新建會話，不要高頻重送相同內容。
- **圖片生成超時？** 不要立刻提交相同任務；保存 Request ID 並查看[圖片模型說明](/zh-TW/guide/image-generation)。
- **Claude Code 的 `fetch failed`？** 先以簡短普通對話確認模型呼叫，再依[Claude Code 教學](/zh-TW/tools/claude-code)排查。

## 聯絡支援前

請依[問題自查](/zh-TW/faq/self-check)完成最小測試，並一次提供：Request ID、時間與時區、用戶端及版本、模型、端點、完整錯誤原文，以及問題是偶發或持續。請勿提供完整 Key、密碼或私密內容。
