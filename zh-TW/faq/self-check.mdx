---
title: "遇到報錯怎麼辦"
description: "保存報錯、檢查設定，仍失敗就聯絡客服。"
---

**先截圖，再按下面檢查。不會處理就直接找客服，不用先弄懂原因。**

## 1. 保存報錯

記下軟體名稱、時間、模型與分組，保存截圖。有請求編號就複製，找不到不用猜。截圖遮住完整 Key、密碼與業務隱私。

## 2. 按報錯檢查

| 看到什麼 | 怎麼做 |
| --- | --- |
| Key 錯誤 / 401 | 重新複製完整 Key，貼上後重啟軟體 |
| 403 / 無權限 | 把模型與分組傳給客服確認 |
| 404 | 重新複製[軟體教學](/zh-TW/tools)的位址 |
| 400 / not implemented | 請客服確認模型能否用於該軟體 |
| 429 / 並行超限 | 等目前請求結束，減少同時執行的任務再試一次 |
| 500 / 502 / 503 / 逾時 | 等 10～30 秒只試一次，仍失敗就找客服 |
| no available channel | 確認分組有該模型，仍報錯就找客服，不要重複儲值 |
| 額度不足 | 查錢包餘額、Key 額度與到期日 |

## 3. 只做一次簡短測試

先保存重要內容，再開新對話，傳「請回覆：你好」。有完整回覆就先用新對話；仍失敗就聯絡客服。**測試可能消耗額度，不要連續重試或刪除整個設定目錄。**

## 4. 複製這段傳給客服

```text
軟體名稱：
發生時間：
模型與分組：
報錯原文或截圖：
請求編號（有就填）：
```

不知道的留空。不要傳完整 Key、密碼或驗證碼。
