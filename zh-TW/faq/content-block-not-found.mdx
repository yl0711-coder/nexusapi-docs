---
title: "Content block not found"
description: "處理長會話、工具呼叫或串流中出現的不完整內容區塊錯誤。"
---

`API Error: Content block not found` 表示用戶端沒有取得預期內容片段。它常發生於長會話恢復、工具呼叫，或串流回應未完整結束時。

## 建議處理方式

1. 新建會話，只保留必要上下文。
2. 更新 Claude Code、Codex、Cursor 或相關擴充套件。
3. 暫時停用非必要工具和實驗性選項。
4. 縮短單次輸入，避免攜帶過長歷史紀錄。
5. 用同一模型發送一條簡短問題做測試。

## 何時聯絡支援

若新會話和簡短請求仍重複出現、跨多個模型皆出現，或伴隨異常消費，請提供 Request ID、時間與時區、工具和版本、模型、錯誤原文或截圖，以及僅原會話失敗或所有會話皆失敗的說明。

請勿提供完整 API Key 或含私密資訊的完整對話。
