---
title: "5 分鐘快速開始"
description: "登入、建立金鑰、設定軟體，完成第一次使用。"
---

**照下面 4 步操作。已經完成的步驟直接跳過。**

## 1. 登入，確認有可用額度

開啟[控制台](https://nexusapi.link/sign-in)登入，沒有帳號請聯絡客服。

開啟[錢包](https://nexusapi.link/wallet)。已有可用餘額或方案，繼續下一步；沒有則先[儲值](/zh-TW/guide/recharge)。

## 2. 建立並複製 API Key

1. 開啟 [API 金鑰](https://nexusapi.link/keys)，點「建立 API 金鑰」。
2. 名稱自行填寫；分組選客服提供的分組；建立數量填 `1`，其他沒有特殊需求就保持預設。
3. 點「儲存變更」。
4. 回到清單，點複製按鈕，複製剛建立的 Key。

不確定怎麼填？開啟[圖文教學](/zh-TW/guide/api-key)。**不要把完整 Key 傳給別人。**

## 3. 依你使用的軟體設定

先核對下面四項，再開啟軟體教學：

| 核對什麼 | 怎麼確認 |
| --- | --- |
| 軟體 | 確認是終端工具、編輯器擴充功能，還是自己的程式 |
| 分組 | 查看新 Key 的分組，首次依客服提供的分組選擇 |
| 模型名稱 | 模型廣場選同一分組，再複製適用於軟體的模型名 |
| 介面位址 | 從對應軟體教學複製，不要自行加路徑 |

| 你在用什麼 | 開啟對應教學照著填 |
| --- | --- |
| Claude Code | [Claude Code 設定](/zh-TW/tools/claude-code) |
| Codex CLI | [Codex CLI 設定](/zh-TW/tools/codex-cli) |
| CC Switch | [CC Switch 設定](/zh-TW/tools/cc-switch) |
| VS Code / Cursor | [編輯器設定](/zh-TW/tools/cursor-vscode) |
| 自己寫程式 | [可複製的程式碼範例](/zh-TW/developer/code-examples) |

不方便改設定檔，可用 [CC Switch](/zh-TW/tools/cc-switch)；先安裝要用的 Claude Code 或 Codex CLI，再管理設定。同一 Key 或分組不代表所有模型都適用所有軟體；不確定時查[模型推薦協定](/zh-TW/developer/model-protocols)，或把軟體、模型和分組傳給客服確認。

**位址、API Key、模型名稱照對應教學填寫。不同軟體的位址可能不同，不要混用。**

## 4. 傳一句話試試

在新對話傳送：**「請只回覆：連線成功，不要修改檔案」**。

收到完整回覆後，到[使用日誌](https://nexusapi.link/usage-logs/common)確認有本次紀錄，模型與分組也正確，才算設定完成。測試會消耗少量額度，不要只靠回覆內容判斷是否使用 NexusAPI。

失敗時把軟體名稱、錯誤截圖、時間、模型和分組傳給客服。截圖遮住完整 Key。
