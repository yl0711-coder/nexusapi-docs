---

**照下面 4 步操作。已經完成的步驟直接跳過。**

## 1. 登入，確認有可用額度

開啟[控制台](https://nexusapi.link/sign-in)登入，沒有帳號請聯絡客服。

開啟[錢包](https://nexusapi.link/wallet)。已有可用餘額或方案，繼續下一步；沒有則先[儲值](/zh-TW/guide/recharge)。

## 2. 建立並複製 API Key

1. 開啟 [API 金鑰](https://nexusapi.link/keys)，點「建立 API 金鑰」。
2. 名稱自行填寫；分組選客服提供的分組；建立數量填 `1`，其他沒有特殊需求就保持預設。
3. 點「儲存變更」。
4. 回到清單，點複製按鈕，複製剛建立的 Key。

不確定怎麼填？開啟[圖文教學](/zh-TW/guide/api-key)。**不要把完整 Key 傳給別人。**

## 3. 依你使用的軟體設定

| 你在用什麼 | 開啟對應教學照著填 |
| --- | --- |
| Claude Code | [Claude Code 設定](/zh-TW/tools/claude-code) |
| Codex CLI | [Codex CLI 設定](/zh-TW/tools/codex-cli) |
| CC Switch | [CC Switch 設定](/zh-TW/tools/cc-switch) |
| VS Code / Cursor | [編輯器設定](/zh-TW/tools/cursor-vscode) |
| 自己寫程式 | [可複製的程式碼範例](/zh-TW/developer/code-examples) |

**位址、API Key、模型名稱照對應教學填寫。不同軟體的位址可能不同，不要混用。**

## 4. 傳一句話試試

在軟體中傳送：**「請回覆：連線成功」**。

能收到完整回覆，就可以開始使用。[使用日誌](https://nexusapi.link/usage-logs/common)可以查看本次呼叫和費用。

失敗了？把**軟體名稱、錯誤截圖、發生時間、模型和分組**傳給客服。截圖請遮住完整 Key。
