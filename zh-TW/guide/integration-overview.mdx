## 1. 找到你在用的軟體

| 你要做什麼 | 照這篇操作 |
| --- | --- |
| 使用 Claude Code | [Claude Code 教學](/zh-TW/tools/claude-code) |
| 使用 Codex CLI | [Codex CLI 教學](/zh-TW/tools/codex-cli) |
| 用 CC Switch 切換服務 | [CC Switch 教學](/zh-TW/tools/cc-switch) |
| 在 VS Code / Cursor 中使用 | [編輯器教學](/zh-TW/tools/cursor-vscode) |
| 自己寫程式 | [程式碼範例](/zh-TW/developer/code-examples) |

## 2. 準備三項資訊

| 要填什麼 | 去哪裡找 |
| --- | --- |
| API Key | 在 [API 金鑰](https://nexusapi.link/keys)頁建立並複製 |
| 模型名稱 | [模型廣場](https://nexusapi.link/pricing)選金鑰分組，再複製名稱 |
| 介面位址 | 從上面對應教學複製，不要自行拼接 |

Claude Code 通常填 `https://nexusapi.link`；Codex CLI 和 OpenAI SDK 通常填 `https://nexusapi.link/v1`。**以使用的軟體教學為準。**

## 3. 確認能用

傳送「請回覆：連線成功」。收到完整回覆即可；沒有成功，先看[問題自查](/zh-TW/faq/self-check)，或把錯誤截圖傳給客服。截圖不要出現完整 API Key。
