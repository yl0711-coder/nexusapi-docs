NexusAPI 可供自建程式、OpenAI 相容用戶端與常用程式設計工具使用。不同用戶端會自行拼接路徑，且使用的協定不完全相同；請先依使用情境選擇，不要把一個工具的設定直接複製到另一個工具。

## 接入前的三項確認

1. 在控制台建立 API Key，並設定合理額度。
2. 確認該 Key 所屬群組包含目標模型。
3. 從模型廣場或 `/v1/models` 複製準確的模型 ID。

## 位址與協定對照

| 情境 | Base URL | 起始協定 | 說明 |
| --- | --- | --- | --- |
| OpenAI 相容 SDK 或一般程式 | `https://nexusapi.link/v1` | Chat Completions | SDK 通常會自行加上 `/chat/completions`。 |
| Claude Code | `https://nexusapi.link` | Anthropic Messages | Base URL 不要再加 `/v1`。 |
| Codex CLI | `https://nexusapi.link/v1` | Responses | 使用 Codex 的自訂 Provider 設定。 |
| 圖片模型 | `https://nexusapi.link/v1` | Images | 僅限模型廣場明示支援圖片生成的模型。 |

<Warning>
**模型可見不代表所有協定都可用**

請先閱讀[介面與模型能力矩陣](/zh-TW/developer/capability-matrix)。它說明目前對外公開的端點，以及為何不能把底層軟體的每一條路由當作站點承諾。
</Warning>

## 最小驗證流程

1. 以目前 Key 呼叫 `GET /v1/models`。
2. 選取回傳且符合協定的模型 ID。
3. 用一段簡短文字做一次測試。
4. 在控制台使用紀錄確認請求與花費。

若失敗，先保留完整錯誤與 Request ID，再依[問題自查](/zh-TW/faq/self-check)排查。不要高頻重送相同任務。
