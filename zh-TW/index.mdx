## 遇到問題

已有服務群，請回原服務群反映；沒有服務群，請聯絡為你開通帳號的對接人。還沒開始設定，可先提供軟體名稱與想用的模型，確認分組再操作。

把以下資料傳給客服：

- 使用的軟體。
- 發生時間、模型和分組。
- 錯誤原文或截圖；有請求編號時一起提供。

**截圖請遮住完整 API Key，不要傳密碼或驗證碼。** 不確定的資訊不用猜，先把看到的錯誤傳過來。
