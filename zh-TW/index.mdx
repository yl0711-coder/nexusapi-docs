## 串接時需要的三項資訊

| 資訊 | 從哪裡取得 | 作用 |
| --- | --- | --- |
| Base URL | 本文件 | 指定請求傳送到 NexusAPI 的位址 |
| API Key | 控制台 → 令牌管理 | 識別呼叫身分與可用群組 |
| 模型 ID | 控制台 → 模型廣場 | 指定要呼叫的模型 |

<Warning>
請勿在聊天記錄、截圖、前端程式碼庫或公開設定中洩露 API Key。懷疑洩露時，請立即在控制台刪除或重設該 Key。
</Warning>

## 需要支援時，請一併提供

- 發生時間與時區
- 模型 ID、請求介面，以及是否使用串流回應
- 完整錯誤原文與 Request ID
- 已完成的最小重現步驟

這些資訊能避免反覆追問，也能更快定位問題。
