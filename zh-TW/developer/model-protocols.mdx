先在下方找到模型名稱，再選擇對應協定。請保留模型名稱的大小寫、日期和後綴，不要自行改寫。

下表列出目前可選模型與建議協定。實際可用範圍以你的 API Key 分組為準。

## 如何選擇協定

| 使用的模型 | 先選協定 | 請求路徑 |
| --- | --- | --- |
| Claude | Anthropic Messages | `/v1/messages` |
| GPT 且分組支援 Responses | Responses | `/v1/responses` |
| GPT 僅確認 Chat Completions 的分組；DeepSeek、GLM、Kimi、Qwen、Grok | Chat Completions | `/v1/chat/completions` |

<Warning>
請先確認模型在你的 API Key 分組中可用。若軟體只支援一種協定，請選擇同時支援該協定的模型與分組。
</Warning>

使用 `gpt-5.6x` 分組時，先選擇 Chat Completions；如需 Responses，請先聯絡客服確認。

## 軟體設定與核對

1. 使用 Claude Code，依[設定教學](/zh-TW/tools/claude-code)填寫，Base URL 使用 `https://nexusapi.link`。
2. 使用 Codex CLI，依[設定教學](/zh-TW/tools/codex-cli)選 Responses；模型與分組均須支援此協定。
3. 使用 Chat Completions 程式，依[程式碼範例](/zh-TW/developer/code-examples)填寫，OpenAI SDK 的 Base URL 使用 `https://nexusapi.link/v1`。

找不到模型或所需協定時，先查看[模型與介面能力](/zh-TW/developer/capability-matrix)，再將模型名、Key 分組、軟體和 Request ID 提供給客服。請勿提供完整 Key。
