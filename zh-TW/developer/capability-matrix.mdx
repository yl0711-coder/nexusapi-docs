NexusAPI 是模型閘道，不代表每個模型都支援每一個 API。**模型、令牌群組與協定必須同時相符。**請以控制台的模型廣場，以及目前 Key 實際回傳的結果為準。

<Info>
**呼叫前請確認**

1. 目標模型已在目前令牌群組中上架。
2. 模型廣場標示的協定符合你的用戶端。
3. 先用 `/v1/models` 查看此 Key 實際可見的模型，再做最小測試請求。
</Info>

## 目前公開說明的能力

| 目的 | 介面／協定 | 適用情境 | 重要限制 |
| --- | --- | --- | --- |
| 列出目前 Key 可用模型 | `GET /v1/models` | 建立 Key 後、選模型前 | 僅反映此 Key 的群組和限制。 |
| 文字、對話與串流 | `POST /v1/chat/completions` | OpenAI 相容 SDK、程式與多數文字模型 | 請使用模型廣場標示為 `openai` 的模型。 |
| Claude Code／Anthropic 原生用戶端 | `POST /v1/messages` | 模型標示為 `anthropic` 時 | Claude Code 的 Base URL 不要再重複加上 `/v1`。 |
| Codex CLI | `POST /v1/responses` | 依 [Codex CLI 教學](/zh-TW/tools/codex-cli)設定 Provider 時 | 不是所有模型都可用，不能拿來呼叫目前的 Anthropic 類 Claude 渠道。 |
| 圖片生成 | `POST /v1/images/generations` | 模型廣場明確標示支援圖片生成時 | 只傳送所選圖片模型支援的參數。 |

<Warning>
**不要將 New API 的全部路由視為 NexusAPI 對外承諾**

底層 New API 軟體可能包含更多相容路由；NexusAPI 僅支援本頁、模型廣場或正式教學明確列出的能力。圖片編輯／變體、embeddings、音訊、rerank 和原生 Gemini 目前不是通用的公開 NexusAPI 能力，請勿在正式工作負載中以猜測方式測試。
</Warning>

## 用目前 Key 確認模型

```bash
curl 'https://nexusapi.link/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

從 `data[].id` 複製模型 ID。部分回應還會提供 `supported_endpoint_types`；若有此欄位，可用來確認模型標示為 `openai` 或 `anthropic`。

`/v1/models` 是單一 Key 的即時快照；模型廣場提供價格、群組與說明。若兩者不同，請以目前 Key 的回傳結果和控制台狀態為準。

## 協定選擇速查

| 你正在使用 | 建議從哪裡開始 |
| --- | --- |
| Python、JavaScript、cURL 或 OpenAI 相容 SDK | `/v1/chat/completions` |
| Claude Code | [Claude Code 教學](/zh-TW/tools/claude-code)中的 Messages 設定 |
| Codex CLI | [Codex CLI 教學](/zh-TW/tools/codex-cli)中的 Responses Provider |
| 圖片模型 | [圖片模型說明](/zh-TW/guide/image-generation) |

如果模型可見但請求仍失敗，先檢查模型 ID、令牌群組和請求路徑，並保留 Request ID 後依[問題自查](/zh-TW/faq/self-check)處理。
