CC Switch 用来管理配置。**先安装你要用的 [Claude Code](/tools/claude-code) 或 [Codex CLI](/tools/codex-cli)，只做对应教程的安装步骤，再回到本页。** 已安装就直接继续；不必再手动修改它们的配置文件。

## 1. 安装 CC Switch

打开[官方下载页](https://github.com/farion1231/cc-switch/releases/latest)，按系统选安装包：

- Windows：普通电脑选 Windows `.msi`；ARM 电脑选带 `arm64` 的 `.msi`。
- macOS：选 macOS `.dmg`，打开后按提示安装。
- Linux：按系统选 `.deb` 或 `.AppImage`。

## 2. 添加自定义供应商

打开 CC Switch，在左侧选 **Claude Code** 或 **Codex**，再点右上角 **+ / 添加供应商**，选择**自定义配置**。不要选择 Claude Desktop，也不要选其他网站的预设。

![CC Switch 4.0.21：选择自定义配置](/images/nexusapi/cc-switch-custom-entry-zh.png)

## 3. 按表填写

先[创建 Key](/guide/api-key)，在[模型广场](https://nexusapi.link/pricing)选同一分组并复制适用于目标工具的模型名称。按下表填写 NexusAPI 参数：

| 字段 | Claude Code | Codex |
| --- | --- | --- |
| 名称 | NexusAPI Claude | NexusAPI Codex |
| 地址 / Endpoint | `https://nexusapi.link` | `https://nexusapi.link/v1` |
| API Key | 自己的完整 NexusAPI Key | 自己的完整 NexusAPI Key |
| 主模型 | 复制的 Claude Code / Messages 模型名 | 复制的 Codex / Responses 模型名 |

Claude Code：打开“高级选项”，在“默认兜底模型”填复制的主模型名；Haiku 的实际请求模型填客服确认可用的辅助模型名。下图的占位符不能照抄。

Codex：主模型按表填写，不用填写 Claude Code 的模型映射。只配置要用的应用，模式选“直连 / Direct”；其他选项先保持默认，填完点“添加 / 保存”。

![Claude Code 填写示例：占位符必须替换，截图未保存、未连接。](/images/nexusapi/cc-switch-claude-form-zh.png)

Claude Code 填写示例：占位符必须替换，截图未保存、未连接。

![Claude Code 模型映射示例](/images/nexusapi/cc-switch-claude-models-zh.png)

## 4. 启用并验证

保存后点击这条 NexusAPI 配置的**切换 / Switch**。只是保存、不启用，软件不会切换。然后重开终端，运行对应工具：

<Tabs>
<Tab title="Claude Code">
```bash
claude
```
</Tab>
<Tab title="Codex">
```bash
codex
```
</Tab>
</Tabs>

发送“请只回复：连接成功，不要修改文件”。收到完整回复，再到[使用日志](https://nexusapi.link/usage-logs/common)确认本次模型和分组。测试消耗少量额度。

提示找不到命令：先安装对应 CLI。仍请求官方服务：检查是否已启用这条配置并重启工具。提示模型不可用：重新复制自己分组支持的主模型；若错误点名辅助模型，再确认 Haiku / Sonnet / Opus 的可用名称。其他错误把截图发给客服，遮盖 Key。

官方项目：[CC Switch](https://github.com/farion1231/cc-switch)。按钮名称可能随版本变化。
