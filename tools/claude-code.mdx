---
title: "Claude Code 安装与配置"
description: "选系统安装，填入自己的 Key 和模型，然后发一句话验证。"
---

只使用 NexusAPI Key 配置本次调用，不用在此流程登录 Claude 官方账号。

## 1. 准备并安装

先[创建 API Key](/guide/api-key)。在[模型广场](https://nexusapi.link/pricing)选同一分组，复制支持 Claude Code / Messages 的模型名称。打开终端：Windows 在开始菜单搜 `PowerShell`；Mac 按 `Command + 空格` 搜“终端”。

只运行自己系统下的安装命令。已有 Claude Code 可跳过安装。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

安装后重开终端，运行下面命令。看到版本号再继续；提示找不到命令时先重开终端，仍不行请发安装报错给客服。

```bash
claude --version
```

## 2. 打开配置文件

复制自己系统的命令，打开用户配置文件：

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

macOS / Linux 会打开 nano 编辑器：粘贴后按 `Ctrl + O`、回车保存，再按 `Ctrl + X` 退出。Windows 记事本中按 `Ctrl + S` 保存，文件必须叫 `settings.json`，不能变成 `.json.txt`。

## 3. 填入 Key 和模型

空文件可直接粘贴下面内容。把 `YOUR_API_KEY` 换成完整 Key，`YOUR_MODEL_ID` 换成刚复制的模型名称，保留英文引号和逗号。

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

如果文件已有内容，先备份，只合并 `model` 和 `env`；不要清空原配置。不确定怎么合并，可使用 [CC Switch](/tools/cc-switch) 管理配置。不要把 Key 放在项目配置或截图里。

## 4. 启动并确认成功

保存后关闭并重开终端，进入自己的项目文件夹，再运行：

```bash
claude
```

进入后输入 `/status`：确认 `Anthropic base URL` 为 `https://nexusapi.link`，认证来源是 `ANTHROPIC_AUTH_TOKEN`，模型是刚填写的名称。

再发送“请只回复：连接成功，不要修改文件”。收到完整回复，并在[使用日志](https://nexusapi.link/usage-logs/common)看到本次记录，就完成了。测试消耗少量额度。

出现 `/login` 或 Key 错误，先确认配置保存到了用户目录、两处占位符已替换，再重启。其他错误见[问题自查](/faq/self-check)。不要为了排错删除整个 `.claude` 目录。

官方项目：[Claude Code](https://github.com/anthropics/claude-code)。
