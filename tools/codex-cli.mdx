本页配置 Codex CLI。使用 NexusAPI Key，不要把 ChatGPT 登录密码当作 Key。

## 1. 安装 Codex

Windows 在开始菜单打开 PowerShell；Mac 打开“终端”。只运行自己系统的安装命令，已经安装可跳过。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Tab>
</Tabs>

安装后重开终端，执行以下命令。显示版本号再继续；找不到命令就先处理安装问题。

```bash
codex --version
```

## 2. 保存地址和模型

先[创建 Key](/guide/api-key)，在[模型广场](https://nexusapi.link/pricing)选同一分组，复制支持 Codex / Responses 的模型名称。然后按系统打开个人配置文件：

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex" | Out-Null
notepad "$env:USERPROFILE\.codex\config.toml"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```
</Tab>
</Tabs>

nano 中按 `Ctrl + O`、回车保存，`Ctrl + X` 退出。Windows 记事本按 `Ctrl + S`，文件名保持 `config.toml`，不能带 `.txt`。

空文件直接粘贴下面内容，只把 `YOUR_MODEL_ID` 换成复制的模型名称：

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

已有配置先备份：`model`、`model_provider` 放在文件顶部，增加或更新 `[model_providers.nexusapi]`，不要重复添加同名段。不确定怎么合并，可使用 [CC Switch](/tools/cc-switch)。本文件不填 Key。

## 3. 设置并保存 API Key

只把 `YOUR_API_KEY` 换成自己的完整 Key。Windows 命令会同时设置当前终端和用户环境变量。

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
[Environment]::SetEnvironmentVariable("NEXUSAPI_API_KEY", $env:NEXUSAPI_API_KEY, "User")
```
</Tab>
<Tab title="macOS (Zsh)">
```bash
touch ~/.zshrc
nano ~/.zshrc
```

在文件末尾加入下一行；已有同名变量就替换旧值，不要重复添加。保存后关闭并重开终端。

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
<Tab title="Linux / WSL (Bash)">
```bash
nano ~/.bashrc
```

在文件末尾加入下一行；已有同名变量就替换旧值，不要重复添加。保存后关闭并重开终端。

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
</Tabs>

Mac 按默认 Zsh、Linux 按 Bash 演示。使用其他 Shell 时，把同一行放到对应启动文件；不确定请问客服。不要把 Key 写进项目或截图。

## 4. 启动验证

在自己的项目目录打开终端，执行：

```bash
codex
```

输入 `/status`，确认模型正确、Provider 是 NexusAPI。再发“请只回复：连接成功，不要修改文件”。收到完整回复，并在[使用日志](https://nexusapi.link/usage-logs/common)看到记录，就配置好了。测试消耗少量额度。

## 5. 常见卡点

提示 `Missing environment variable`：回到第 3 步；提示模型不可用：重新复制当前分组支持 Codex 的模型名。其他报错见[问题自查](/faq/self-check)。

使用 Codex 编辑器扩展时，Mac 从 Dock 打开的编辑器未必能读到终端变量。先用本页 CLI 验证；需要扩展时，从已配置好的终端用 `code .` 或 `cursor .` 启动编辑器。不要把 Key 填进项目设置。

官方安装和配置：[Codex CLI](https://learn.chatgpt.com/docs/cli) · [Custom providers](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers)。
