---
title: "在 VS Code、Cursor 中使用 Claude Code"
description: "NexusAPI：在 VS Code、Cursor 中使用 Claude Code"
---

Claude Code 官方扩展提供图形化对话、代码差异预览、文件引用和权限确认。
VS Code 与 Cursor 共用同一份 Claude Code 用户级配置，因此只需配置一次 NexusAPI Key。

## 1. 安装扩展

开始前请确认：

- VS Code 版本为 1.98 或更高版本。
- 已按 [Claude Code 教程](/tools/claude-code) 配置 NexusAPI。
- `~/.claude/settings.json` 中的 API Key 和 Base URL 已生效。

打开扩展商店：

- macOS：`Cmd + Shift + X`
- Windows / Linux：`Ctrl + Shift + X`

搜索 `Claude Code`，确认发布者是 **Anthropic** 后再安装。也可以从
[Claude Code 官方 VS Code 指南](https://code.claude.com/docs/en/vs-code)
进入 VS Code 或 Cursor 的安装入口。

<Warning>
**核对发布者**

扩展商店中可能存在名称相近的第三方扩展。安装前请确认扩展名称为
`Claude Code`、发布者为 `Anthropic`。
</Warning>

## 2. 让扩展使用 NexusAPI

扩展会读取与 CLI 相同的用户级 `~/.claude/settings.json`（Windows 为用户目录下的对应文件）。因此：

1. 保持[Claude Code 教程](/tools/claude-code)中的 `settings.json` 配置即可。
2. **不要**把 NexusAPI Key 再复制到 VS Code / Cursor 的用户设置或项目 `.vscode/settings.json` 中。
3. 保存 `settings.json` 后，完全退出并重新打开编辑器。

如果扩展仍然显示 Anthropic 官方登录页：

1. 检查扩展是否为最新版本。
2. 若当前版本提供 **Disable Login Prompt** 设置，可在编辑器设置中搜索 `Claude Code login` 后开启。
3. 完全重启编辑器后再打开 Claude Code；若没有此设置，先在编辑器集成终端运行 `claude` 验证用户级配置。

<Warning>
**保护 API Key**

不要把 Key 写进项目目录的 `.vscode/settings.json`，也不要同步、截图或提交包含 Key 的配置。请只保存在用户目录的 `~/.claude/settings.json`。
</Warning>

Cursor 能安装 Claude Code 扩展时会使用同一份用户级配置；如果当前 Cursor 版本不支持该扩展，请在 Cursor 的集成终端中运行 `claude`，并按[Claude Code 教程](/tools/claude-code)配置用户目录中的设置文件。

## 3. 打开 Claude Code

安装完成后，可以通过以下任一方式打开：

- 点击编辑器右上角的 Claude Code 星形图标。
- 点击左侧活动栏中的 Claude Code 图标。
- 打开命令面板，搜索 `Claude Code`。
- 点击右下角状态栏中的 `Claude Code`。

如果右上角没有图标，请先打开一个代码文件；该图标可能只在文件打开后显示。

![Claude Code 官方扩展在 VS Code 中的界面示例](/images/nexusapi/claude-code-vscode-official.jpg)

> 界面示例来自
> [Claude Code 官方 VS Code 文档](https://code.claude.com/docs/en/vs-code)。
> 具体按钮位置可能随扩展版本更新。

## 4. 验证配置

在扩展中发送一个简单请求，例如：

```text
请解释当前打开文件的作用，不要修改代码。
```

能正常返回后，再输入 `/status`，确认显示的 `Anthropic base URL` 为 `https://nexusapi.link`。遇到错误时，请保留：

- 编辑器和扩展版本
- Claude Code 版本
- 错误原文
- Request ID

然后参考[问题自查](/faq/self-check)。

## 常见问题

### 扩展安装后没有出现

运行命令面板中的 `Developer: Reload Window`，或完整重启编辑器。

### CLI 能用，但扩展不能用

确认 `~/.claude/settings.json` 位于**用户目录**而非项目目录，且其中的 Base URL 和 Key 正确；如果当前版本提供 **Disable Login Prompt**，可开启后完全重启编辑器。

### Cursor 扩展商店找不到

可从 Claude Code 官方 VS Code 指南进入 Cursor 安装入口；如果当前 Cursor
版本不支持该扩展，仍可在 Cursor 的集成终端中运行 `claude`。
