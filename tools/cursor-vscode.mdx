title: "在 VS Code / Cursor 中使用 Claude Code"
description: "安装正确的扩展，在用户设置里填 Key 和地址，然后发消息测试。"
---

**本页配置 Claude Code 扩展，不是 Cursor 自带的 AI 聊天。** 先[创建 Key](/guide/api-key)，到[模型广场](https://nexusapi.link/pricing)选同一分组，复制支持 Claude Code 的模型名称。

## 1. 安装扩展

打开扩展商店：Windows / Linux 按 `Ctrl + Shift + X`；Mac 按 `Command + Shift + X`。搜索 `Claude Code`，确认发布者为 **Anthropic**，再点安装。

![官方扩展市场：认准 Claude Code for VS Code，发布者 Anthropic](/images/nexusapi/claude-extension-marketplace.png)

图为官方扩展市场，用来核对名称和发布者；在编辑器扩展商店找到同一项再安装。

## 2. 打开用户设置

按 `Ctrl + Shift + P`（Mac 用 `Command + Shift + P`），搜索并选择 **Preferences: Open User Settings (JSON)**。一定要打开“用户设置”，不是工作区设置、默认设置或项目的 `.vscode/settings.json`。

## 3. 填入 NexusAPI 配置

把下面的 `YOUR_API_KEY` 换成自己的完整 Key，`YOUR_MODEL_ID` 换成刚复制的模型名称，其他保持不变。

```json
{
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "https://nexusapi.link"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

如果文件已有设置，先备份，再合并上方的 `claudeCode` 设置；不要把原文件清空。只剩空的 `{}` 时，可以直接替换。

保存后不要再去登录官方账号。这份配置含个人 Key，不要放进项目、共享或同步给别人。

![用户设置示例：只需配置两个 `claudeCode` 项；下方外观与演示窗口设置不用复制。占位符需替换，截图不表示已连接成功。](/images/nexusapi/vscode-user-settings-demo.png)

用户设置示例：只需配置两个 `claudeCode` 项；下方外观与演示窗口设置不用复制。占位符需替换，截图不表示已连接成功。

## 4. 重启并测试

完全退出并重新打开编辑器。打开 Claude Code 图标，新建对话，发送“请只回复：连接成功，不要修改文件”。收到完整回复，再到[使用日志](https://nexusapi.link/usage-logs/common)确认本次请求。测试会消耗少量额度。

仍显示官方登录？检查上面的配置是否写在用户设置、占位符是否已替换，并升级扩展后重启。VS Code 可从[官方扩展市场](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)安装；Cursor 找不到扩展时，可在编辑器终端按 [Claude Code 教程](/tools/claude-code)使用。

官方入口：[Claude Code 项目](https://github.com/anthropics/claude-code) · [VS Code 扩展市场](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code)。
