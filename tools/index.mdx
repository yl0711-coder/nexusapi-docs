不同工具面向的工作方式不同。先根据用途选择，再进入对应教程，避免混用地址和配置文件。

## 快速选择

| 你的需求 | 推荐入口 | 适合谁 |
| --- | --- | --- |
| 在终端中让 AI 处理代码和项目任务 | [Claude Code](/tools/claude-code) | 使用 Claude 工作流的开发者 |
| 使用 Codex 终端智能体 | [Codex CLI](/tools/codex-cli) | 使用 Responses / Codex 工作流的开发者 |
| 在多个 Provider 配置之间切换 | [CC Switch](/tools/cc-switch) | 同时管理多个 CLI 配置的用户 |
| 在 VS Code 或 Cursor 中使用 Claude Code | [VS Code / Cursor](/tools/cursor-vscode) | 偏好编辑器界面的用户 |
| 自己编写程序调用 API | [接入方式总览](/guide/integration-overview) | 应用开发者和自动化脚本 |

## 配置前先确认

1. 已创建 API Key，并设置合理额度。
2. API Key 所属分组包含目标模型。
3. 从模型广场复制准确模型 ID。
4. 备份工具已有配置，不直接删除整个配置目录。
5. 完成后发送一条简短测试请求，并检查使用日志。

<Warning>
**使用可信来源的安装脚本**

自动安装或配置脚本可能修改本机配置、写入 API Key 或安装第三方组件。仅在确认来源、阅读脚本内容并备份现有配置后运行。
</Warning>

## 为什么每个工具的地址不一样

部分工具需要包含 `/v1` 的 API 地址，部分工具会自动拼接路径，还有些工具使用原生 Messages 或 Responses 协议。

请使用对应教程给出的地址，不要把 Claude Code、Codex CLI 和通用 OpenAI SDK 的配置互相复制。详细说明见[接入方式总览](/guide/integration-overview)。

## 教程里没有你的工具

如果某个客户端支持自定义 OpenAI 兼容地址，可以先参考[5 分钟快速开始](/guide/quick-start)和该客户端官方文档。

配置前请确认：

- 客户端是否支持自定义 Base URL。
- 客户端使用 Chat Completions 还是 Responses。
- 客户端是否会自动补全 `/v1`。
- 模型 ID 是否允许手动填写。

暂未验证的客户端请先结合其官方文档和本页的协议说明完成最小测试；验证稳定后，我们再考虑补充正式教程。
