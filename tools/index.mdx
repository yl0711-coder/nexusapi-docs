## 1. 选你的软件

已装软件，直接打开对应教程；没安装，先做对应教程的安装步骤。不想手改配置文件，可选 CC Switch，但它不代替 Claude Code 或 Codex CLI 本身。

| 你在用什么 | 打开教程 |
| --- | --- |
| Claude Code | [配置教程](/tools/claude-code) |
| Codex CLI | [配置教程](/tools/codex-cli) |
| CC Switch | [配置教程](/tools/cc-switch) |
| VS Code / Cursor | [配置教程](/tools/cursor-vscode) |
| 自己写程序 | [配置教程](/developer/code-examples) |

## 2. 开始前

1. 准备好自己的 [API Key](/guide/api-key)。
2. 按对应教程复制地址和模型名称，不要混用不同软件的配置。
3. 已经有配置的，先备份；不要删除整个配置目录。

没找到你的软件？把软件名称和配置页面截图发给客服，截图请遮盖 Key。

## 3. 模型怎么选

| 使用方式 | 选模型时注意 |
| --- | --- |
| Claude Code 或它的编辑器扩展 | 本套教程先选当前分组中支持 Claude Code 的 Claude 模型 |
| Codex CLI | 选已确认支持 Codex 的 GPT 模型和分组；不是所有 GPT 分组都适用 |
| CC Switch | 按里面选的 Claude Code 或 Codex 应用来选，不是按 CC Switch 名称选模型 |
| 自己写程序 | 按[模型推荐协议](/developer/model-protocols)选择接口 |

具体模型名称见[模型推荐协议](/developer/model-protocols)。模型广场能看到，不等于你的 Key 能在所有软件中调用；不确定时，把软件、模型和 Key 分组发给客服，不要发送完整 Key。
