## Три вещи для подключения

| Данные | Где получить | Назначение |
| --- | --- | --- |
| Base URL | В этой документации | Направляет запросы в NexusAPI |
| API Key | Консоль → Управление токенами | Определяет вызывающего и доступные группы |
| ID модели | Консоль → Каталог моделей | Выбирает модель для вызова |

<Warning>
Не раскрывайте API Key в чатах, скриншотах, фронтенд-репозиториях или публичных конфигурациях. При подозрении на утечку сразу удалите или перевыпустите Key в консоли.
</Warning>

## При обращении в поддержку приложите

- Время возникновения проблемы и часовой пояс
- ID модели, endpoint и информацию о streaming
- Полный текст ошибки и Request ID
- Минимальный сценарий воспроизведения, который уже был выполнен

Это сокращает число уточнений и помогает быстрее найти причину.
