---
title: "Что делать при ошибке"
description: "Сохраните ошибку, проверьте настройку и при необходимости обратитесь в поддержку."
---

**Сначала сделайте снимок ошибки. Выполните проверки ниже или сразу обратитесь в поддержку, если непонятно.**

## 1. Сохраните ошибку

Сохраните приложение, время, модель, группу и снимок. Скопируйте Request ID, если он есть; неизвестное не угадывайте. Скройте полный ключ, пароли и частные рабочие данные.

## 2. Действуйте по сообщению

| Сообщение | Действие |
| --- | --- |
| Ключ / 401 | Заново скопировать полный ключ и перезапустить приложение |
| 403 | Уточнить у поддержки модель и группу |
| 404 | Скопировать адрес из [инструкции приложения](/ru/tools) |
| 400 / not implemented | Проверить совместимость модели с приложением через поддержку |
| 429 / лимит одновременных запросов | Дождаться завершения запросов, уменьшить число задач и попробовать один раз |
| 500 / 502 / 503 / тайм-аут | Подождать 10–30 секунд, попробовать один раз, затем обратиться в поддержку |
| no available channel | Проверить модель в группе; не пополнять баланс только из-за этой ошибки |
| Недостаточно средств | Проверить баланс, лимит и срок ключа |

## 3. Одно короткое сообщение

Сохраните важное, откройте новый диалог и отправьте «Ответь: привет». При полном ответе используйте новый диалог; иначе обратитесь в поддержку. **Тест может расходовать кредиты. Не повторяйте запрос в цикле и не удаляйте весь каталог настроек.**

## 4. Скопируйте поддержке

```text
Приложение:
Время:
Модель и группа:
Текст или снимок ошибки:
Request ID (если есть):
```

Неизвестное оставьте пустым. Не отправляйте полный ключ, пароль или код подтверждения.
