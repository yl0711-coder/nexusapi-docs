NexusAPI — это шлюз моделей: не каждая модель работает с каждым API. **Модель, группа токена и протокол должны совпадать.** Источником актуальной информации служат каталог моделей и результат, возвращённый вашей текущей ключевой парой.

<Info>
**Проверьте до вызова**

1. Убедитесь, что модель доступна в группе вашего токена.
2. Проверьте, что `supported_endpoint_types` в ответе `/v1/models` содержит нужный протокол.
3. Выполните `/v1/models` с этой ключевой парой, затем отправьте минимальный запрос.
</Info>

## Публично документированные возможности

| Цель | API / протокол | Когда использовать | Важное ограничение |
| --- | --- | --- | --- |
| Список моделей, доступных текущему ключу | [GET /v1/models](/ru/developer/api-basics) | После создания ключа и до выбора модели | Отражает только группу и ограничения этого ключа. |
| Текст, чат и потоковая передача | [POST /v1/chat/completions](/ru/developer/openai-compatible) | OpenAI-совместимые SDK, скрипты и большинство текстовых моделей | Используйте только модель, у которой `supported_endpoint_types` содержит `openai`. |
| Claude Code или нативный Anthropic-клиент | [POST /v1/messages](/ru/developer/anthropic-messages) | `supported_endpoint_types` содержит `anthropic` | Не добавляйте `/v1` повторно в Base URL Claude Code. |
| Codex CLI | [POST /v1/responses](/ru/developer/responses) | При настройке провайдера по [руководству Codex](/ru/tools/codex-cli) | Используйте только модель, у которой `supported_endpoint_types` содержит `openai-response`. |
| Генерация изображений | [POST /v1/images/generations](/ru/guide/image-generation) | `supported_endpoint_types` содержит `image-generation` | Передавайте только параметры, поддерживаемые выбранной моделью. |

<Warning>
**Ориентируйтесь на опубликованную область возможностей NexusAPI**

NexusAPI публично поддерживает только возможности, явно указанные здесь, в каталоге моделей или в официальном руководстве. Редактирование и вариации изображений, embeddings, аудио, rerank и нативный Gemini пока не документированы как общие публичные возможности. До использования неподтверждённой возможности в production уточните её доступность у поддержки.
</Warning>

## Проверка моделей текущим ключом

```bash
curl 'https://nexusapi.link/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

Скопируйте ID из `data[].id`. `data[].supported_endpoint_types` перечисляет доступные для модели протоколы запросов: `openai` для Chat Completions, `anthropic` для Messages, `openai-response` для Responses и `image-generation` для генерации изображений. У модели может быть несколько типов; выбирайте по этому полю и вашему клиенту, а не по имени модели.

`/v1/models` — моментальный снимок для одного ключа. В каталоге также указаны цены, группы и описания. При расхождении следуйте ответу текущего ключа и состоянию консоли.

## Быстрый выбор протокола

| Вы используете | С чего начать |
| --- | --- |
| Python, JavaScript, cURL или OpenAI-совместимый SDK | `/v1/chat/completions` (сначала подтвердите наличие `openai`) |
| Claude Code | Настройка Messages в [руководстве Claude Code](/ru/tools/claude-code) (сначала подтвердите наличие `anthropic`) |
| Codex CLI | Провайдер Responses в [руководстве Codex CLI](/ru/tools/codex-cli) (сначала подтвердите наличие `openai-response`) |
| Модель изображений | [Руководство по моделям изображений](/ru/guide/image-generation) (сначала подтвердите наличие `image-generation`) |

Если модель видна, но запрос не проходит, сначала проверьте ID модели, группу токена и путь запроса. Сохраните Request ID и пройдите [самопроверку](/ru/faq/self-check).

- Эта страница отвечает на вопрос: «какой API использовать для текущей модели?».
