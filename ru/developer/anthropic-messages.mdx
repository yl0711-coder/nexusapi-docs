---

Используйте этот API, когда `supported_endpoint_types` в `/v1/models` текущего key содержит `anthropic`. Сначала проверьте [матрицу возможностей](/ru/developer/capability-matrix): **модель, группа key и протокол должны совпадать**.

<Warning>
**Messages не является универсальным endpoint**

Для OpenAI-совместимого приложения используйте [Chat Completions](/ru/developer/openai-compatible). Если `supported_endpoint_types` не содержит `anthropic`, не используйте Messages как универсальный endpoint: `not implemented` обычно означает несовместимость протокола, а не временную ошибку.
</Warning>

## Endpoint и минимальный запрос

```text
POST https://nexusapi.link/v1/messages
```

```bash
curl 'https://nexusapi.link/v1/messages' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_API_KEY' \
  -H 'anthropic-version: 2023-06-01' \
  -d '{
    "model": "YOUR_ANTHROPIC_MODEL_ID",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Здравствуйте"}]
  }'
```

| Элемент | Нужен | Примечание |
| --- | --- | --- |
| `model` | Да | Точный ID, видимый текущему key, у которого `supported_endpoint_types` содержит `anthropic` |
| `max_tokens` | Да | Максимум выходных токенов этого запроса |
| `messages` | Да | Диалог в формате Anthropic Messages |
| `anthropic-version` | Нужен нативному протоколу | SDK управляет им сам; при ручном вызове укажите совместимую версию |

Полные поля, tools, streaming и Schema ответа смотрите в документации используемого клиента Anthropic. Поддержка необязательных полей зависит от модели и её текущих возможностей.

## Использование Anthropic SDK

Нативный SDK сам управляет нужными заголовками. Передайте ему NexusAPI key и задайте Base URL **без `/v1`**:

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link",
)

message = client.messages.create(
    model="YOUR_ANTHROPIC_MODEL_ID",
    max_tokens=256,
    messages=[{"role": "user", "content": "Здравствуйте"}],
)
```

SDK добавляет `/v1/messages`. Не задавайте `https://nexusapi.link/v1/messages` как `base_url`: это может создать повтор пути или 404.

## Claude Code и собственное приложение

| Сценарий | Настройка |
| --- | --- |
| Claude Code | По [руководству Claude Code](/ru/tools/claude-code): `ANTHROPIC_BASE_URL=https://nexusapi.link` и `ANTHROPIC_AUTH_TOKEN` в `~/.claude/settings.json` |
| Anthropic SDK / нативное приложение | Base URL `https://nexusapi.link`, клиент сам отправляет Messages |
| Приложение с OpenAI SDK | Не смешивайте эту настройку; используйте [Chat Completions](/ru/developer/openai-compatible) |

## Устранение ошибок

- `401`: проверьте key, его активность и отсутствие сброса после утечки.
- `404`: проверьте, не добавил ли SDK второй `/v1`.
- `400`: сначала проверьте только `model`, `max_tokens`, `messages`, затем добавляйте поля постепенно.
- `500, not implemented`: убедитесь, что `supported_endpoint_types` содержит `anthropic` и запрос использует соответствующий endpoint.

При постоянной ошибке сохраните Request ID и обезличенный запрос, затем выполните [самопроверку](/ru/faq/self-check).
