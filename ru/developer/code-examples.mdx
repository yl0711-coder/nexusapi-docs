Примеры используют OpenAI Chat Completions. Сначала проверьте протокол в [матрице возможностей](/ru/developer/capability-matrix) и скопируйте точный ID модели, доступный текущему ключу.

## Базовые параметры

- Base URL: `https://nexusapi.link/v1`
- API-ключ: создаётся в [консоли NexusAPI](https://nexusapi.link)
- Model ID: точное значение из каталога или `/v1/models`

## Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link/v1",
)

response = client.chat.completions.create(
    model="YOUR_MODEL_ID",
    messages=[{"role": "user", "content": "Кратко представься."}],
)

print(response.choices[0].message.content)
```

## JavaScript

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "YOUR_API_KEY",
  baseURL: "https://nexusapi.link/v1",
});

const response = await client.chat.completions.create({
  model: "YOUR_MODEL_ID",
  messages: [{ role: "user", content: "Кратко представься." }],
});

console.log(response.choices[0].message.content);
```

## cURL

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"Проверка подключения"}]}'
```

Не помещайте настоящий ключ в исходный код и репозиторий. Эти примеры Chat Completions применимы только если `supported_endpoint_types` содержит `openai`. Для Responses используйте [соответствующее руководство](/ru/developer/responses) только тогда, когда модель содержит `openai-response`. Для изображений используется другой endpoint — см. [руководство по изображениям](/ru/guide/image-generation).
