NexusAPI поддерживает совместимые вызовы для основных SDK OpenAI. Ниже приведён быстрый пример интеграции широко используемых языков разработки. Для поддержки конкретных интерфейсов и параметров, пожалуйста, обратитесь к [Документация по справкам API](https://nexusapi.apifox.cn/) как стандарт.

### Параметры доступа к ядру

Перед использованием любой модели необходимо подготовить следующие два основных параметра:

- **Адрес интерфейса (базовый URL):** `https://nexusapi.link/v1`
- **Идентификационные учетные данные (API-ключ):** Это должно быть у нас [Пульт управления](https://nexusapi.link) Генерация обычно осуществляется `sk-` Начало.

> **Примечание:** При запросе, пожалуйста, введите API-ключ в заголовок HTTP-запроса `Authorization` поле, форматировано как `Bearer sk-xxxxxx`。

### Python
Просто инстанцируйте клиента, как раньше `api_key` И `base_url` Просто замените его на нашу.

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-您在 NexusAPI 生成的令牌",
    base_url="https://nexusapi.link/v1"
)

response = client.chat.completions.create(
    model="claude-sonnet-4-6", # 或其他模型
    messages=[
        {"role": "user", "content": "你好，请自我介绍。"}
    ],
    stream=True # 支持流式输出
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```

### JavaScript

```js
import OpenAI from "openai";

const openai = new OpenAI({
    apiKey: "sk-您在 NexusAPI 生成的令牌",
    baseURL: "https://nexusapi.link/v1"
});

async function main() {
    const stream = await openai.chat.completions.create({
        model: "claude-sonnet-4-6",
        messages: [{ role: "user", content: "你好！" }],
        stream: true,
    });
    for await (const chunk of stream) {
        process.stdout.write(chunk.choices[0]?.delta?.content || "");
    }
}
main();
```
