Найдите точное имя модели и выберите указанный протокол. Сохраняйте регистр, даты и суффиксы.

В таблице перечислены доступные для выбора модели и рекомендуемые протоколы. Доступ зависит от группы вашего API-ключа.

## Выбор протокола

| Используемые модели | Первый выбор | Путь запроса |
| --- | --- | --- |
| Claude | Anthropic Messages | `/v1/messages` |
| GPT в группе с поддержкой Responses | Responses | `/v1/responses` |
| Группы GPT только с подтверждённым Chat Completions; DeepSeek, GLM, Kimi, Qwen, Grok | Chat Completions | `/v1/chat/completions` |

<Warning>
Убедитесь, что модель доступна в группе вашего API-ключа. Если клиент поддерживает только один протокол, выберите совместимые с ним модель и группу.
</Warning>

Для группы `gpt-5.6x` начните с Chat Completions. Если нужен Responses, сначала уточните его поддержку.

## Настройка клиента и проверка

1. Для Claude Code следуйте [инструкции](/ru/tools/claude-code), Base URL: `https://nexusapi.link`.
2. Для Codex CLI следуйте [инструкции](/ru/tools/codex-cli) с Responses. Модель и группа должны поддерживать этот протокол.
3. Для Chat Completions используйте [примеры кода](/ru/developer/code-examples), Base URL SDK OpenAI: `https://nexusapi.link/v1`.

Если модели или протокола нет, проверьте [матрицу возможностей](/ru/developer/capability-matrix), затем отправьте поддержке имя модели, группу ключа, клиент и Request ID. Полный ключ не отправляйте.
