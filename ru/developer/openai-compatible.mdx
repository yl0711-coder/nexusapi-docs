Эта страница описывает только **OpenAI Chat Completions**. Перед вызовом проверьте модель, группу ключа и протокол в [матрице возможностей](/ru/developer/capability-matrix).

<Tip>
Каталог моделей и матрица показывают текущую доступность.
</Tip>

## Endpoint

```text
POST https://nexusapi.link/v1/chat/completions
```

## Минимальный запрос

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "YOUR_MODEL_ID",
    "messages": [{"role": "user", "content": "Здравствуйте"}]
  }'
```

| Заголовок | Обязательно | Значение |
| --- | --- | --- |
| `Content-Type` | Да | `application/json` |
| `Authorization` | Да | `Bearer YOUR_API_KEY` |

## Минимальные поля и потоковая передача

| Поле | Обязательно | Назначение |
| --- | --- | --- |
| `model` | Да | Точный ID, видимый текущему ключу, у которого `supported_endpoint_types` содержит `openai` |
| `messages` | Да | Сообщения диалога в формате Chat Completions |
| `stream` | Нет | Используйте `true` для событий потоковой передачи, только если модель и клиент поддерживают их |

В обычном ответе текст обычно читается из `choices[0].message.content`; в потоковом — из каждого `choices[0].delta.content`. Сначала проверьте модель и ключ минимальным запросом без потоковой передачи, затем включайте `stream` или добавляйте поля.

`temperature`, вызовы инструментов, визуальный ввод и структурированный вывод не гарантированы для всех моделей только из-за «OpenAI-совместимости». Текущую доступность модели и поддерживаемые возможности проверяйте в [матрице возможностей](/ru/developer/capability-matrix) и каталоге.

## Первые проверки при ошибке

| Результат | Что проверить |
| --- | --- |
| 401 | Ключ отсутствует, неверен, истёк или отключён. |
| 429 | Частоту, параллельность или временное ограничение вышестоящего сервиса. |
| 500 / 502 / 503 | Временную ошибку обработки или вышестоящего сервиса; подождите и повторите один раз. |
| 524 | Превышен лимит ожидания. |

При `status_code=500, not implemented` не повторяйте запрос как обычную ошибку 500 с высокой частотой. Обычно это означает несовместимость модели и протокола запроса. Проверьте, содержит ли `supported_endpoint_types` значение `openai`, затем используйте подходящее руководство. Сохраните Request ID и пройдите [самопроверку](/ru/faq/self-check).
