NexusAPI совместим с вызовами интерфейса в стиле OpenAI.

## Завершения чата

Адрес запроса:

```text
POST https://nexusapi.link/v1/chat/completions
```

Пример запроса:

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "claude-sonnet-4-6",
    "messages": [
      {
        "role": "user",
        "content": "你好"
      }
    ]
  }'
```

## Заголовок запроса

| Заголовок запроса | Обязательно | Объяснение |
| --- | --- | --- |
| `Content-Type` | Да | Исправлено `application/json` |
| `Authorization` | Да | Формат `Bearer YOUR_API_KEY` |

## Распространённые ошибки

| Неправильно | Возможные причины |
| --- | --- |
| 401 | Ошибка ключа API, ключ не доставлен или ключ некорректен |
| 429 | Запросы слишком быстрые, срабатывает троттлинг или сервис временно занят |
| 500/502/503 | Обработка запросов временно сбывает или сервис становится недоступным |
| 524 | Попросите, чтобы время ожидания было слишком долгим |

Пожалуйста, сохраняйте идентификатор запроса при обнаружении ошибок и обращайтесь к ним[Проверьте проблему самостоятельно](/ru/faq/self-check)。 Не повторяйте с высокой частотой за короткое время.
