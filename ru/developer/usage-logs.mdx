Используй свой**Системный токен доступа**Программные запросы**Его собственный рассказ**Журналы использования, которые можно интегрировать в ваши системы выставления счетов, аудита или мониторинга.

- Базовый URL:`https://api.nexusapi.link`
- Этот интерфейс**Только для чтения**, возвращает только данные счета, соответствующего токене.

## Цзянь Цюань

1. В консоли NexusAPI,**Личные настройки → генерации токенов**«Приобретён.»**Системный токен доступа**(Примечание: это не для вызова модели.) `sk-` API Key — это токен на уровне аккаунта; Если это утекает, пожалуйста, восстановите его как устаревший).
2. Вставьте заголовок запроса при вызове:

```http
Authorization: Bearer <你的系统访问令牌>
```

- Жетон**Размещается только заголовок запроса**, не пишите в URL.
- Этот токен является атрибутом аккаунта; добавление, удаление или ротация ключей API не влияет на него, что делает его подходящим для долгосрочной интеграции.

## Запрос в журнал использования

```http
GET /v1/logs?page=1&page_size=50[&start_time=..&end_time=..]
```

### Параметры запроса (все опционально)

| Параметры | Тип | Объяснение |
| --- | --- | --- |
| `page` | целое число | Номера страниц начинаются с 1, по умолчанию — 1 |
| `page_size` | целое число | Количество записей на странице: по умолчанию 10, максимум 50 |
| `start_time` | строка/int | Время начала, Unix секунды (например, `1717200000`) или RFC3339 (например, `2026-06-01T00:00:00Z`） |
| `end_time` | строка/int | Время окончания, формат как выше |

Ограничения:`page × page_size ≤ 100000`(предел глубины переворота страницы); Временной промежуток не ограничен.

### Пример возврата (200)

```json
{
  "data": [
    {
      "time": "2026-06-20T14:03:11Z", "token_name": "我的密钥", "group": "default",
      "model": "gpt-5.5", "use_time": 3, "first_byte": 0.8,
      "prompt_tokens": 1200, "completion_tokens": 800, "cost": 0.012,
      "ip": "1.2.3.4", "request_id": "2026xyzreq",
      "request_path": "/v1/chat/completions"
    }
  ],
  "page": 1, "page_size": 10
}
```

| Поле | Объяснение |
| --- | --- |
| `time` | Время запроса (UTC, RFC3339) |
| `token_name` | Название API-ключа, использованного в этот раз |
| `group` | Группировка токенов |
| `model` | Название модели |
| `use_time` | Общее время потраченного времени (секунды) |
| `first_byte` | Время первого символа (секунды); Это используется, когда нет начального символа в не-потоковых формах `null` |
| `prompt_tokens` / `completion_tokens` | Количество токенов на входе/выводе |
| `cost` | Сумма, потраченная в это время (USD) |
| `ip` | Источник: IP |
| `request_id` | Запрос ID |
| `request_path` | Путь вызова |

**Страница возвращает меньше 'page_size' (или пустой), то есть последняя страница.**

## Примеры вызовов

```bash
curl -H "Authorization: Bearer <你的系统访问令牌>" \
  "https://api.nexusapi.link/v1/logs?page=1&page_size=50&start_time=1717200000&end_time=1717804800"
```

Полный том переворота страницы (псевдокод):

```text
page = 1
while True:
    resp = GET /v1/logs?page=page&page_size=50
    处理 resp.data
    if len(resp.data) < 50: break   # 某页不满即最后一页
    page += 1
```

## Код ошибки

| HTTP | Ошибка | Значение |
| --- | --- | --- |
| 400 | `invalid_request` | Параметры некорректны (слишком глубоко переворачиваются страницы / неверный формат времени / порядок времени неправильный) |
| 401 | `unauthorized` | Токен отсутствует / недействителен / аккаунт отключён |
| 429 | `rate_limited` | Запросы слишком частые (диапазоны ответа). `Retry-After`, пожалуйста, следуйте инструкциям, чтобы отступить) |
| 503 | `unavailable` | Услуга временно недоступна (с определённой суммой денег). `Retry-After`） |
| 500 | `internal_error` | Внутренние ошибки |

## Рекомендации по использованию

- Время пришло **UTC**；`cost` В долларах США.
- Использование пагинации (`page_size` Максимум 50) + сегментированное время по времени,**Не проводите часто опросы**； Для сценариев аудита рекомендуется нажимать «вчера» раз в день.
- Поддерживается только HTTPS.
