---
title: "API журналов использования"
description: "Получайте детальные журналы NexusAPI своего аккаунта с системным токеном доступа и низкой частотой."
---

`api.nexusapi.link` — отдельный **read-only шлюз журналов**, не связанный с модельным relay и консолью. Он читает записи потребления аккаунта владельца токена; через него нельзя вызвать модель, пополнить счёт или изменить настройки.

## Основные данные

| Пункт | Значение |
| --- | --- |
| Base URL | `https://api.nexusapi.link` |
| Endpoint | `GET /v1/logs` |
| Рекомендуемые учётные данные | Системный токен доступа |
| Порядок | Сначала новые записи |

Создайте токен в **Консоль → Личные настройки → Создать токен** и отправляйте его только так:

```http
Authorization: Bearer YOUR_SYSTEM_ACCESS_TOKEN
```

<Warning>
Для вызова моделей используется API-ключ из Управления токенами; для этого endpoint — системный токен доступа. Он не вызывает модели, но раскрывает данные уровня аккаунта и должен храниться как секрет.
</Warning>

## Параметры

| Параметр | Назначение |
| --- | --- |
| `start_time` | Начало в Unix-секундах или RFC3339. |
| `end_time` | Конец в Unix-секундах или RFC3339; не раньше начала. |
| `page` | Номер страницы от `1`. |
| `page_size` | Размер страницы: по умолчанию `10`, максимум `50`. |

Запрашивайте данные за день или неделю. Серверных фильтров по модели, группе или имени ключа нет; фильтруйте свои данные локально. `page × page_size` не может превышать `100000`.

```bash
curl -G 'https://api.nexusapi.link/v1/logs' \
  -H 'Authorization: Bearer YOUR_SYSTEM_ACCESS_TOKEN' \
  --data-urlencode 'start_time=2026-06-01T00:00:00Z' \
  --data-urlencode 'end_time=2026-06-02T00:00:00Z' \
  --data-urlencode 'page=1' \
  --data-urlencode 'page_size=50'
```

Пустой `data` или число записей меньше `page_size` означает последнюю страницу. Полезные поля: `time`, `token_name`, `group`, `model`, `prompt_tokens`, `completion_tokens`, `cost`, `request_id`, `request_path`. Для 429 или 503 соблюдайте `Retry-After`; используйте плановую инкрементную синхронизацию, а не секундный polling.
