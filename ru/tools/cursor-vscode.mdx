title: "Claude Code в VS Code или Cursor"

---

Официальное расширение Claude Code предоставляет чат, предпросмотр diff, ссылки на файлы и запросы разрешений. VS Code и Cursor используют одну пользовательскую конфигурацию Claude Code.

## 1. Установите официальное расширение

Сначала завершите [настройку Claude Code](/ru/tools/claude-code). В списке расширений найдите **Claude Code** и убедитесь, что издатель — **Anthropic**. См. [официальное руководство VS Code](https://code.claude.com/docs/en/vs-code).

<Warning>
Могут существовать похожие сторонние расширения. Используйте только опубликованное Anthropic и не вставляйте ключ в панель стороннего расширения.
</Warning>

## 2. Используйте общую настройку NexusAPI

Расширение читает тот же `~/.claude/settings.json`, что и CLI (или эквивалентный путь Windows). Не сохраняйте ключ повторно в настройках проекта VS Code или Cursor.

Если редактор продолжает просить вход: откройте настройки, найдите `Claude Code login`, включите **Disable Login Prompt**, если этот пункт доступен, и полностью перезапустите редактор. Если приложение с рабочего стола не наследует окружение, запустите `code .` из уже настроенного терминала.

## 3. Безопасная проверка

Откройте Claude Code из боковой панели или палитры команд и попросите: «Объясни, что делает текущий файл, не меняя его». После успеха найдите соответствующую запись в журнале NexusAPI.

При проблеме обновите редактор, расширение и Claude Code, полностью перезапустите их, сохраните ошибку и Request ID, затем пройдите [самопроверку](/ru/faq/self-check). Не передавайте полный ключ, секрет рабочего пространства или приватный исходный код.
