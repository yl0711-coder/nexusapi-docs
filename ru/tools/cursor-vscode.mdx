**Это расширение Claude Code, не встроенный AI-чат Cursor.** [Создайте ключ](/ru/guide/api-key), выберите его группу в [Витрине моделей](https://nexusapi.link/pricing) и скопируйте модель для Claude Code.

## 1. Установите расширение

Нажмите `Ctrl + Shift + X` (Mac: `Command + Shift + X`), найдите `Claude Code`, проверьте издателя **Anthropic** и установите.

![Официальный Marketplace: Claude Code for VS Code, издатель Anthropic](/images/nexusapi/claude-extension-marketplace.png)

По этой официальной карточке проверьте название и издателя, затем установите соответствующее расширение в редакторе.

## 2. Откройте настройки пользователя

Через `Ctrl + Shift + P` (Mac: `Command + Shift + P`) выберите **Preferences: Open User Settings (JSON)**. Нужны настройки пользователя, не проекта, не рабочего пространства и не настройки по умолчанию.

## 3. Задайте NexusAPI

Замените `YOUR_API_KEY` полным ключом, а `YOUR_MODEL_ID` — скопированной моделью. Остальное не меняйте.

```json
{
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "https://nexusapi.link"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

Сохраните копию текущих настроек и объедините записи `claudeCode`, не удаляя другие. Если в файле только `{}`, замените всё содержимое.

Сохраните. Для этих запросов вход в официальный аккаунт не нужен. Настройки содержат ключ: не помещайте их в проект и не делитесь ими и не синхронизируйте их с другими.

![Пример пользовательских настроек: нужны только две записи `claudeCode`. Настройки оформления и демонстрационного окна ниже копировать не нужно. Замените заполнители; снимок не подтверждает успешное подключение.](/images/nexusapi/vscode-user-settings-demo.png)

Пример пользовательских настроек: нужны только две записи `claudeCode`. Настройки оформления и демонстрационного окна ниже копировать не нужно. Замените заполнители; снимок не подтверждает успешное подключение.

## 4. Перезапустите и проверьте

Полностью закройте редактор и откройте снова. В новой беседе Claude Code отправьте «Ответь только: подключение успешно. Не меняй файлы». Проверьте полный ответ и [журнал](https://nexusapi.link/usage-logs/common). Тест расходует немного кредитов.

Снова официальный вход? Проверьте настройки пользователя и замену значений, обновите расширение и перезапустите. Для VS Code используйте [официальный каталог расширений](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code). Если Cursor не находит расширение, используйте терминал по [инструкции Claude Code](/ru/tools/claude-code).
