---
title: "Используйте код Клода в VS Code и курсор"
---

Официальное расширение Claude Code предлагает графические диалоги, предвариальный просмотр кода, ссылки на файлы и проверку разрешений.
VS Code настроен аналогично Cursor.

## 1. Установка расширений

Пожалуйста, уточните перед началом:

- Версия VS Code — 1.98 или выше.
- Прессовано [Урок по коду Клода](/ru/tools/claude-code) Настройте NexusAPI.
- `~/.claude/settings.json` Ключ API и базовый URL теперь активны.

Откройте дополнительный магазин:

- macOS:`Cmd + Shift + X`
- Windows / Linux:`Ctrl + Shift + X`

Поиск `Claude Code`, издатель был подтверждён **Антропический** Затем переустановить. Он также может быть из
[Официальное руководство по Claude Code VS Code](https://code.claude.com/docs/en/vs-code)
Входите в портал установки VS Code или Cursor.

<Warning>
**Проверьте издателя**

В магазине расширений могут быть сторонние расширения с похожими названиями. Перед установкой, пожалуйста, убедитесь, что название расширения таково:
`Claude Code`, издатель: `Anthropic`。
</Warning>
## 2. Заставьте расширения использовать NexusAPI

Расширение Claude Code используется совместно с CLI `~/.claude/settings.json`。 В обычных обстоятельствах тебе не нужно там находиться
VS код или курсор `settings.json` Многократно вводите ключ API посередине.

Если расширение всё ещё показывает запрос на вход:

1. Откройте настройки редактора.
2. Поиск `Claude Code login`。
3. Активация **Отключить запрос на вход**。
4. Полностью выйдите и откройте редактор заново.

Если редактор не читает окружение терминала, вы можете войти в каталог проекта из настроенного терминала и запустить его:

```bash
code .
```

Пользователи Cursor могут перезапустить Cursor или запускать его напрямую в интегрированном терминале Cursor `claude`。

## 3. Откройте код Клода

После установки вы можете открыть его любым из следующих способов:

- Нажмите на иконку звезды Claude Code в правом верхнем углу редактора.
- Нажмите на значок Claude Code в левой панели активности.
- Откройте командную панель и найдите `Claude Code`。
- Нажмите на строку статуса в правом нижнем углу `Claude Code`。

Если в правом верхнем углу нет значка, пожалуйста, сначала откройте кодовый файл; Этот значок может появиться только после открытия файла.

> Конкретные положения кнопок могут быть обновлены в расширенной версии.

## 4. Проверьте конфигурацию

Отправьте простой запрос в расширение, например:

```text
请解释当前打开文件的作用，不要修改代码。
```

Если он возвращает нормально, значит, расширение прочитало конфигурацию NexusAPI. Если вы столкнётесь с ошибками, пожалуйста, сохраняйте:

- Редактор и расширенная версия
- Версия Claude Code
- Неправильный исходный текст
- Запрос ID

Тогда обратитесь к нему[Проверьте проблему самостоятельно](/ru/faq/self-check)。

## Часто задаваемые вопросы

### После расширенной установки не появилось

Запустите командную панель в меню Run `Developer: Reload Window`, или полностью перезапустить редактор.

### CLI работает, но расширения не могут

Подтвержденное расширение **Отключить запрос на вход** Включено и проверено
`~/.claude/settings.json` Является ли это действительным JSON? Расширения и CLI должны иметь одинаковую конфигурацию.

### Хранилище расширения курсора не найдено

Вы можете получить доступ к записи установки курсора из официального руководства Claude Code VS Code; Если текущий курсор присутствует
Версия не поддерживает это расширение и всё ещё может запускаться в интегрированном терминале Cursor `claude`。
