Claude Code — это мощный помощник по программированию ИИ, который позволяет работать с ИИ непосредственно на вашем устройстве. Этот урок проведёт вас через процесс установки и настройки.

## Требования к системе

- Поддерживаемые операционные системы: macOS 13+, Ubuntu 20.04+, Debian 10+ или Windows 10 1809+
- Аппаратное обеспечение: более 4 ГБ памяти, процессор x64 или ARM64
- Установка Windows необязательна [Git для Windows](https://git-scm.com/install/windows), так что можно использовать Git Bash
- Сеть: сетевое соединение, которое обычно обращается к сервисам NexusAPI

## 1. Установить Claude Code

Приоритизируйте с помощью нативного метода установки, предоставленного Claude Code. Нативная установка не требует предварительной установки Node.js.

### macOS, Linux или WSL

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

### Windows PowerShell

```powershell
irm https://claude.ai/install.ps1 | iex
```

Вам не нужно запускать PowerShell в качестве администратора. Windows также можно установить через WinGet:

```powershell
winget install Anthropic.ClaudeCode
```

### macOS Homebrew

```bash
brew install --cask claude-code
```

После установки выполните следующую команду для проверки только для чтения:

```bash
claude --version
claude doctor
```

## 2. Настройка токена API

### Шаг 1: Получить токен API
Войдите в консоль и нажмите для входа слева`令牌管理`Выберите меню из "`添加令牌`Создайте новый токен со следующими вариантами предложений токенов:

> - Название: Название токена
> - Квота: установка разумных верхних пределов на основе использования проекта
> - Группировка: Выберите группы, связанные с Клодом,
> - Другие опции: Сохранить настройки по умолчанию


### Шаг 2: Откройте каталог конфигурационных файлов

Найдите каталог хранения конфигурационного файла Claude Code в зависимости от вашей системы `.claude` , обычно расположен на:

- Окна: `C:\\Users\\用户名文件夹\\.claude`
- macOS: `~/.claude` Или `.claude`
- Linux: `~/.claude`

На macOS нажмите «Command+Shift+G» на интерфейсе Finder и введите путь `~/.claude` Нажмите Enter, чтобы открыть каталог конфигурации
Если папки нет, можно выполнить следующую команду для создания конфигурационного файла (применимо к macOS / Linux / WSL / Git Bash)
```
mkdir -p ~/.claude
touch ~/.claude/settings.json
```
Windows сначала может создать каталог конфигурации, а затем открыть конфигурационный файл с помощью Notepad:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude"
notepad "$env:USERPROFILE\.claude\settings.json"
```

Если файл уже существует, пожалуйста, добавьте следующее `env` Поля должны быть объединены с этим полем без перезаписи исходного MCP, разрешений или других конфигураций.


### Шаг 3: Изменить конфигурационный файл

В каталоге конфигурации создайте или измените settings.json конфигурационный файл, запишите следующую конфигурационную информацию, где `ANTHROPIC_AUTH_TOKEN` Замените его своим собственным токеном API

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-您的 API 令牌",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link",
    "CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS": "1"
  }
}
```
Ubuntu / macOS также можно создавать или модифицировать напрямую через vi или vim `settings.json` Документы

```bash
vim  ~/.claude/settings.json
```

## 3. Запуск Клода Кода

После завершения изменений конфигурации перезапустите терминал и затем войдите в каталог проекта:

```bash
cd your-project-folder
```

Введите это в каталог проектов `claude` Это запустит и запустит Claude Code:

```bash
claude
```
После начального запуска вы увидите следующие шаги настройки:

1. **Выберите тему** → Выберите любимую тему + нажмите Enter
2. **Уведомление о безопасности** → Подтвердить инструкции по безопасности + Нажать Enter
3. **Конфигурация терминала** → Используйте стандартную конфигурацию + нажмите Enter
4. **Доверьтесь каталогу работ** → Доверять текущему каталогу + нажать Enter

Теперь вы можете начать писать код с помощью своего помощника по программированию ИИ!

## Невозможно подключиться к сервисам Anthropic
Беги `claude` Если возникают следующие ошибки:

```text
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR BAD REQUEST
Please check your internet connection and network settings.
Note: Claude Code might not be available in your country.
```
Беги первым `claude doctor`, тогда подтвердите `~/.claude/settings.json` Средний
`ANTHROPIC_AUTH_TOKEN` И `ANTHROPIC_BASE_URL` Сохранено и в правильном формате JSON.
После изменения конфигурации закройте и откройте терминал снова, затем запустите его снова `claude`。

Не переписывайте его насильно через скрипты `.claude.json` Внутреннее состояние. Эти поля могут меняться в зависимости от версии,
Прямое перезаписывание файлов может привести к потере исходного статуса входа и конфигурации. Если проблема всё ещё существует, пожалуйста, держите её на месте
`claude --version`、`claude doctor` Свяжитесь с поддержкой после вывода и ошибки в оригинальном тексте.


## Часто задаваемые вопросы

### Вопрос: Столкновение с «Invalid API Key · Пожалуйста, запустите ошибку /login"?

**A:** Это указывает на то, что Claude Code не обнаружил переменных окружающей среды. Пожалуйста, проверьте:
- Правильно ли он настроен `ANTHROPIC_AUTH_TOKEN` И `ANTHROPIC_BASE_URL`
- Правильно ли значение переменной среды (токен с `sk-` Открытие)
- Если используется постоянная конфигурация, был ли терминал перезапущен?

### Вопрос: PowerShell не может установить скрипты и сталкивается с ошибками при выполнении политики?

**A:** Сначала можно перейти на Windows CMD или официальный метод установки через WinGet. Действительно, нужны корректировки
При использовании политик PowerShell изменяется только текущая область применения:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Перед запуском убедитесь, что проблема вызвана локальными политиками; не изменяйте глобальную политику всего компьютера.

### Вопрос: Почему отображается статус «офлайн»?

**A:** Claude Code проверяет статус сети, подключаясь к Google. Отображение «офлайн» не влияет на обычное использование, это просто означает, что Google не может быть подключен.

### Вопрос: Почему Fetch не работает при просмотре веб-страниц?

**A:** Перед тем как получить доступ к веб-странице, Claude Code должен позвонить в службу Claude для проверки безопасности. Вам понадобятся:
- Поддерживайте стабильное международное интернет-соединение
- При необходимости используйте глобальные прокси

### Вопрос: Всегда ли запрос показывает «fetch failed»?

**A:** Возможно, проблема связана с сетевой средой. Решение:
1. Попробуйте использовать прокси-инструменты


### Вопрос: Как мне обрабатывать ошибки API?

**A:** Возможно, сетевое соединение или сервис временно недоступны. Предложения:
- Exit Claude Code (Ctrl+C)
- Повтор `claude` Порядок
- Если проблема сохраняется, сохраните ID запроса и свяжитесь с ним[Проверьте проблему самостоятельно](/ru/faq/self-check)

### Вопрос: Ошибка входа в веб-страницу?

**A:** Попробуйте очистить файлы cookie с сайта, затем войти снова.
