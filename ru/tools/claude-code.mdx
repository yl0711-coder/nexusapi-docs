title: "Настройка Claude Code"
description: "Установите Claude Code и подключите его к NexusAPI через нативную конфигурацию Anthropic."
---

Claude Code использует нативный Anthropic Messages. Base URL NexusAPI — `https://nexusapi.link`; **не добавляйте `/v1`**.

## Системные требования

- macOS 13+, Ubuntu 20.04+, Debian 10+, Alpine Linux 3.19+ или Windows 10 версии 1809+;
- не менее 4 ГБ памяти и процессор x64 или ARM64;
- сеть с доступом к NexusAPI;
- при работе в Git Bash на Windows можно дополнительно установить [Git for Windows](https://git-scm.com/install/windows).

## 1. Установка Claude Code

Используйте официальный установщик:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

```powershell
irm https://claude.ai/install.ps1 | iex
```

Также доступны `winget install Anthropic.ClaudeCode` для Windows и `brew install --cask claude-code` для macOS. Проверьте установку:

### Windows WinGet

```powershell
winget install Anthropic.ClaudeCode
```

### macOS Homebrew

```bash
brew install --cask claude-code
```

```bash
claude --version
claude doctor
```

## 2. Создайте ключ NexusAPI

В **Управлении токенами → Добавить токен** выберите группу, содержащую модель, нужную для Claude Code, и задайте лимит. Не судите по одному названию модели: проверьте каталог или [матрицу возможностей](/ru/developer/capability-matrix).

### Выберите безопасные параметры ключа

Используйте понятное проектное имя и подходящий лимит. Ограничение модели и IP allowlist включайте только при понимании последствий; для временных тестовых ключей задавайте срок действия.

## 3. Создайте пользовательскую конфигурацию

### Найдите каталог конфигурации

| Система | Путь |
| --- | --- |
| macOS / Linux / WSL | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\\.claude\\settings.json` |

macOS, Linux, WSL и Git Bash:

```bash
mkdir -p ~/.claude
touch ~/.claude/settings.json
```

В Windows PowerShell сначала создайте каталог, затем откройте файл настроек:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude"
notepad "$env:USERPROFILE\.claude\settings.json"
```

### Задайте переменные окружения

Объедините эти значения с существующим `env`, не затирая MCP и разрешения:

```json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_NEXUSAPI_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

Сохраняйте это в каталоге пользователя, а не в репозитории проекта.

<Tip>
**Отключайте экспериментальные поля только при явной ошибке совместимости**

Если текст ошибки прямо упоминает `context_management` или неподдерживаемые экспериментальные входные поля, добавьте в `env` значение `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` и проверьте снова. Оно отключает часть preview-полей и не является настройкой по умолчанию.
</Tip>

## 4. Запуск и проверка

Откройте новый терминал, перейдите в каталог проекта и выполните:

```bash
cd your-project-folder
```

```bash
claude
```

Затем выполните `/status`. Убедитесь, что **Anthropic base URL** — `https://nexusapi.link`, а источником аутентификации указан `ANTHROPIC_AUTH_TOKEN`, и отправьте короткий вопрос. Доверяйте только знакомым рабочим каталогам.

## Частые проблемы

### `Invalid API Key · Please run /login`

Проверьте обе переменные, состояние ключа и перезапуск терминала. Не исправляйте это прямым редактированием внутренних файлов состояния входа Claude.

### Не удаётся подключиться к сервисам Anthropic

Выполните `claude doctor`, проверьте JSON в `settings.json` и две переменные окружения, затем откройте терминал заново. Если ошибка остаётся, сохраните её текст, `claude --version` и вывод `claude doctor`.

```text
Unable to connect to Anthropic services
Failed to connect to api.anthropic.com: ERR BAD REQUEST
```

Не перезаписывайте скриптом внутренние поля `.claude.json`. Они могут меняться между версиями, а перезапись способна удалить состояние входа или другие настройки.

### PowerShell блокирует установщик

Сначала используйте WinGet или официальный установщик из Windows CMD. Если вы подтвердили, что проблема только в локальной политике выполнения, измените её лишь для текущего пользователя:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

Не меняйте глобальную политику компьютера только для установки клиента.

### `fetch failed`

1. Отправьте обычный короткий запрос. Если он работает, проблема, вероятно, в WebFetch или другой отдельной сетевой функции.
2. Если не работает ни один вызов модели, выполните `claude doctor` и проверьте Base URL через `/status`.
3. Проверьте DNS, firewall, корпоративную сеть или доверенный прокси для `nexusapi.link`.
4. Откройте новый терминал и проверьте один раз. При постоянной ошибке сохраните версию, вывод doctor, текст ошибки и Request ID, затем пройдите [самопроверку](/ru/faq/self-check).

### Статус `offline`

Вспомогательные функции могут проверять отдельные сервисы. Подтвердите реальный вызов через `/status` и короткий запрос к модели, прежде чем считать gateway недоступным.

### WebFetch не работает, но обычный чат работает

WebFetch может использовать отдельные проверки безопасности доменов и внешний сетевой доступ. Если короткий текстовый запрос успешен, не меняйте Base URL NexusAPI и разбирайте ошибку WebFetch по сетевым правилам Claude Code.

### API-запрос не выполняется

Завершите текущую сессию, откройте новую сессию `claude` и выполните одну короткую проверку. При повторении ошибки сохраните Request ID и пройдите [самопроверку](/ru/faq/self-check).
