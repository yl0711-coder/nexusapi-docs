---

Запросы используют ключ NexusAPI. Вход в официальный аккаунт Claude для этой настройки не нужен.

## 1. Подготовка и установка

[Создайте ключ](/ru/guide/api-key), выберите его группу в [Витрине моделей](https://nexusapi.link/pricing), скопируйте модель для Claude Code / Messages. Windows: найдите `PowerShell` в Пуске. Mac: `Command + Space`, затем Terminal.

Выполните команду только своей системы. Установленный Claude Code можно не переустанавливать.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

Откройте новый терминал и проверьте версию. Если команда не найдена, перезапустите терминал; при повторной ошибке отправьте ошибку установки поддержке.

```bash
claude --version
```

## 2. Откройте файл конфигурации

Откройте пользовательский файл командой своей системы:

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

В nano: `Ctrl + O`, Enter для сохранения, `Ctrl + X` для выхода. В Блокноте Windows: `Ctrl + S`. Имя должно быть `settings.json`, не `.json.txt`.

## 3. Укажите ключ и модель

В пустой файл вставьте блок ниже. Замените `YOUR_API_KEY` полным ключом, `YOUR_MODEL_ID` — скопированным именем модели. Кавычки и запятые оставьте.

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

Сначала сохраните копию существующего файла, затем объедините только `model` и `env`, не стирая остальное. Можно использовать [CC Switch](/ru/tools/cc-switch). Не помещайте ключ в проект или скриншот.

## 4. Запустите и проверьте

Сохраните, заново откройте терминал в своём проекте и запустите:

```bash
claude
```

Введите `/status`: адрес `Anthropic base URL` должен быть `https://nexusapi.link`, источник ключа — `ANTHROPIC_AUTH_TOKEN`, модель — выбранная вами.

Отправьте «Ответь только: подключение успешно. Не меняй файлы». Полный ответ и запись в [журнале](https://nexusapi.link/usage-logs/common) подтверждают настройку. Тест расходует немного кредитов.

При `/login` или ошибке ключа проверьте пользовательский файл и заменённые значения, перезапустите. См. [проверку ошибок](/ru/faq/self-check). Не удаляйте весь каталог `.claude`.

Официальный проект: [Claude Code](https://github.com/anthropics/claude-code).
