---

Используется ключ NexusAPI, не пароль ChatGPT.

## 1. Установите Codex

Windows: PowerShell; Mac: Terminal. Выполните установку только для своей системы. Если установлен, пропустите.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Tab>
</Tabs>

Заново откройте терминал и проверьте версию. Если команда не найдена, сначала исправьте установку.

```bash
codex --version
```

## 2. Сохраните адрес и модель

[Создайте ключ](/ru/guide/api-key), выберите его группу в [Витрине моделей](https://nexusapi.link/pricing), скопируйте модель Codex / Responses. Откройте пользовательский файл:

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex" | Out-Null
notepad "$env:USERPROFILE\.codex\config.toml"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```
</Tab>
</Tabs>

В nano: `Ctrl + O`, Enter и `Ctrl + X`. В Блокноте: `Ctrl + S`. Имя файла — `config.toml`, без `.txt`.

Вставьте в пустой файл и замените только `YOUR_MODEL_ID`:

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

Сохраните копию старого файла. `model` и `model_provider` должны быть вверху, затем добавьте или обновите один раздел `[model_providers.nexusapi]`. Альтернатива — [CC Switch](/ru/tools/cc-switch). Ключ сюда не пишите.

## 3. Задайте и сохраните ключ

Замените только `YOUR_API_KEY`. В Windows ключ сохраняется и в текущем терминале, и в пользовательском окружении.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
[Environment]::SetEnvironmentVariable("NEXUSAPI_API_KEY", $env:NEXUSAPI_API_KEY, "User")
```
</Tab>
<Tab title="macOS (Zsh)">
```bash
touch ~/.zshrc
nano ~/.zshrc
```

Добавьте следующую строку в конец файла; существующее значение замените, не дублируйте. Сохраните и заново откройте терминал.

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
<Tab title="Linux / WSL (Bash)">
```bash
nano ~/.bashrc
```

Добавьте следующую строку в конец файла; существующее значение замените, не дублируйте. Сохраните и заново откройте терминал.

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
</Tabs>

Примеры для стандартного Zsh на Mac и Bash в Linux. Другой shell требует своего файла запуска; при сомнениях спросите поддержку. Не помещайте ключ в проект или скриншоты.

## 4. Запустите проверку

Откройте терминал в своём проекте и выполните:

```bash
codex
```

Проверьте модель и провайдера NexusAPI через `/status`. Отправьте «Ответь только: подключение успешно. Не меняй файлы». Полный ответ и [журнал](https://nexusapi.link/usage-logs/common) подтверждают работу. Тест расходует немного кредитов.

## 5. Частые затруднения

`Missing environment variable`: повторите шаг 3. Недоступная модель: скопируйте имя модели Codex из своей группы. Остальное — [проверка ошибок](/ru/faq/self-check).

Редактор из Dock на Mac может не получить переменные терминала. Сначала проверьте CLI; расширение Codex запускайте через `code .` или `cursor .` из настроенного терминала. Не пишите ключ в настройки проекта.

Официальная установка и настройка: [Codex CLI](https://learn.chatgpt.com/docs/cli) · [Custom providers](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers).
