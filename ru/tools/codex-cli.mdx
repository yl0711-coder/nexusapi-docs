title: "Настройка Codex CLI"
description: "Установите Codex CLI и настройте NexusAPI как пользовательский Responses-провайдер."
---

Команды и поля `config.toml` основаны на [официальном репозитории Codex](https://github.com/openai/codex) и [справочнике custom provider](https://learn.chatgpt.com/docs/config-file/config-advanced). NexusAPI предоставляет URL, ключ и ID модели.

## 1. Установка

Выберите один официальный способ:

### Windows PowerShell

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

### macOS, Linux или WSL

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

### Если Node.js уже установлен

```bash
npm install -g @openai/codex
codex --version
```

После установки также проверьте версию в новом терминале:

```bash
codex --version
```

## 2. Создайте совместимый ключ

В **Управлении токенами → Добавить токен** выберите группу с нужной моделью. Затем проверьте `/v1/models` и [матрицу возможностей](/ru/developer/capability-matrix): `supported_endpoint_types` должен содержать `openai-response`.

## 3. Настройте custom provider

| Система | Файл |
| --- | --- |
| Windows | `%USERPROFILE%\\.codex\\config.toml` |
| macOS / Linux | `~/.codex/config.toml` |

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

Храните NexusAPI Key в переменной окружения, а не в этом файле. `~/.codex/auth.json` может содержать состояние учётных данных Codex; NexusAPI Key туда добавлять не нужно.

## 4. Укажите ключ через окружение

### Windows PowerShell

```powershell
setx NEXUSAPI_API_KEY "YOUR_NEXUSAPI_KEY"
```

### macOS, Linux или WSL

```bash
export NEXUSAPI_API_KEY='YOUR_NEXUSAPI_KEY'
```

После `setx` откройте новый терминал. `export` действует только в текущей оболочке. Для постоянного хранения используйте менеджер учётных данных или управляемые переменные окружения, не репозиторий.

## 5. Проверка

В каталоге проекта выполните:

```bash
cd your-project-folder
codex
```

Для первой проверки задайте задачу без записи:

```text
Объясни структуру репозитория, не меняя файлы.
```

Затем проверьте журнал использования в консоли. При ошибке проверьте новый терминал, ключ, группу и ID модели, сохраните Request ID и используйте [самопроверку](/ru/faq/self-check).

## Устранение неполадок

1. Используйте терминал, открытый после задания `NEXUSAPI_API_KEY`.
2. Проверьте, что ключ включён, аккаунт имеет кредит, а группа содержит выбранную модель.
3. Снова скопируйте точный ID из каталога или `/v1/models`.
4. Сохраните исходную ошибку и Request ID, затем используйте [самопроверку](/ru/faq/self-check).

## VS Code / Cursor

Установите [расширение Codex, опубликованное OpenAI](https://marketplace.visualstudio.com/items?itemName=OpenAI.chatgpt), из marketplace. Оно использует ту же пользовательскую конфигурацию Codex; не добавляйте в VS Code устаревшие параметры `chatgpt.apiBase` или `chatgpt.config`.
