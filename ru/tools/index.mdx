---
title: "Выберите инструмент, который вам подходит"
---

Разные инструменты служат разным способам работы. Выбирайте по назначению, затем переходите к соответствующему учебнику, чтобы избежать смешивания адресов и конфигурационных файлов.

## Быстрый выбор

| Ваши потребности | Рекомендуемая запись | Кого бы ни подойдёт |
| --- | --- | --- |
| Пусть ИИ управляет кодом и проектными задачами в терминале | [Код Клода](/ru/tools/claude-code) | Разработчики, использующие рабочий процесс Claude |
| Использование агентов терминала Codex | [Codex CLI](/ru/tools/codex-cli) | Разработчики, использующие рабочий процесс Responses / Codex |
| Переключение между несколькими конфигурациями провайдеров | [CC-коммутатор](/ru/tools/cc-switch) | Управление пользователями с несколькими конфигурациями CLI одновременно |
| Используйте код Клода в VS Code или курсор | [VS Код / Курсор](/ru/tools/cursor-vscode) | Пользователи, предпочитающие интерфейс редактора |
| Напишите собственную программу для вызова API | [Обзор методов доступа](/ru/guide/integration-overview) | Разработчики приложений и автоматизированные скрипты |

## Подтвердите до настройки

1. Создан ключ API, установлен разумный лимит.
2. Группа ключей API включает целевой модель.
3. Скопируйте точный идентификатор модели из квадрата модели.
4. Инструмент резервного копирования уже имеет конфигурации; не удаляйте всю папку конфигурации напрямую.
5. После завершения отправьте краткий запрос на тестирование и проверьте журналы использования.

<Warning>
**Не запускайте скрипты с одним кликом неизвестного происхождения напрямую**

Скрипты автоматической установки или настройки могут изменять локальные конфигурации, записывать ключи API или устанавливать сторонние компоненты. Перед запуском проверьте исходный код, прочитайте содержимое скрипта и скопируйте резервную копию существующей конфигурации.
</Warning>
## Почему адрес для каждого инструмента отличается?

Некоторые инструменты должны быть включены `/v1` API-адреса, некоторые инструменты автоматически соединяют пути, в то время как другие используют нативные протоколы сообщений или ответов.

Пожалуйста, используйте адрес, указанный в соответствующем учебнике; не копируйте конфигурации Claude Code, Codex CLI или универсального OpenAI SDK. См. подробное объяснение[Обзор методов доступа](/ru/guide/integration-overview)。

## Ваши инструменты не включены в туториал

Если клиент поддерживает пользовательские адреса, совместимые с OpenAI, вы можете сначала обратиться к этому[Начинайте быстро за 5 минут](/ru/guide/quick-start)и официальную документацию клиента.

Пожалуйста, уточните перед настройкой:

- Поддерживает ли клиент пользовательские базовые URL?
- Клиент использует В Чате Завершения или Ответы?
- Будет ли клиент автоматически заполнять данные `/v1`。
- Можно ли вводить ID модели вручную.

Непроверенные клиенты не будут включаться в официальные обучающие материалы только для увеличения количества страниц.
