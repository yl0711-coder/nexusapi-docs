Сначала выберите инструмент для вашего способа работы, затем следуйте его отдельному руководству. Chat Completions, нативный Messages и Responses — разные протоколы; не переносите Base URL или конфигурацию между инструментами без проверки.

## Быстрый выбор

| Цель | Руководство | Сценарий |
| --- | --- | --- |
| Агент для кода в терминале | [Claude Code](/ru/tools/claude-code) | Claude workflow |
| Codex в терминале | [Codex CLI](/ru/tools/codex-cli) | Responses / Codex workflow |
| Несколько локальных провайдеров | [CC Switch](/ru/tools/cc-switch) | Переключение CLI-конфигураций |
| Claude Code в редакторе | [VS Code / Cursor](/ru/tools/cursor-vscode) | Работа в редакторе |
| Приложение или скрипт | [Обзор подключения](/ru/guide/integration-overview) | SDK / автоматизация |

## До изменения локальной конфигурации

1. Создайте ключ с нужным лимитом.
2. Проверьте группу ключа и целевую модель.
3. Скопируйте точный ID из каталога или `/v1/models`.
4. Сохраните резервную копию существующего файла конфигурации.
5. Один раз проверьте короткой read-only задачей и посмотрите журнал.

<Warning>
Перед запуском установочного скрипта убедитесь, что он получен из официального источника. Просмотрите его назначение и не вставляйте ключ в недоверенный код.
</Warning>

## Почему URL зависит от инструмента

Одним инструментам нужен API-адрес с `/v1`, другие сами добавляют путь, а некоторые используют нативные протоколы Messages или Responses.

Используйте адрес из руководства конкретного инструмента и не копируйте настройки между Claude Code, Codex CLI и обычным OpenAI SDK. Подробности приведены в [обзоре подключения](/ru/guide/integration-overview).

## Быстрая сверка протокола и URL

| Клиент | Обычный Base URL | Протокол |
| --- | --- | --- |
| OpenAI-совместимый SDK / приложение | `https://nexusapi.link/v1` | Chat Completions |
| Claude Code | `https://nexusapi.link` | Messages |
| Codex CLI | `https://nexusapi.link/v1` | Provider Responses |

Фактическая совместимость зависит от модели и группы. Сначала прочитайте [матрицу возможностей](/ru/developer/capability-matrix).

## Нужного инструмента нет в списке

Если клиент поддерживает настраиваемый OpenAI-совместимый Base URL, начните с [быстрого старта](/ru/guide/quick-start) и официальной документации самого клиента.

До настройки проверьте, добавляет ли он `/v1` автоматически, какой протокол отправляет и разрешает ли вручную указывать ID модели. Мы не публикуем непроверенные инструкции лишь для увеличения списка.
