## 1. Выберите приложение

Приложение установлено — откройте его инструкцию. Иначе сначала выполните установку. CC Switch помогает не редактировать файлы вручную, но не заменяет сам Claude Code или Codex CLI.

| Используете | Инструкция |
| --- | --- |
| Claude Code | [Настройка](/ru/tools/claude-code) |
| Codex CLI | [Настройка](/ru/tools/codex-cli) |
| CC Switch | [Настройка](/ru/tools/cc-switch) |
| VS Code / Cursor | [Настройка](/ru/tools/cursor-vscode) |
| Своя программа | [Настройка](/ru/developer/code-examples) |

## 2. Перед началом

1. Подготовьте свой [API-ключ](/ru/guide/api-key).
2. Скопируйте адрес и модель из нужной инструкции. Не смешивайте настройки разных приложений.
3. Сначала сохраните копию текущих настроек. Не удаляйте весь каталог конфигурации.

Приложения нет в списке? Отправьте поддержке его название и скриншот настроек, скрыв ключ.

## 3. Выберите совместимую модель

| Способ использования | Что выбрать |
| --- | --- |
| Claude Code или его расширение | Для этих инструкций — модель Claude из вашей группы с поддержкой Claude Code |
| Codex CLI | GPT-модель и группу с подтверждённой поддержкой Codex; не все GPT-группы подходят |
| CC Switch | Выбирать для активного приложения Claude Code или Codex внутри CC Switch |
| Своя программа | Выбрать интерфейс по [протоколам моделей](/ru/developer/model-protocols) |

Точные имена — в [протоколах](/ru/developer/model-protocols). Наличие модели на витрине не означает доступность через ваш ключ во всех приложениях. При сомнении сообщите поддержке приложение, модель и группу, но не полный ключ.
