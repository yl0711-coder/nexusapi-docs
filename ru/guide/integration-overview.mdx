NexusAPI поддерживает популярные AI-клиенты и API в стиле OpenAI. Разные инструменты могут автоматически добавлять части пути запроса, поэтому указывайте адрес для конкретного способа использования и не переносите всю конфигурацию одного инструмента в другой.

## Подготовка

Перед началом любой интеграции убедитесь, что:

1. В консоли создан API-ключ.
2. Группа этого API-ключа включает нужную модель.
3. Точный идентификатор модели скопирован из каталога моделей.
4. Для модели выбран поддерживаемый тип API, а запросы отправляются по HTTPS.

## URL и протоколы

| Сценарий | Адрес для ввода | Основной протокол | Важное замечание |
| --- | --- | --- | --- |
| OpenAI SDK / обычное текстовое приложение | `https://nexusapi.link/v1` | Chat Completions | Путь запроса добавляет SDK или приложение. |
| Codex CLI | `https://nexusapi.link/v1` | Responses | Используйте Provider из руководства Codex. |
| Claude Code | `https://nexusapi.link` | Anthropic Messages | Не добавляйте `/v1` повторно. |
| CC Switch | В зависимости от типа Provider | Зависит от целевого инструмента | У Claude и Codex разные правила URL. |
| Модели изображений | `https://nexusapi.link/v1` | Images | Используйте только модели, явно отмеченные как поддерживающие генерацию изображений. |

Эта таблица помогает выбрать способ интеграции. Сначала проверьте модель и протокол в [матрице возможностей API и моделей](/ru/developer/capability-matrix), а параметры и структуру ответа — в [Chat Completions](/ru/developer/openai-compatible). Фактическая доступность конкретной модели для вашего ключа определяется каталогом моделей.

## Сначала выберите правильный протокол

Одинаковый Base URL не означает, что каждая модель принимает любой формат запроса.

| Цель | Рекомендуемый endpoint | Когда использовать |
| --- | --- | --- |
| Обычный текст, чат или streaming | `/v1/chat/completions` | Модель доступна через OpenAI-совместимый маршрут. |
| Codex CLI и соответствующий Provider | `/v1/responses` | Используйте только если `supported_endpoint_types` содержит `openai-response`. |
| Claude Code или нативный Anthropic-клиент | `/v1/messages` | Используйте только если `supported_endpoint_types` содержит `anthropic`. |
| Генерация изображений | `/v1/images/generations` | У модели явно заявлена поддержка изображений. |

<Warning>
**Не используйте Responses как универсальную альтернативу**

Если `supported_endpoint_types` модели не содержит `openai-response` и `/v1/responses` возвращает `status_code=500, not implemented`, протокол не совпадает. Используйте endpoint, указанный для модели; в Claude Code сохраните нативную настройку Messages. Повторная отправка того же запроса не устранит несовместимость протокола.
</Warning>

## Почему URL могут выглядеть по-разному

Для универсального OpenAI-совместимого запроса обычно используется:

```text
https://nexusapi.link/v1
```

Некоторым клиентам нужен URL сайта без `/v1`; другие сами добавляют `/chat/completions`, `/responses` или `/messages`. Следуйте инструкции для конкретного инструмента. Для изображений используйте [руководство по моделям изображений](/ru/guide/image-generation).

<Warning>
**Не дублируйте путь**

Если клиент уже добавляет `/v1`, введённый вручную суффикс может превратить адрес в `/v1/v1/...` и вызвать 404. При 404 сначала проверьте реальный URL запроса клиента.
</Warning>

## Не смешивайте настройку клиента и универсальный API

CLI-инструменты, расширения редактора и собственные приложения могут использовать разные протоколы и файлы конфигурации. Даже при одинаковом имени модели нельзя целиком копировать настройку одного инструмента в другой.

- **Codex CLI:** используйте [руководство Codex CLI](/ru/tools/codex-cli) и его настройки Responses.
- **Claude Code:** используйте [руководство Claude Code](/ru/tools/claude-code) и нативную конфигурацию Anthropic Messages.
- **Собственное текстовое приложение:** начинайте с Chat Completions, если SDK явно не требует другой протокол.
- **Изображения:** используйте endpoint изображений, не передавайте параметры генерации изображений в текстовый чат.
- **Если вы не уверены:** перед изменением настроек определите точный клиент и путь, который он действительно отправляет.

## Справочник API

В [матрице возможностей API и моделей](/ru/developer/capability-matrix) можно проверить, какой протокол подходит выбранной модели. Минимальный запрос Chat Completions приведён в [Chat Completions](/ru/developer/openai-compatible).

Этот справочный центр объясняет, как выбрать и настроить интеграцию, и даёт минимальные проверяемые запросы. Необязательные параметры всегда зависят от протокола клиента и возможностей, отображаемых сейчас в каталоге моделей.

## Как убедиться, что настройка работает

- Клиент возвращает полный ответ.
- Соответствующий запрос появился в журнале использования консоли.
- Модель, группа и списанная сумма соответствуют ожиданиям.

При ошибке сохраните её текст и Request ID, затем откройте [самопроверку](/ru/faq/self-check).
