## 1. Найдите приложение

| Задача | Инструкция |
| --- | --- |
| Claude Code | [Claude Code](/ru/tools/claude-code) |
| Codex CLI | [Codex CLI](/ru/tools/codex-cli) |
| Переключение через CC Switch | [CC Switch](/ru/tools/cc-switch) |
| VS Code / Cursor | [Редактор](/ru/tools/cursor-vscode) |
| Своя программа | [Примеры кода](/ru/developer/code-examples) |

## 2. Подготовьте три значения

| Значение | Где взять |
| --- | --- |
| API-ключ | Создать и скопировать в разделе [Ключи API](https://nexusapi.link/keys) |
| Имя модели | Выбрать группу ключа в [Витрине моделей](https://nexusapi.link/pricing), затем скопировать имя |
| Адрес API | Скопировать из нужной инструкции выше, не собирать вручную |

Claude Code обычно использует `https://nexusapi.link`, Codex CLI и OpenAI SDK — `https://nexusapi.link/v1`. **Следуйте инструкции своего приложения.**

## 3. Проверьте работу

Отправьте «Ответь: подключение успешно». Полный ответ означает успех. Иначе откройте [проверку ошибок](/ru/faq/self-check) или отправьте скриншот поддержке. Скройте полный API-ключ.
