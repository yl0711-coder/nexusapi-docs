NexusAPI можно использовать из собственного приложения, OpenAI-совместимого клиента или инструмента разработки. Клиенты по-разному формируют URL и используют разные протоколы. Сначала выберите сценарий, а не копируйте настройки одного инструмента в другой.

## Три проверки перед подключением

1. Создайте API-ключ в консоли и задайте разумный лимит.
2. Убедитесь, что его группа токена содержит нужную модель.
3. Скопируйте точный ID модели из каталога или из `/v1/models`.

## Выберите сценарий

| Цель | Рекомендуемое руководство |
| --- | --- |
| Приложение, SDK, cURL или автоматизация | [Быстрый старт](/ru/guide/quick-start) |
| Claude Code | [Настройка Claude Code](/ru/tools/claude-code) |
| Codex CLI | [Настройка Codex CLI](/ru/tools/codex-cli) |
| Несколько CLI-провайдеров | [Настройка CC Switch](/ru/tools/cc-switch) |
| Claude Code в VS Code или Cursor | [VS Code / Cursor](/ru/tools/cursor-vscode) |

## URL и протоколы

| Сценарий | Base URL | Точка входа | Важно |
| --- | --- | --- | --- |
| OpenAI-совместимый SDK / приложение | `https://nexusapi.link/v1` | Chat Completions | SDK обычно добавляет `/chat/completions`. |
| Claude Code | `https://nexusapi.link` | Anthropic Messages | Не добавляйте `/v1`. |
| Codex CLI | `https://nexusapi.link/v1` | Responses | Настройте custom provider Codex. |
| Модель изображений | `https://nexusapi.link/v1` | Images | Только для явно поддерживающей изображения модели. |

<Warning>
Видимая модель не обязательно доступна через каждый протокол. Перед настройкой прочитайте [матрицу API и возможностей](/ru/developer/capability-matrix): в ней указаны публично документированные endpoints NexusAPI.
</Warning>

## Минимальная проверка

1. Вызовите `GET /v1/models` текущим ключом.
2. Выберите возвращённый ID, соответствующий протоколу.
3. Отправьте один короткий текстовый запрос.
4. Проверьте запись в консоли.

При ошибке сохраните полный текст и Request ID, затем пройдите [самопроверку](/ru/faq/self-check). Не отправляйте одну и ту же задачу в цикле.
