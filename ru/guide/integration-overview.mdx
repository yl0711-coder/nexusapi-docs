NexusAPI поддерживает обычные AI-клиенты и вызовы интерфейса в стиле OpenAI. Разные инструменты могут автоматически заполнять пути, поэтому нужно заполнять адрес в зависимости от того, как вы им пользуетесь.

## Подготовка перед началом

Независимо от используемого метода, требуются следующие требования:

1. Создайте API-ключ в консоли.
2. Убедитесь, что группа ключей API включает целевой модель.
3. Скопируйте точный идентификатор модели с площади моделей.
4. Запрос оформляется с помощью HTTPS-адреса.

## Сравнение адреса и протокола

| Сцена | Введите адрес | Основные соглашения | Примечания |
| --- | --- | --- | --- |
| OpenAI SDK / универсальная программа | `https://nexusapi.link/v1` | Сложности в чате и так далее | Путь запроса конкатенируется SDK или программой |
| Codex CLI | `https://nexusapi.link/v1` | Ответы | Используйте конфигурацию Provider в учебнике по Codex |

| CC-коммутатор | Заполните данные по типу провайдера | Это зависит от целевого инструмента | У Клода другие правила адреса, чем в Codex |

Приведённая выше таблица используется для выбора методов доступа. Полный путь интерфейса, параметры и структура отклика остаются как [Документация по справкам API](https://nexusapi.apifox.cn/) как стандарт.

## Почему адреса могут отличаться

Общие запросы в стиле OpenAI обычно используют:

```text
https://nexusapi.link/v1
```

Некоторые клиенты требуют, чтобы это было опущено `/v1` Адрес сайта может быть автоматически заполнен `/chat/completions`、`/responses`、`/messages` и другие пути. Пожалуйста, обратитесь к соответствующему учебному материалу для получения точности.

<Warning>
**Избегайте повторения одного и того же пути**

Если клиент выполнит её автоматически, `/v1`, который может формироваться после ручного заполнения `/v1/v1/...` И это привело к 404. При встрече с 404 сначала проверьте фактический адрес запроса клиента.
</Warning>
## Не смешивайте конфигурацию клиента с общими API

Инструменты CLI, плагины редакторов и пользовательские программы могут использовать разные протоколы и конфигурационные файлы. Даже если названия моделей совпадают, нельзя напрямую скопировать всю конфигурацию одного инструмента в другой.

Метод оценки:

- Настройте Codex CLI: Прочитайте учебник по Codex и используйте соответствующую конфигурацию Responses.
- Настройка Claude Code: прочитайте учебник по коду Claude с использованием переменных среды Anthropic.
- Пишите свой собственный код: выбирайте путь запроса и параметры на основе ссылки на API.
- Если не уверены: сначала подтвердите имя клиента и реальный путь запроса, который он отправил.

## Документация по справкам API

Полный путь интерфейса, параметры, структура запроса и структура ответа присутствуют [Ссылка на NexusAPI API](https://nexusapi.apifox.cn/) Держите середину.

Центры помощи объясняют «как выбирать и использовать»; Ссылки на API отвечают за объяснение «что такое поля и структуры».

## Как подтвердить успешную конфигурацию

- Клиент может вернуть весь контент обычным способом.
- Соответствующий запрос появляется в журнале использования консоли.
- Модели, группировки и потребление в журналах соответствовали ожиданиям.

Если звонок неудачный, сохраните текст ошибки и запрос ID, затем введите[Проверьте проблему самостоятельно](/ru/faq/self-check)。
