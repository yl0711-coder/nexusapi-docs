Модели изображений вызываются иначе, чем текстовые модели. Перед запросом проверьте в [каталоге моделей](https://nexusapi.link/pricing) точное название модели, группу текущего API Key и отметку о поддержке генерации изображений.

<Warning>
**Сначала проверьте возможности модели**

Не отправляйте параметры генерации изображений в текстовый чат-эндпоинт и не используйте ID текстовой модели в интерфейсе изображений. Повторная отправка несовместимой комбинации модели, endpoint и параметров не решит проблему.
</Warning>

## Выполнение запроса

Для генерации используется Images endpoint в стиле OpenAI:

```text
POST https://nexusapi.link/v1/images/generations
```

Минимальному запросу нужны только ID модели и prompt:

```bash
curl 'https://nexusapi.link/v1/images/generations' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "YOUR_IMAGE_MODEL_ID",
    "prompt": "Минималистичная синяя геометрическая иконка технологической компании на чистом белом фоне"
  }'
```

Замените `YOUR_IMAGE_MODEL_ID` на точный ID модели изображений, который виден текущей группе в каталоге моделей.

## Параметры и результаты

Размер, качество, число изображений и формат ответа зависят от модели. Передавайте `size`, `quality`, `n`, `response_format` и другие необязательные параметры только если их поддержку указывает каталог моделей. Общие правила аутентификации, выбора модели и протокола приведены в [основах API](/ru/developer/api-basics).

Результаты обычно возвращаются в массиве `data`. Будет ли это URL или Base64, а также сколько изображений можно создать за запрос, определяется выбранной моделью и фактическим ответом.

## Ожидание и тайм-ауты

`/v1/images/generations` — это **синхронный HTTP endpoint**: клиент должен ждать результат текущего запроса. Этот публичный endpoint не предоставляет единый API с ID задачи и опросом для обычной генерации изображений; фактические форматы ответа могут различаться у провайдеров.

- Генерация может занять десятки секунд или дольше. Слишком короткий тайм-аут в клиенте, корпоративном прокси или расширении браузера может сработать раньше ответа.
- Не отправляйте одну и ту же задачу повторно, пока не подтвердили результат: это может создать дубликаты и повторные списания.
- При `504`, `524` или тайм-ауте клиента сохраните Request ID и время, затем обратитесь в поддержку. Не считайте автоматически, что задача точно выполнена или точно не запускалась.

## Частые проблемы

| Симптом | Что проверить первым |
| --- | --- |
| `Image generation is not enabled` | Поддержку изображений моделью, использование image endpoint и доступ текущей группы |
| `model not supported` | Точный ID модели и отсутствие текстовой модели в image endpoint |
| `400` / ошибка параметра | Уберите неподтверждённые необязательные параметры и проверьте минимальный запрос |
| `504` / `524` / тайм-аут клиента | Сохраните Request ID и не создавайте сразу повторную задачу |
| Нет результата изображения | Корректно ли клиент читает поле `data` и формат ответа |

Для поддержки укажите модель, Request ID, время, замаскированные параметры запроса и полный текст ошибки. Никогда не передавайте API Key целиком.
