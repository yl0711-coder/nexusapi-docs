**Выполните 4 шага. Уже выполненные шаги можно пропустить.**

## 1. Войдите и проверьте баланс

Откройте [страницу входа](https://nexusapi.link/sign-in). Если аккаунта нет, обратитесь в поддержку.

Откройте [Кошелёк](https://nexusapi.link/wallet). Если есть доступный баланс или подписка, продолжайте. Иначе [пополните баланс](/ru/guide/recharge).

## 2. Создайте и скопируйте API-ключ

1. В разделе [Ключи API](https://nexusapi.link/keys) нажмите **Создать ключ API**.
2. Укажите название, выберите группу от поддержки и количество `1`. Остальные настройки оставьте по умолчанию, если нет особых требований.
3. Нажмите **Сохранить изменения**.
4. В списке нажмите кнопку копирования нового ключа.

Нужны скриншоты? Откройте [инструкцию по ключам](/ru/guide/api-key). **Не передавайте полный ключ другим людям.**

## 3. Настройте своё приложение

| Что используете | Инструкция |
| --- | --- |
| Claude Code | [Настройка Claude Code](/ru/tools/claude-code) |
| Codex CLI | [Настройка Codex CLI](/ru/tools/codex-cli) |
| CC Switch | [Настройка CC Switch](/ru/tools/cc-switch) |
| VS Code / Cursor | [Настройка редактора](/ru/tools/cursor-vscode) |
| Своя программа | [Готовые примеры кода](/ru/developer/code-examples) |

**Адрес и имя модели копируйте из инструкции для вашего приложения, ключ укажите свой. Адреса в разных приложениях могут отличаться.**

## 4. Отправьте тестовое сообщение

Напишите: **«Ответь: подключение успешно»**.

Если пришёл полный ответ, можно пользоваться. Запрос и списание видны в [журнале использования](https://nexusapi.link/usage-logs/common).

При ошибке отправьте поддержке **название приложения, скриншот ошибки, время, модель и группу**. Скройте полный ключ на скриншоте.
