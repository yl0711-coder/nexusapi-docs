本页帮助您完成第一次调用。开始前只需要准备一个 NexusAPI 账号和可用额度。

<Info>
**最短流程**

购买额度 → 创建 API Key → 从模型广场复制模型 ID → 发起测试请求
</Info>

## 1. 购买额度

登录账号进入控制台，在“钱包管理”页面即可在线充值。

![NexusAPI 钱包管理与在线充值页面](/images/nexusapi/console-wallet-topup.png)

## 2. 创建 API 令牌

1. 进入控制台的“令牌管理”。
2. 点击“添加令牌”。
3. 填写便于识别的名称，例如 `codex-work`。
4. 选择包含目标模型的分组。
5. 按用途设置合理额度，然后提交。

![NexusAPI 令牌管理页面，密钥与账号数据已经脱敏](/images/nexusapi/console-token-management.png)

![NexusAPI 创建令牌页面](/images/nexusapi/console-create-token.png)

<Warning>
**请保护 API Key**

API Key 只会用于接口鉴权。不要把它提交到公开代码仓库、截图或聊天记录中。不同项目建议使用不同的 Key。
</Warning>

## 3. API 接口配置

准备以下三个参数：

| 参数 | 填写内容 |
| --- | --- |
| Base URL | `https://nexusapi.link/v1` |
| API Key | 在控制台生成，通常以 `sk-` 开头 |
| 模型 ID | 在[模型广场](https://nexusapi.link/pricing)复制准确名称 |

## 4. 测试验证

以下示例使用 OpenAI Chat Completions 格式。请替换 `YOUR_API_KEY` 和 `YOUR_MODEL_ID`：

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{
    "model": "YOUR_MODEL_ID",
    "messages": [{"role": "user", "content": "请回复：连接成功"}]
  }'
```

收到包含 `choices` 和回复内容的 JSON，说明基础接入成功。

<Tip>
**客户端里的地址可能不同**

部分客户端会自动补全 `/v1` 或具体请求路径。配置客户端时，请使用对应教程：[Claude Code](/tools/claude-code)、[Codex CLI](/tools/codex-cli)、[CC Switch](/tools/cc-switch) 或 [VS Code / Cursor](/tools/cursor-vscode)。不同工具的路径补全规则不同，请不要机械套用本页地址。
</Tip>
