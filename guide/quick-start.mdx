---
title: "5 分钟快速开始"
description: "登录、创建密钥、配置软件，完成第一次使用。"
---

**按下面 4 步做。已经完成的步骤直接跳过。**

## 1. 登录，确认有可用额度

打开[控制台](https://nexusapi.link/sign-in)登录，没有账号请联系客服。

打开[钱包](https://nexusapi.link/wallet)。已有可用余额或套餐，继续下一步；没有则先[充值](/guide/recharge)。

## 2. 创建并复制 API Key

1. 打开 [API 密钥](https://nexusapi.link/keys)，点击“创建 API 密钥”。
2. 名称随意填；分组选客服提供的分组；创建数量填 `1`，其他没有特殊要求就保持默认。
3. 点击“保存更改”。
4. 回到列表，点击复制按钮，复制刚创建的 Key。

不确定怎么填？打开[带图创建教程](/guide/api-key)。**不要把完整 Key 发给别人。**

## 3. 按你用的软件配置

先核对下面四项，再打开软件教程：

| 核对什么 | 怎么确认 |
| --- | --- |
| 软件 | 确认是终端工具、编辑器扩展，还是自己的程序 |
| 分组 | 看刚创建的 Key 对应分组，首次按客服提供的分组选 |
| 模型名称 | 模型广场选同一分组，再复制适用于该软件的模型名 |
| 接口地址 | 从对应软件教程复制，不要自己加路径 |

| 你在用什么 | 打开对应教程照着填 |
| --- | --- |
| Claude Code | [Claude Code 配置](/tools/claude-code) |
| Codex CLI | [Codex CLI 配置](/tools/codex-cli) |
| CC Switch | [CC Switch 配置](/tools/cc-switch) |
| VS Code / Cursor | [编辑器配置](/tools/cursor-vscode) |
| 自己写程序 | [可复制的代码示例](/developer/code-examples) |

**地址、API Key、模型名称照对应教程填写。不同软件的地址可能不同，不要混用。**

不方便改配置文件，可用 [CC Switch](/tools/cc-switch)；先安装要用的 Claude Code 或 Codex CLI，再用它管理配置。Key、分组相同，不代表所有模型都适合所有软件；拿不准时查[模型推荐协议](/developer/model-protocols)，或把软件、模型和分组发给客服确认。

## 4. 发一句话试试

在新对话中发送：**“请只回复：连接成功，不要修改文件”**。

收到完整回复后，到[使用日志](https://nexusapi.link/usage-logs/common)确认有本次记录，模型和分组也正确，就配置好了。测试会消耗少量额度，不要只靠回复内容判断是否走了 NexusAPI。

失败了？把**软件名称、报错截图、发生时间、模型和分组**发给客服。截图请遮盖完整 Key。
