## 1. 我想做什么，去哪里

| 我想做什么 | 打开哪里 | 怎么操作 |
| --- | --- | --- |
| 看账号概况 | [概览](https://nexusapi.link/dashboard/overview) | 查看用量概况；需要核对某一次调用时，再查使用日志 |
| 看一段时间的调用统计 | [数据看板](https://nexusapi.link/dashboard/models) | 选择时间范围查看自己的调用统计，不要把统计区间当成单次调用 |
| 创建、复制、限制或停用 Key | [API 密钥](https://nexusapi.link/keys) | 按[密钥教程](/guide/api-key)操作 |
| 找到某次调用、看扣费 | [使用日志](https://nexusapi.link/usage-logs/common) | 按时间、模型、分组或令牌名称查询，见[用量教程](/billing/usage-and-billing) |
| 看余额、充值、查付款订单 | [钱包](https://nexusapi.link/wallet) | 按[充值教程](/guide/recharge)操作 |
| 找模型、看当前分组的价格 | [模型广场](https://nexusapi.link/pricing) | 先选 Key 对应分组，再复制模型名称，见[模型和价格](/billing/models-pricing) |
| 改语言、设置余额提醒 | [个人资料](https://nexusapi.link/profile) | [界面与菜单设置](/guide/account-security#personal-settings) · [余额提醒](/guide/account-security#balance-reminders) |
| 改密码、检查登录设备 | [安全与访问](https://nexusapi.link/security) | 见[账号安全](/guide/account-security) |

菜单可能因账号开放范围、站点设置或个人显示设置不同而有所差异。找不到入口，先看本页第 3 节，不要猜其他后台地址。

### 查看一段时间的用量统计

1. 打开[数据看板](https://nexusapi.link/dashboard/models)，点击“筛选”。
2. 选择“快速范围”，或填写开始、结束时间；需要按小时、天等汇总时，调整“时间粒度”。
3. 点击“应用筛选器”，查看这一时段的调用次数、消耗和模型用量趋势。想回到默认范围，重新打开筛选窗口，点“重置”。

普通账号查看自己的统计。图表是汇总，不是单次账单；金额有疑问时，按同一时间范围查[使用日志](/billing/usage-and-billing)。

## 2. 余额、Key 额度和消耗不要混淆

- **钱包余额**：账号可用的账户额度。充值到账先在钱包确认。
- **Key 剩余额度**：这把 Key 自己还能使用的额度，不是另一份充值余额。
- **使用日志费用**：某一次调用实际记录的消耗。
- **概览、数据看板**：汇总统计；核对某次报错或扣费，请查对应日志。

钱包有余额，不代表每把 Key 都能调用：Key 可能已到期、被禁用或自身额度耗尽。先按[密钥管理](/guide/api-key#key-limits)检查，不要急着重复充值。

## 3. 看不到菜单怎么办

1. 打开[个人资料](https://nexusapi.link/profile)。如果有“左侧边栏个人设置”，检查对应功能是否被自己隐藏。
2. 如已隐藏，开启该项并点击“保存更改”；不确定之前改了哪些，可用该区域的“重置为默认”，再保存。
3. 没有这个设置、没有目标选项，或保存后仍找不到，联系原服务群或为你开通账号的对接人。

个人设置只能显示账号已开放的入口，不能解锁未开放功能。钱包中的套餐等功能，以你实际看到的内容为准。

## 4. 需要帮助时发什么

说明你在哪个页面、想做什么、发生时间，再附报错或截图。有请求 ID 就一起提供；不知道的留空。

**不要发送完整 Key、密码、验证码或恢复码。截图先遮盖个人资料、支付信息和业务隐私。**
