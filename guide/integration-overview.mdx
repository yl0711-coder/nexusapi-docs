## 1. 找到你在用的软件

| 你要做什么 | 照着这篇操作 |
| --- | --- |
| 使用 Claude Code | [Claude Code 教程](/tools/claude-code) |
| 使用 Codex CLI | [Codex CLI 教程](/tools/codex-cli) |
| 用 CC Switch 切换服务 | [CC Switch 教程](/tools/cc-switch) |
| 在 VS Code / Cursor 中使用 | [编辑器教程](/tools/cursor-vscode) |
| 自己写程序 | [代码示例](/developer/code-examples) |

## 2. 准备三项信息

| 要填什么 | 去哪里找 |
| --- | --- |
| API Key | [API 密钥](https://nexusapi.link/keys)页创建并复制 |
| 模型名称 | [模型广场](https://nexusapi.link/pricing)选中密钥分组，再复制模型名称 |
| 接口地址 | 从上面的对应教程复制，不要自己拼接 |

Claude Code 通常填写 `https://nexusapi.link`；Codex CLI 和 OpenAI SDK 通常填写 `https://nexusapi.link/v1`。**以你所用软件的教程为准。**

## 3. 确认能用

发送一句“请回复：连接成功”。收到完整回复即可；没有成功，先看[问题自查](/faq/self-check)，或把报错截图发给客服。截图里不要出现完整 API Key。
