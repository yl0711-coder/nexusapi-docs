title: "5-minute quick start"
description: "Sign in, create a key, configure your app, and send a first message."
---

**Follow these four steps. Skip any step you have already completed.**

## 1. Sign in and check your balance

[Sign in](https://nexusapi.link/sign-in). Contact support if you do not have an account.

Open [Wallet](https://nexusapi.link/wallet). If you have usable credit or a plan, continue; otherwise [add funds](/en/guide/recharge).

## 2. Create and copy an API key

1. Open [API Keys](https://nexusapi.link/keys) and click **Create API Key**.
2. Enter a name, choose the group provided by support, and set quantity to `1`. Leave other settings at their defaults unless you need to change them.
3. Click **Save changes**.
4. Back in the list, click the copy button for your new key.

Need pictures? See [the key guide](/en/guide/api-key). **Do not share your complete key.**

## 3. Follow the guide for your app

| What you use | Guide |
| --- | --- |
| Claude Code | [Configure Claude Code](/en/tools/claude-code) |
| Codex CLI | [Configure Codex CLI](/en/tools/codex-cli) |
| CC Switch | [Configure CC Switch](/en/tools/cc-switch) |
| VS Code / Cursor | [Editor setup](/en/tools/cursor-vscode) |
| Your own program | [Copyable code examples](/en/developer/code-examples) |

**Copy the address and model name from the matching guide and enter your own API key. Addresses can differ between apps.**

## 4. Send a test message

Send: **“Reply with: connection successful.”**

A complete reply means you can start using the app. Check the request and charge in [Usage Logs](https://nexusapi.link/usage-logs/common).

If it fails, send support the **app name, error screenshot, time, model and group**. Hide your complete key in screenshots.
