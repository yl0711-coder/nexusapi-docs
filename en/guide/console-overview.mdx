**Use the website to manage your account and usage. To configure Claude Code, Codex or another app, follow the [app guides](/en/tools).**

## 1. Where to go

| Task | Open | What to do |
| --- | --- | --- |
| Check your account summary | [Overview](https://nexusapi.link/dashboard/overview) | Review usage totals; use logs to check a specific request |
| Review calls over a period | [Dashboard](https://nexusapi.link/dashboard/models) | Select a time range for your statistics; these are not individual request details |
| Create, copy, restrict or disable a key | [API Keys](https://nexusapi.link/keys) | Follow the [key guide](/en/guide/api-key) |
| Find a request and its charge | [Usage Logs](https://nexusapi.link/usage-logs/common) | Filter by time, model, group or token name; see [usage and billing](/en/billing/usage-and-billing) |
| Check balance, top up or find payment orders | [Wallet](https://nexusapi.link/wallet) | Follow the [top-up guide](/en/guide/recharge) |
| Find models and group-specific prices | [Model Square](https://nexusapi.link/pricing) | Select the key's group before copying a model name; see [models and prices](/en/billing/models-pricing) |
| Change language or balance reminders | [Profile](https://nexusapi.link/profile) | [Display and menu settings](/en/guide/account-security#personal-settings) · [Balance reminders](/en/guide/account-security#balance-reminders) |
| Change password or check signed-in devices | [Security & Access](https://nexusapi.link/security) | See [account security](/en/guide/account-security) |

Menus can differ by account access, site configuration and personal display settings. If an entry is missing, use section 3 rather than guessing other backend URLs.

### Review usage over a period

1. Open [Dashboard](https://nexusapi.link/dashboard/models) and click **Filter**.
2. Choose a **Quick Range**, or set the start and end times. Adjust **Time Granularity** to group results by hour, day or another available interval.
3. Click **Apply Filters** to review call counts, consumption and model usage trends. To restore the default range, reopen the filter dialog and click **Reset**.

An ordinary account sees its own statistics. Charts are aggregates, not individual bills. For a charge question, check [Usage Logs](/en/billing/usage-and-billing) for the same period.

## 2. Balance, key quota and usage are different

- **Wallet balance:** the account's available credits. Confirm top-ups in Wallet.
- **Key remaining quota:** what that particular key can still use, not a second prepaid balance.
- **Log charge:** recorded usage for one request.
- **Overview and Dashboard:** aggregate statistics; check the relevant log for a specific error or charge.

A funded wallet does not guarantee every key works. A key may have expired, been disabled or exhausted its own quota. Check [key settings](/en/guide/api-key#key-limits) before topping up again.

## 3. If a menu entry is missing

1. Open [Profile](https://nexusapi.link/profile). If **Sidebar Personal Settings** is available, check whether you hid the feature.
2. Re-enable it and click **Save Changes**. If unsure of previous changes, use **Reset to Default** in that area, then save.
3. If the settings or option are absent, or the entry is still missing, contact your existing service group or account contact.

Personal settings only show features already available to your account. They do not unlock others. Features such as wallet plans depend on what your account actually displays.

## 4. What to send support

Include the page, what you wanted to do, the time and an error or screenshot. Add the request ID if available; leave unknown details blank.

**Never send a complete key, password, verification code or recovery code. Hide personal, payment and business details in screenshots.**
