## 1. Find your app

| What you want to do | Follow this guide |
| --- | --- |
| Use Claude Code | [Claude Code](/en/tools/claude-code) |
| Use Codex CLI | [Codex CLI](/en/tools/codex-cli) |
| Switch providers with CC Switch | [CC Switch](/en/tools/cc-switch) |
| Use VS Code / Cursor | [Editor setup](/en/tools/cursor-vscode) |
| Write your own program | [Code examples](/en/developer/code-examples) |

## 2. Have these three details ready

| What to enter | Where to find it |
| --- | --- |
| API key | Create and copy it in [API Keys](https://nexusapi.link/keys) |
| Model name | Select your key's group in [Model Square](https://nexusapi.link/pricing), then copy the name |
| API address | Copy it from the matching guide above; do not assemble it yourself |

Claude Code usually uses `https://nexusapi.link`; Codex CLI and OpenAI SDK usually use `https://nexusapi.link/v1`. **Follow the guide for your app.**

## 3. Check that it works

Send “Reply with: connection successful.” A complete reply means the setup works. Otherwise, see [troubleshooting](/en/faq/self-check) or send support an error screenshot. Hide your complete API key.
