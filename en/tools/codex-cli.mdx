Codex CLI is OpenAI's local coding agent. The commands and `config.toml` fields below follow the [official Codex repository](https://github.com/openai/codex) and [custom-provider reference](https://learn.chatgpt.com/docs/config-file/config-advanced). NexusAPI supplies only the Base URL, API key, and model ID.

## 1. Install Codex CLI

Choose one official installation method.

### Windows PowerShell

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

### macOS, Linux, or WSL

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

### With Node.js already installed

```bash
npm install -g @openai/codex
```

Verify installation:

```bash
codex --version
```

## 2. Create a compatible key

In **NexusAPI console → Token Management → Add token**, select a group containing the exact model you need. Use a recognizable name and a suitable project limit. Then check `/v1/models` and the [capability matrix](/en/developer/capability-matrix) to confirm that `supported_endpoint_types` includes `openai-response`.

## 3. Configure a custom provider

Open the user configuration file:

| System | File |
| --- | --- |
| Windows | `%USERPROFILE%\.codex\config.toml` |
| macOS / Linux | `~/.codex/config.toml` |

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

Replace `YOUR_MODEL_ID` with the exact model ID available to the key. Do not put the actual key in this file.

<Warning>
**Keep the NexusAPI key in an environment variable**

The configuration above reads the key from `NEXUSAPI_API_KEY` through `env_key`. `auth.json` can contain Codex credential state; there is no need to put a NexusAPI key in it. Keep the key out of source code and screenshots as well.
</Warning>

## 4. Set the environment variable

### Windows PowerShell

```powershell
setx NEXUSAPI_API_KEY "YOUR_NEXUSAPI_KEY"
```

Open a new terminal after running this command.

### macOS, Linux, or WSL

```bash
export NEXUSAPI_API_KEY='YOUR_NEXUSAPI_KEY'
```

This affects only the current shell. For long-term storage, use your system's credential or shell-environment management; never add the key to a repository.

## 5. Verify safely

```bash
cd your-project-folder
codex
```

For the first task, use a read-only instruction such as:

```text
Explain the repository layout without changing files.
```

Then check the console usage log.

## VS Code / Cursor

Install the [Codex extension published by OpenAI](https://marketplace.visualstudio.com/items?itemName=OpenAI.chatgpt) from the extension marketplace. It uses the same user-level Codex configuration; do not add the legacy `chatgpt.apiBase` or `chatgpt.config` settings to VS Code.

## Troubleshooting

1. Use a newly opened terminal so `NEXUSAPI_API_KEY` is available.
2. Confirm the key is enabled, funded, and assigned to the right group.
3. Recopy the exact model ID from the Model Marketplace or `/v1/models`.
4. Save the complete error and Request ID, then use the [self-check guide](/en/faq/self-check).
