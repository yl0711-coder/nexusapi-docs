## 1. Pick your app

Already installed? Open that app's guide. Otherwise, follow its installation steps first. CC Switch can manage settings if you prefer not to edit files, but it does not replace the Claude Code or Codex CLI itself.

| You use | Open this guide |
| --- | --- |
| Claude Code | [Setup guide](/en/tools/claude-code) |
| Codex CLI | [Setup guide](/en/tools/codex-cli) |
| CC Switch | [Setup guide](/en/tools/cc-switch) |
| VS Code / Cursor | [Setup guide](/en/tools/cursor-vscode) |
| Your own program | [Setup guide](/en/developer/code-examples) |

## 2. Before you start

1. Have your own [API key](/en/guide/api-key) ready.
2. Copy the address and model name from the matching guide. Do not mix configurations from different apps.
3. Back up existing settings first. Do not delete the whole configuration folder.

App not listed? Send support its name and a screenshot of its settings. Hide the key.

## 3. Choose a compatible model

| How you connect | What to choose |
| --- | --- |
| Claude Code or its editor extension | For these guides, use a Claude model in your group that supports Claude Code |
| Codex CLI | A GPT model and group confirmed to support Codex; not every GPT group does |
| CC Switch | Choose for its selected Claude Code or Codex app, not for CC Switch itself |
| Your own program | Select the endpoint using [model protocols](/en/developer/model-protocols) |

See [model protocols](/en/developer/model-protocols) for exact names. A model appearing in Model Square does not mean your key can use it in every app. If unsure, send support your app, model and group, not your complete key.
