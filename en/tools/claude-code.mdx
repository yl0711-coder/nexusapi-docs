---
title: "Install and configure Claude Code"
description: "Install for your system, enter a key and model, and test one message."
---

This setup uses your NexusAPI key. You do not need to sign in to an official Claude account for these requests.

## 1. Prepare and install

[Create an API key](/en/guide/api-key). In [Model Square](https://nexusapi.link/pricing), select its group and copy a Claude Code / Messages-compatible model name. On Windows, search Start for `PowerShell`. On Mac, use `Command + Space` to open Terminal.

Run only the installer for your system. Skip installation if Claude Code is already installed.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

Reopen the terminal after installation and run this. Continue when you see a version number. If the command is not found, reopen the terminal; send the installation error to support if it still fails.

```bash
claude --version
```

## 2. Open the configuration file

Use your system's command to open the user configuration:

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

On macOS / Linux, nano saves with `Ctrl + O`, Enter, then exits with `Ctrl + X`. In Windows Notepad, use `Ctrl + S`. Keep the name `settings.json`, not `.json.txt`.

## 3. Enter your key and model

For an empty file, paste the following. Replace `YOUR_API_KEY` with your complete key and `YOUR_MODEL_ID` with the copied model name. Keep the quotes and commas.

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

Back up an existing file and merge only `model` and `env`; do not erase other settings. You can use [CC Switch](/en/tools/cc-switch) instead. Keep keys out of project settings and screenshots.

## 4. Start and verify

Save, reopen the terminal in your own project folder, and run:

```bash
claude
```

Enter `/status`. Check `Anthropic base URL` is `https://nexusapi.link`, the credential source is `ANTHROPIC_AUTH_TOKEN`, and the model matches your setting.

Send “Reply only: connection successful. Do not modify files.” A complete reply and a matching [Usage Logs](https://nexusapi.link/usage-logs/common) record confirm setup. The test uses a little credit.

For `/login` or key errors, check the user-level file and replaced values, then restart. See [troubleshooting](/en/faq/self-check) for other errors. Do not delete the entire `.claude` folder.

Official project: [Claude Code](https://github.com/anthropics/claude-code).
