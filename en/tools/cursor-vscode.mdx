---
title: "Use Claude Code in VS Code or Cursor"
---

The official Claude Code extension provides graphical chat, diff previews, file references, and permission prompts. VS Code and Cursor use essentially the same setup.

## 1. Install the Extension

Before starting:

- Use VS Code 1.98 or later.
- Complete the [Claude Code setup](/en/tools/claude-code).
- Confirm that the NexusAPI token and Base URL work in `~/.claude/settings.json`.

Open the Extensions view, search for `Claude Code`, and verify that the publisher is **Anthropic**. You can also use the install links in the [official Claude Code VS Code guide](https://code.claude.com/docs/en/vs-code).

<Warning>
**Verify the publisher**

Similar third-party extensions may exist. Install `Claude Code` published by `Anthropic`.
</Warning>
## 2. Use the NexusAPI Configuration

The extension and CLI share `~/.claude/settings.json`. Do not duplicate the API key in VS Code or Cursor `settings.json`.

If the extension still shows a sign-in prompt:

1. Open editor settings.
2. Search for `Claude Code login`.
3. Enable **Disable Login Prompt**.
4. Fully restart the editor.

If the editor does not inherit your terminal environment, start VS Code from a configured terminal with:

```bash
code .
```

Cursor users can restart Cursor or run `claude` in Cursor's integrated terminal.

## 3. Open and Verify Claude Code

Open Claude Code from the editor icon, Activity Bar, Command Palette, or status bar. Then send a read-only test:

![Official Claude Code extension interface in VS Code](/images/nexusapi/claude-code-vscode-official.jpg)

> Interface example from the
> [official Claude Code VS Code documentation](https://code.claude.com/docs/en/vs-code).
> Button placement may change between extension versions.

```text
Explain what the current file does without modifying it.
```

If it responds normally, the extension is using the NexusAPI configuration.

When reporting a problem, keep the editor version, extension version, Claude Code version, original error, and Request ID.
