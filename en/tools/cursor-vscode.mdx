title: "Use Claude Code in VS Code / Cursor"
description: "Install the extension, enter your key in user settings, and test a message."
---

**This configures the Claude Code extension, not Cursor's built-in AI chat.** [Create a key](/en/guide/api-key), select the same group in [Model Square](https://nexusapi.link/pricing), and copy a Claude Code-compatible model name.

## 1. Install the extension

Press `Ctrl + Shift + X` (Mac: `Command + Shift + X`). Search for `Claude Code`, confirm publisher **Anthropic**, then install.

![Official Marketplace: Claude Code for VS Code, publisher Anthropic](/images/nexusapi/claude-extension-marketplace.png)

Use this official Marketplace listing to check the name and publisher, then install the matching extension in your editor.

## 2. Open user settings

Press `Ctrl + Shift + P` (Mac: `Command + Shift + P`) and choose **Preferences: Open User Settings (JSON)**. Use user settings, not workspace settings, defaults or a project's `.vscode/settings.json`.

## 3. Enter the NexusAPI settings

Replace `YOUR_API_KEY` with your complete key and `YOUR_MODEL_ID` with the model name you copied. Keep the rest unchanged.

```json
{
  "claudeCode.disableLoginPrompt": true,
  "claudeCode.environmentVariables": [
    {
      "name": "ANTHROPIC_BASE_URL",
      "value": "https://nexusapi.link"
    },
    {
      "name": "ANTHROPIC_AUTH_TOKEN",
      "value": "YOUR_API_KEY"
    },
    {
      "name": "ANTHROPIC_MODEL",
      "value": "YOUR_MODEL_ID"
    }
  ]
}
```

Back up existing settings and merge the `claudeCode` entries above without deleting other settings. If the file is only `{}`, replace it directly.

Save; you do not need to sign in to the official account for these requests. These settings contain your personal key: do not put them in a project or share or sync them with others.

![User settings example: configure only the two `claudeCode` entries. The appearance and demo-window settings below are not needed. Replace placeholders; this image does not demonstrate a successful connection.](/images/nexusapi/vscode-user-settings-demo.png)

## 4. Restart and test

Fully quit and reopen the editor. Open Claude Code, start a conversation and send “Reply only: connection successful. Do not modify files.” Check for a complete reply and a record in [Usage Logs](https://nexusapi.link/usage-logs/common). Testing uses a small amount of credit.

Still seeing official sign-in? Check user settings and replaced values, update the extension and restart. VS Code users can install from the [official extension marketplace](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code). If Cursor cannot find the extension, use the editor terminal with the [Claude Code guide](/en/tools/claude-code).

Official links: [Claude Code project](https://github.com/anthropics/claude-code) · [VS Code extension marketplace](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code).
