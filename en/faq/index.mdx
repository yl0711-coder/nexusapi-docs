First, choose the phenomenon closest to you. When encountering a call error, please save the Request ID and the full error text first.

## Access and configuration

- **Where to start using it for the first time?**
  Read on[Start quickly in 5 minutes](/en/guide/quick-start)。

- **Which base URL should be filled?**
  Different clients may have different rates, please check[Overview of access methods](/en/guide/integration-overview)。

- **Why did 404 appear?**
  Check if the address is formed `/v1/v1/...`, and whether the client automatically concatenates the request path.

- **Can I not use the API Key after creation?**
  Check Key status, amount, grouping, model ID, and `Authorization: Bearer` Format.

## Models, groupings, and costs

- **How do you confirm whether a group can use the target model?**
  Exist[Model Square](https://nexusapi.link/pricing)Filter and replicate accurate model IDs by group.

- **How much does a single request consume?**
  View input, output, cache, and spend in the console usage log. See field descriptions[Dosage and log description](/en/billing/usage-and-billing)。

- **Will a failed request be charged?**
  Errors without generating valid content are usually zero; if there is interruption or subsequent attempts, verification must be made using the Request ID.

- **Why does the balance remain normal, but the quota is insufficient?**
  Also check account balance, API Key limit, and grouping; Submit the Request ID when it persists.

## Invocation error

- **What are 400, 401, 429, 500, 502, 503, 504, 524?**
  View[API Call FAQ](/en/faq/common-errors)。

- **Suddenly unable to continue a long conversation?**
  Save the original error text and create a new session for verification; Do not repeatedly submit the same request frequently.

- **After the mistake, the mission succeeded again?**
  Subsequent attempts may occur; please refer to the final record with the same Request ID and the client's final result.

## Get help quickly

If you cannot determine the type of problem, press [Self-check the issue](/en/faq/self-check)Complete minimum verification and submit it all at once:

- Request ID
- Time and time zone of occurrence
- Client and Version
- Model and request interface
- Complete error in the original text
- The question is whether it happens occasionally or continuously

Do not submit complete API Keys, passwords, or private data.
