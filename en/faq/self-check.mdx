---
title: "What to do when an error appears"
description: "Save the error, check your setup and contact support if it still fails."
---

**Take a screenshot first. Follow the checks below, or contact support directly if unsure.**

## 1. Save the error

Keep the app name, time, model, group and error screenshot. Copy a Request ID if available; do not guess. Hide full keys, passwords and private business content.

## 2. Check the message

| Message | What to do |
| --- | --- |
| Key error / 401 | Copy the full key again, paste it and restart the app |
| 403 | Ask support to check the model and group |
| 404 | Copy the address from [your app guide](/en/tools) |
| 400 / not implemented | Ask support whether this model works with your app |
| 429 / concurrency limit | Wait for current requests to finish, reduce simultaneous tasks and try once |
| 500 / 502 / 503 / timeout | Wait 10–30 seconds and try once; then contact support if needed |
| no available channel | Check the model in your group; contact support rather than topping up again |
| Insufficient credit | Check wallet credit, key limit and expiry |

## 3. Try one short message

Save important content, start a new conversation and send “Reply: hello”. If a complete reply arrives, use the new conversation. If not, contact support. **The test may use credit. Do not retry repeatedly or delete the entire configuration folder.**

## 4. Copy this to support

```text
App name:
Time:
Model and group:
Error text or screenshot:
Request ID (if available):
```

Leave unknown fields blank. Never send full keys, passwords or verification codes.
