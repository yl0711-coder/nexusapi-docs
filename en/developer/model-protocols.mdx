Find the exact model name below and select its recommended protocol. Preserve capitalization, dates, and suffixes.

The table lists currently selectable models and their recommended protocols. Access depends on your API key group.

## Choose a protocol

| Models you use | Start with | Request path |
| --- | --- | --- |
| Claude | Anthropic Messages | `/v1/messages` |
| GPT in a group supporting Responses | Responses | `/v1/responses` |
| GPT groups confirmed only for Chat Completions; DeepSeek, GLM, Kimi, Qwen, Grok | Chat Completions | `/v1/chat/completions` |

<Warning>
Confirm that your model is available in your API key group. If your client supports only one protocol, choose a model and group that both support it.
</Warning>

For the `gpt-5.6x` group, start with Chat Completions. If you need Responses, ask support to confirm it first.

## Client setup and checks

1. For Claude Code, follow the [setup guide](/en/tools/claude-code) and use `https://nexusapi.link` as the base URL.
2. For Codex CLI, follow the [setup guide](/en/tools/codex-cli) with Responses. Both the model and its group must support it.
3. For Chat Completions programs, follow the [code examples](/en/developer/code-examples). Set the OpenAI SDK base URL to `https://nexusapi.link/v1`.

If the model or protocol is missing, check the [capability matrix](/en/developer/capability-matrix), then send support the model name, key group, client, and Request ID. Never send the full key.
