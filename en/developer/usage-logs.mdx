## Query the usage log

```http
GET /v1/logs?page=1&page_size=50[&start_time=..&end_time=..]
```

### Request parameters (all optional)

| Parameters | Type | Explanation |
| --- | --- | --- |
| `page` | integer | Page numbers start from 1, default is 1 |
| `page_size` | integer | Number of entries per page: default 10, maximum 50 |
| `start_time` | string/int | Start time, Unix seconds (e.g., `1717200000`) or RFC3339 (e.g., `2026-06-01T00:00:00Z`） |
| `end_time` | string/int | End time, format as above |

Constraints:`page × page_size ≤ 100000`(Page Turn Depth Limit); There is no limit to the time window span.

### Return Example (200)

```json
{
  "data": [
    {
      "time": "2026-06-20T14:03:11Z", "token_name": "我的密钥", "group": "default",
      "model": "gpt-5.5", "use_time": 3, "first_byte": 0.8,
      "prompt_tokens": 1200, "completion_tokens": 800, "cost": 0.012,
      "ip": "1.2.3.4", "request_id": "2026xyzreq",
      "request_path": "/v1/chat/completions"
    }
  ],
  "page": 1, "page_size": 10
}
```

| Field | Explanation |
| --- | --- |
| `time` | Request time (UTC, RFC3339) |
| `token_name` | The name of the API Key used this time |
| `group` | Token grouping |
| `model` | Model name |
| `use_time` | Total time spent (seconds) |
| `first_byte` | First character time (seconds); This is used when there is no initial character in non-flow forms `null` |
| `prompt_tokens` / `completion_tokens` | Number of tokens input/output |
| `cost` | Amount spent this time (USD) |
| `ip` | Source: IP |
| `request_id` | Request ID |
| `request_path` | Call path |

**A page returns fewer than 'page_size' (or empty), i.e., the last page.**

## Examples of calls

```bash
curl -H "Authorization: Bearer <你的系统访问令牌>" \
  "https://api.nexusapi.link/v1/logs?page=1&page_size=50&start_time=1717200000&end_time=1717804800"
```

Page Flip Full Volume (Pseudocode):

```text
page = 1
while True:
    resp = GET /v1/logs?page=page&page_size=50
    处理 resp.data
    if len(resp.data) < 50: break   # 某页不满即最后一页
    page += 1
```

## Error code

| HTTP | error | Meaning |
| --- | --- | --- |
| 400 | `invalid_request` | Parameters are invalid (page turns too deep / time format is incorrect / time order is incorrect) |
| 401 | `unauthorized` | Token missing / invalid / account disabled |
| 429 | `rate_limited` | Requests are too frequent (response bands). `Retry-After`, please follow the prompts to step back) |
| 503 | `unavailable` | The service is temporarily unavailable (with a band of money). `Retry-After`） |
| 500 | `internal_error` | Internal errors |

## Usage recommendations

- The time is **UTC**；`cost` In US dollars.
- Using pagination (`page_size` Maximum 50) + time window segmented pulling,**Do not frequently poll**； For audit scenarios, it's recommended to tap 'yesterday' once a day.
- Only HTTPS is supported.
