Using Claude Code, Codex or CC Switch? Follow [your app's guide](/en/tools) instead.

## 1. Have a key and model ready

[Create an API key](/en/guide/api-key). In [Model Square](https://nexusapi.link/pricing), select that same group and copy a model name that supports Chat Completions. Ask support if unsure.

Open a terminal. Replace only `YOUR_API_KEY` and `YOUR_MODEL_ID` below. Run later commands in this same terminal; set the values again after closing it.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
$env:NEXUSAPI_MODEL = "YOUR_MODEL_ID"
```
</Tab>
<Tab title="macOS / Linux">
```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
export NEXUSAPI_MODEL='YOUR_MODEL_ID'
```
</Tab>
</Tabs>

## 2. Run one example

Choose just one option. Save files in your own test folder, not under the names `openai.py` or `openai.mjs`.

<Tabs>
<Tab title="Python">
Install [Python 3](https://www.python.org/downloads/) first. Open a terminal in your test folder and install the dependency using your system's commands.

<Tabs>
<Tab title="Windows">
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install openai
```
</Tab>
<Tab title="macOS / Linux">
```bash
python3 -m venv .venv
.venv/bin/python -m pip install openai
```
</Tab>
</Tabs>

Create `demo.py`, paste the complete code and save:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["NEXUSAPI_API_KEY"],
    base_url="https://nexusapi.link/v1",
)
response = client.chat.completions.create(
    model=os.environ["NEXUSAPI_MODEL"],
    messages=[{"role": "user", "content": "Reply only: connection successful"}],
)
print(response.choices[0].message.content)
```

Run in the same terminal:

<Tabs>
<Tab title="Windows">
```powershell
.\.venv\Scripts\python.exe demo.py
```
</Tab>
<Tab title="macOS / Linux">
```bash
.venv/bin/python demo.py
```
</Tab>
</Tabs>
</Tab>
<Tab title="JavaScript">
Install [Node.js LTS](https://nodejs.org/en/download), reopen the terminal and set the two variables above again. Then run:

```bash
npm install openai
```

Create `demo.mjs` (not `.txt`), paste and save:

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.NEXUSAPI_API_KEY,
  baseURL: "https://nexusapi.link/v1",
});
const response = await client.chat.completions.create({
  model: process.env.NEXUSAPI_MODEL,
  messages: [{role: "user", content: "Reply only: connection successful"}],
});
console.log(response.choices[0].message.content);
```

Run:

```bash
node demo.mjs
```
</Tab>
<Tab title="HTTP / cURL">
No SDK needed. Use the command for your system:

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$body = @{
  model = $env:NEXUSAPI_MODEL
  messages = @(@{role = "user"; content = "Reply only: connection successful"})
} | ConvertTo-Json -Depth 5
$result = Invoke-RestMethod -Method Post -Uri "https://nexusapi.link/v1/chat/completions" -Headers @{Authorization = "Bearer $env:NEXUSAPI_API_KEY"} -ContentType "application/json" -Body $body
$result.choices[0].message.content
```
</Tab>
<Tab title="macOS / Linux">
```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H "Authorization: Bearer $NEXUSAPI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d "{\"model\":\"$NEXUSAPI_MODEL\",\"messages\":[{\"role\":\"user\",\"content\":\"Reply only: connection successful\"}]}"
```
</Tab>
</Tabs>
</Tab>
</Tabs>

## 3. Check the result

A complete reply such as `connection successful` means the basic connection works. Check the request in [Usage Logs](https://nexusapi.link/usage-logs/common). The test uses a small amount of credit.

On errors, check that placeholders were replaced, the key has no asterisks and the model belongs to your group. If it still fails, send support the error and time, not your key.

SDK installation reference: [OpenAI SDK](https://developers.openai.com/api/docs/libraries).
