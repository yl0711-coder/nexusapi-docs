The model, key group, and protocol used with NexusAPI must all match. Use the Model Square and the result returned by your current key as the live source of truth.

<Info>
**Confirm before you call**

1. Confirm that the model is in your key's key group in the Model Square.
2. Confirm that `supported_endpoint_types` returned by `/v1/models` includes the protocol you need.
3. Use `/v1/models` to see what the key can actually access, then send a minimal request.
</Info>

## Publicly documented capabilities

| Goal | Endpoint / protocol | When to use it | Important limit |
| --- | --- | --- | --- |
| List models visible to the current key | [GET /v1/models](/en/developer/api-basics) | After creating a key and before selecting a model | It reflects the key's group and restrictions, not every model on the site. |
| Text, chat, and streaming | [POST /v1/chat/completions](/en/developer/openai-compatible) | OpenAI-compatible SDKs, scripts, and most text models | Use only a model whose `supported_endpoint_types` includes `openai`. |
| Claude Code or a native Anthropic client | [POST /v1/messages](/en/developer/anthropic-messages) | `supported_endpoint_types` includes `anthropic` | Do not append `/v1` again in the Claude Code base URL. |
| Codex CLI | [POST /v1/responses](/en/developer/responses) | The provider is configured as described in the [Codex guide](/en/tools/codex-cli) | Use only a model whose `supported_endpoint_types` includes `openai-response`. |

<Warning>
Image-generation models are not currently offered. Ask support before using any capability not listed here.
</Warning>

## Check models with the current key

```bash
curl 'https://nexusapi.link/v1/models' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

Copy a model ID from `data[].id`. `data[].supported_endpoint_types` lists the request protocols available for that model: `openai` for Chat Completions, `anthropic` for Messages, `openai-response` for Responses. A model can list more than one type; choose from that field for your client rather than guessing from a model name.

`/v1/models` is a point-in-time view for one key. The Model Square shows prices, groups, and descriptions. If they differ, follow the current key result and console state.

## A simple protocol rule

| You are using | Start with |
| --- | --- |
| Python, JavaScript, cURL, or an OpenAI-compatible SDK | `/v1/chat/completions` (first confirm that the field includes `openai`) |
| Claude Code | The Messages configuration in the [Claude Code guide](/en/tools/claude-code) (first confirm that the field includes `anthropic`) |
| Codex CLI | The Responses provider in the [Codex CLI guide](/en/tools/codex-cli) (first confirm that the field includes `openai-response`) |

If a model is visible but the call still fails, check its ID, your key group, and the request path first. Keep the Request ID and use the [self-check guide](/en/faq/self-check).
