**Làm theo 4 bước dưới đây. Bỏ qua bước đã hoàn thành.**

## 1. Đăng nhập và kiểm tra số dư

Mở [trang đăng nhập](https://nexusapi.link/sign-in). Chưa có tài khoản thì liên hệ hỗ trợ.

Mở [Ví](https://nexusapi.link/wallet). Có số dư hoặc gói còn dùng được thì tiếp tục; nếu chưa có, hãy [nạp tiền](/vi/guide/recharge).

## 2. Tạo và sao chép khóa API

1. Mở [Khóa API](https://nexusapi.link/keys), chọn **Tạo Khóa API**.
2. Điền tên, chọn nhóm do hỗ trợ cung cấp, số lượng là `1`. Không có yêu cầu riêng thì giữ mặc định các mục còn lại.
3. Chọn **Lưu thay đổi**.
4. Trở lại danh sách và bấm nút sao chép khóa vừa tạo.

Cần xem hình? Mở [hướng dẫn tạo khóa](/vi/guide/api-key). **Không gửi khóa đầy đủ cho người khác.**

## 3. Cấu hình phần mềm đang dùng

Kiểm tra bốn mục trước khi mở hướng dẫn:

| Mục | Cách xác nhận |
| --- | --- |
| Phần mềm | Công cụ dòng lệnh, tiện ích trình soạn thảo hay chương trình tự viết |
| Nhóm | Nhóm của khóa mới; lần đầu dùng nhóm hỗ trợ cung cấp |
| Tên mô hình | Chọn cùng nhóm trong Quảng trường mô hình rồi sao chép tên tương thích |
| Địa chỉ API | Sao chép từ đúng hướng dẫn, không tự thêm đường dẫn |

| Bạn dùng gì | Hướng dẫn |
| --- | --- |
| Claude Code | [Cấu hình Claude Code](/vi/tools/claude-code) |
| Codex CLI | [Cấu hình Codex CLI](/vi/tools/codex-cli) |
| CC Switch | [Cấu hình CC Switch](/vi/tools/cc-switch) |
| VS Code / Cursor | [Cấu hình trình soạn thảo](/vi/tools/cursor-vscode) |
| Chương trình tự viết | [Mã mẫu có thể sao chép](/vi/developer/code-examples) |

Không tiện sửa tệp? Dùng [CC Switch](/vi/tools/cc-switch) sau khi cài Claude Code hoặc Codex CLI cần dùng. Cùng khóa hoặc nhóm không có nghĩa mọi mô hình đều dùng được với mọi phần mềm. Xem [giao thức đề xuất](/vi/developer/model-protocols), hoặc gửi phần mềm, mô hình và nhóm cho hỗ trợ.

**Lấy địa chỉ và tên mô hình từ đúng hướng dẫn, rồi điền khóa của bạn. Mỗi phần mềm có thể cần địa chỉ khác nhau.**

## 4. Gửi một câu thử

Trong hội thoại mới, gửi: **“Chỉ trả lời: kết nối thành công. Không sửa tệp.”**

Sau khi nhận đủ câu trả lời, kiểm tra bản ghi, mô hình và nhóm trong [Nhật ký sử dụng](https://nexusapi.link/usage-logs/common). Chỉ có câu trả lời chưa chứng minh yêu cầu đi qua NexusAPI. Lượt thử dùng một ít hạn mức.

Nếu lỗi, gửi tên phần mềm, ảnh lỗi, thời gian, mô hình và nhóm cho hỗ trợ. Che toàn bộ khóa.
