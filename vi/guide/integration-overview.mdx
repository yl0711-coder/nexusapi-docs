NexusAPI có thể được dùng từ ứng dụng tự viết, client tương thích OpenAI hoặc công cụ lập trình. Mỗi client ghép URL và dùng giao thức khác nhau. Hãy chọn theo tình huống, không sao chép nguyên cấu hình từ công cụ này sang công cụ khác.

## Ba bước kiểm tra trước khi kết nối

1. Tạo API Key trong console và đặt giới hạn phù hợp.
2. Xác nhận nhóm token của khóa có mô hình cần dùng.
3. Sao chép chính xác model ID từ Chợ mô hình hoặc `/v1/models`.

## URL và giao thức

| Tình huống | Base URL | Điểm bắt đầu | Lưu ý |
| --- | --- | --- | --- |
| SDK tương thích OpenAI / ứng dụng chung | `https://nexusapi.link/v1` | Chat Completions | SDK thường tự nối `/chat/completions`. |
| Claude Code | `https://nexusapi.link` | Anthropic Messages | Không thêm `/v1`. |
| Codex CLI | `https://nexusapi.link/v1` | Responses | Dùng custom provider của Codex. |
| Mô hình ảnh | `https://nexusapi.link/v1` | Images | Chỉ dùng với mô hình được ghi rõ là hỗ trợ ảnh. |

<Warning>
Mô hình hiển thị không có nghĩa là nó dùng được với mọi giao thức. Hãy đọc [ma trận API và khả năng mô hình](/vi/developer/capability-matrix) trước: trang này nêu các endpoint mà NexusAPI công bố hỗ trợ.
</Warning>

## Kiểm tra tối thiểu

1. Gọi `GET /v1/models` bằng khóa hiện tại.
2. Chọn ID được trả về và phù hợp giao thức.
3. Gửi một yêu cầu văn bản ngắn.
4. Kiểm tra bản ghi tương ứng trong console.

Nếu lỗi, lưu toàn bộ lỗi và Request ID rồi làm [tự kiểm tra](/vi/faq/self-check). Không gửi lặp một tác vụ trong vòng lặp.
