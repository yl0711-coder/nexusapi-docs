NexusAPI hỗ trợ các ứng dụng khách AI phổ biến và API theo kiểu OpenAI. Mỗi công cụ có thể tự nối thêm một phần đường dẫn, vì vậy hãy điền địa chỉ đúng với cách sử dụng của bạn; không sao chép nguyên cấu hình của một công cụ sang công cụ khác.

## Chuẩn bị trước khi tích hợp

Dù chọn cách tích hợp nào, hãy xác nhận rằng:

1. Bạn đã tạo API Key trong bảng điều khiển.
2. Nhóm của API Key đó có quyền dùng mô hình mục tiêu.
3. Bạn đã sao chép chính xác model ID từ Chợ mô hình.
4. Bạn đã kiểm tra loại API mà mô hình hỗ trợ và gửi yêu cầu qua HTTPS.

## Đối chiếu URL và giao thức

| Tình huống | Địa chỉ cần điền | Giao thức chính | Lưu ý |
| --- | --- | --- | --- |
| OpenAI SDK / ứng dụng văn bản thông thường | `https://nexusapi.link/v1` | Chat Completions | SDK hoặc ứng dụng sẽ nối đường dẫn yêu cầu. |
| Codex CLI | `https://nexusapi.link/v1` | Responses | Dùng cấu hình Provider trong hướng dẫn Codex. |
| Claude Code | `https://nexusapi.link` | Anthropic Messages | Không thêm lặp lại `/v1` vào địa chỉ cấu hình. |
| CC Switch | Theo loại Provider | Phụ thuộc công cụ đích | Quy tắc URL của Claude và Codex khác nhau. |
| Mô hình ảnh | `https://nexusapi.link/v1` | Images | Chỉ dùng mô hình được ghi rõ là hỗ trợ tạo ảnh. |

Bảng này giúp chọn phương án tích hợp. Trước tiên, hãy xem [ma trận khả năng API và mô hình](/vi/developer/capability-matrix) để xác nhận mô hình và giao thức; xem [Chat Completions](/vi/developer/openai-compatible) để biết tham số và cấu trúc phản hồi. Khả năng sử dụng thực tế của một Key và mô hình vẫn lấy Chợ mô hình làm chuẩn.

## Chọn đúng giao thức trước

Cùng một Base URL không có nghĩa mọi mô hình đều chấp nhận cùng một định dạng yêu cầu.

| Mục tiêu | Endpoint khuyến nghị | Dùng khi |
| --- | --- | --- |
| Văn bản, hội thoại hoặc streaming thông thường | `/v1/chat/completions` | Mô hình dùng được qua tuyến tương thích OpenAI. |
| Codex CLI và Provider tương ứng | `/v1/responses` | Chỉ dùng khi `supported_endpoint_types` chứa `openai-response`. |
| Claude Code hoặc client Anthropic gốc | `/v1/messages` | Chỉ dùng khi `supported_endpoint_types` chứa `anthropic`. |
| Tạo ảnh | `/v1/images/generations` | Mô hình được ghi rõ là hỗ trợ tạo ảnh. |

<Warning>
**Không dùng Responses như endpoint thay thế chung**

Nếu `supported_endpoint_types` của model không chứa `openai-response` nhưng `/v1/responses` trả `status_code=500, not implemented`, giao thức không khớp. Hãy dùng endpoint được nêu cho model đó; Claude Code giữ cấu hình Messages gốc. Gửi lại đúng yêu cầu đó không khắc phục sự không tương thích giao thức.
</Warning>

## Vì sao URL có thể trông khác nhau

Yêu cầu theo kiểu OpenAI thông thường dùng:

```text
https://nexusapi.link/v1
```

Một số client yêu cầu URL trang web không có `/v1`, hoặc tự thêm `/chat/completions`, `/responses`, `/messages`. Hãy làm theo hướng dẫn của công cụ tương ứng; với mô hình ảnh, xem [hướng dẫn mô hình ảnh](/vi/guide/image-generation).

<Warning>
**Tránh lặp đường dẫn**

Nếu client đã tự thêm `/v1`, việc tự nhập thêm có thể tạo thành `/v1/v1/...` và gây lỗi 404. Khi gặp 404, trước hết hãy kiểm tra URL yêu cầu thực tế mà client gửi đi.
</Warning>

## Không trộn cấu hình client với API thông thường

Công cụ CLI, tiện ích editor và ứng dụng tự xây dựng có thể dùng giao thức và tệp cấu hình khác nhau. Dù model name giống nhau, không được áp nguyên cấu hình của một công cụ sang công cụ khác.

- **Codex CLI:** đọc [hướng dẫn Codex CLI](/vi/tools/codex-cli) và dùng cấu hình Responses của nó.
- **Claude Code:** đọc [hướng dẫn Claude Code](/vi/tools/claude-code) và giữ cấu hình Anthropic Messages gốc.
- **Ứng dụng văn bản tự xây dựng:** bắt đầu bằng Chat Completions, trừ khi SDK yêu cầu rõ một giao thức khác.
- **Tạo ảnh:** dùng endpoint ảnh; không gửi tham số tạo ảnh đến endpoint chat văn bản.
- **Khi chưa chắc chắn:** xác định tên client chính xác và đường dẫn mà nó thực sự gửi trước khi đổi cấu hình.

## Tài liệu tham khảo API

Hãy dùng [ma trận khả năng API và mô hình](/vi/developer/capability-matrix) để xác nhận giao thức phù hợp với mô hình mục tiêu. Yêu cầu Chat Completions tối thiểu được trình bày tại [Chat Completions](/vi/developer/openai-compatible).

Trung tâm trợ giúp này giải thích cách chọn và cấu hình tích hợp, đồng thời cung cấp yêu cầu tối thiểu có thể kiểm chứng. Các tham số tùy chọn vẫn phụ thuộc vào giao thức của client và khả năng hiện hiển thị trong Chợ mô hình.

## Cách xác nhận cấu hình thành công

- Client trả về một phản hồi hoàn chỉnh.
- Yêu cầu tương ứng xuất hiện trong nhật ký sử dụng của bảng điều khiển.
- Mô hình, nhóm và khoản phí trong nhật ký đúng như mong đợi.

Nếu gọi thất bại, hãy lưu nguyên văn lỗi và Request ID, sau đó xem [tự kiểm tra sự cố](/vi/faq/self-check).
