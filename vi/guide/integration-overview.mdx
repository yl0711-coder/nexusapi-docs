## 1. Tìm phần mềm của bạn

| Bạn muốn làm gì | Hướng dẫn |
| --- | --- |
| Dùng Claude Code | [Claude Code](/vi/tools/claude-code) |
| Dùng Codex CLI | [Codex CLI](/vi/tools/codex-cli) |
| Chuyển dịch vụ bằng CC Switch | [CC Switch](/vi/tools/cc-switch) |
| Dùng VS Code / Cursor | [Trình soạn thảo](/vi/tools/cursor-vscode) |
| Viết chương trình | [Mã mẫu](/vi/developer/code-examples) |

## 2. Chuẩn bị ba thông tin

| Cần điền | Lấy ở đâu |
| --- | --- |
| khóa API | Tạo và sao chép tại [Khóa API](https://nexusapi.link/keys) |
| Tên mô hình | Trong [Quảng trường mô hình](https://nexusapi.link/pricing), chọn nhóm của khóa rồi sao chép tên |
| Địa chỉ API | Sao chép từ đúng hướng dẫn phía trên, không tự ghép |

Claude Code thường dùng `https://nexusapi.link`; Codex CLI và OpenAI SDK thường dùng `https://nexusapi.link/v1`. **Ưu tiên hướng dẫn của phần mềm đang dùng.**

## 3. Kiểm tra hoạt động

Gửi “Hãy trả lời: kết nối thành công.” Nhận đủ câu trả lời là xong. Nếu chưa được, xem [tự kiểm tra lỗi](/vi/faq/self-check) hoặc gửi ảnh lỗi cho hỗ trợ. Che khóa API đầy đủ trong ảnh.
