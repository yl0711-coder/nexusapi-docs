Dùng API này khi `supported_endpoint_types` trong `/v1/models` của khóa hiện tại chứa `anthropic`. Hãy xem [ma trận khả năng](/vi/developer/capability-matrix) trước: **mô hình, nhóm của khóa và giao thức phải cùng khớp**.

<Warning>
**Phạm vi sử dụng Messages**

API này chỉ phù hợp với mô hình có `supported_endpoint_types` chứa `anthropic`. Ứng dụng tương thích OpenAI nên dùng [Chat Completions](/vi/developer/openai-compatible); nếu không có `anthropic`, hãy chọn giao thức mà mô hình hỗ trợ. `not implemented` thường lỗi không tương thích giao thức, không phải lỗi tạm thời có thể giải quyết bằng retry.
</Warning>

## Endpoint và yêu cầu tối thiểu

```text
POST https://nexusapi.link/v1/messages
```

```bash
curl 'https://nexusapi.link/v1/messages' \
  -H 'Content-Type: application/json' \
  -H 'x-api-key: YOUR_API_KEY' \
  -H 'anthropic-version: 2023-06-01' \
  -d '{
    "model": "YOUR_ANTHROPIC_MODEL_ID",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Xin chào"}]
  }'
```

| Mục | Bắt buộc | Ghi chú |
| --- | --- | --- |
| `model` | Có | ID mô hình chính xác mà khóa hiện tại nhìn thấy, có `supported_endpoint_types` chứa `anthropic` |
| `max_tokens` | Có | Số token đầu ra tối đa cho yêu cầu này |
| `messages` | Có | Hội thoại theo định dạng Anthropic Messages |
| `anthropic-version` | Giao thức gốc yêu cầu | SDK tự quản lý; khi gọi thủ công dùng phiên bản tương thích |

Xem tài liệu giao thức của ứng dụng khách Anthropic đang dùng để biết toàn bộ trường, các lệnh gọi công cụ, phản hồi dạng luồng và cấu trúc phản hồi. Khả năng của trường tùy chọn vẫn phụ thuộc mô hình và khả năng hiện tại của nó.

## Dùng Anthropic SDK

SDK gốc tự quản lý các header giao thức cần thiết. Truyền khóa NexusAPI vào SDK và đặt Base URL **không có `/v1`**:

```python
from anthropic import Anthropic

client = Anthropic(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link",
)

message = client.messages.create(
    model="YOUR_ANTHROPIC_MODEL_ID",
    max_tokens=256,
    messages=[{"role": "user", "content": "Xin chào"}],
)
```

SDK tự thêm `/v1/messages`. Không đặt `base_url` là `https://nexusapi.link/v1/messages`, vì có thể lặp đường dẫn hoặc gây 404.

## Claude Code và ứng dụng tự viết

| Tình huống | Cấu hình |
| --- | --- |
| Claude Code | Theo [hướng dẫn Claude Code](/vi/tools/claude-code): đặt `ANTHROPIC_BASE_URL=https://nexusapi.link` và `ANTHROPIC_AUTH_TOKEN` trong `~/.claude/settings.json` |
| Anthropic SDK / ứng dụng gốc | Base URL là `https://nexusapi.link`, để ứng dụng khách gửi Messages |
| Ứng dụng dùng OpenAI SDK | Không trộn cấu hình này; dùng [Chat Completions](/vi/developer/openai-compatible) |

## Khắc phục sự cố

- `401`: kiểm tra khóa đúng, đang hoạt động và chưa bị reset sau khi lộ.
- `404`: kiểm tra SDK có tự thêm `/v1` lần thứ hai hay không.
- `400`: kiểm tra chỉ với `model`, `max_tokens`, `messages` trước rồi thêm dần trường tùy chọn.
- `500, not implemented`: xác nhận `supported_endpoint_types` chứa `anthropic` và yêu cầu dùng đúng endpoint tương ứng.

Nếu lỗi kéo dài, lưu Request ID và yêu cầu đã che thông tin, sau đó làm theo [tự kiểm tra](/vi/faq/self-check).
