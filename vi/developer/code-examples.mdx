Các ví dụ dùng OpenAI Chat Completions. Trước tiên xác nhận giao thức trong [ma trận khả năng](/vi/developer/capability-matrix), sau đó sao chép model ID chính xác mà key hiện tại dùng được.

## Thiết lập cơ bản

- Base URL: `https://nexusapi.link/v1`
- API Key: tạo trong [console NexusAPI](https://nexusapi.link)
- Model ID: giá trị chính xác trong Chợ mô hình hoặc `/v1/models`

## Python

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://nexusapi.link/v1",
)

response = client.chat.completions.create(
    model="YOUR_MODEL_ID",
    messages=[{"role": "user", "content": "Hãy tự giới thiệu ngắn gọn."}],
)

print(response.choices[0].message.content)
```

## JavaScript

```js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.NEXUSAPI_API_KEY,
  baseURL: "https://nexusapi.link/v1",
});

const response = await client.chat.completions.create({
  model: "YOUR_MODEL_ID",
  messages: [{ role: "user", content: "Hãy tự giới thiệu ngắn gọn." }],
});

console.log(response.choices[0].message.content);
```

## cURL

```bash
curl 'https://nexusapi.link/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -d '{"model":"YOUR_MODEL_ID","messages":[{"role":"user","content":"Kiểm tra kết nối"}]}'
```

Không ghi key thật vào mã nguồn hoặc kho lưu trữ. Tạo ảnh dùng endpoint khác; xem [hướng dẫn mô hình ảnh](/vi/guide/image-generation).
