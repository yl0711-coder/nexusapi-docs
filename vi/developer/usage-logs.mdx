title: "API nhật ký sử dụng"
description: "Đọc chi tiết sử dụng NexusAPI của tài khoản bằng mã truy cập hệ thống với tần suất thấp."
---

`api.nexusapi.link` là cổng nhật ký **chỉ đọc**, tách biệt với console và relay mô hình. Nó chỉ đọc nhật ký tiêu thụ của tài khoản sở hữu token; không thể gọi mô hình, nạp credit hay thực hiện thao tác quản trị.

## Thông tin cơ bản

| Mục | Giá trị |
| --- | --- |
| Base URL | `https://api.nexusapi.link` |
| Endpoint | `GET /v1/logs` |
| Thông tin xác thực khuyến nghị | Mã truy cập hệ thống |
| Thứ tự | Bản ghi mới nhất trước |

Tạo mã trong **Console → Cài đặt cá nhân → Tạo token**, rồi chỉ gửi qua Header:

```http
Authorization: Bearer YOUR_SYSTEM_ACCESS_TOKEN
```

<Warning>
Gọi mô hình dùng API Key tạo trong Quản lý token; API nhật ký nên dùng mã truy cập hệ thống. Mã này không gọi được mô hình nhưng có thể đọc dữ liệu cấp tài khoản, nên vẫn phải được giữ bí mật.
</Warning>

## Tham số

| Tham số | Ý nghĩa |
| --- | --- |
| `start_time` | Thời gian bắt đầu dạng Unix giây hoặc RFC3339. |
| `end_time` | Thời gian kết thúc dạng Unix giây hoặc RFC3339, không sớm hơn bắt đầu. |
| `page` | Số trang từ `1`. |
| `page_size` | Số bản ghi/trang, mặc định `10`, tối đa `50`. |

Nên truy vấn từng ngày hoặc tuần. Không có bộ lọc server theo mô hình, nhóm hoặc tên key; hãy lọc dữ liệu tài khoản ở phía bạn. `page × page_size` không được vượt `100000`.

```bash
curl -G 'https://api.nexusapi.link/v1/logs' \
  -H 'Authorization: Bearer YOUR_SYSTEM_ACCESS_TOKEN' \
  --data-urlencode 'start_time=2026-06-01T00:00:00Z' \
  --data-urlencode 'end_time=2026-06-02T00:00:00Z' \
  --data-urlencode 'page=1' \
  --data-urlencode 'page_size=50'
```

`data` rỗng hoặc ít hơn `page_size` là trang cuối. Các trường hữu ích gồm `time`, `token_name`, `group`, `model`, `prompt_tokens`, `completion_tokens`, `cost`, `request_id`, `request_path`. Với 429/503, tuân theo `Retry-After`; dùng đồng bộ tăng dần có lịch, không polling từng giây.
