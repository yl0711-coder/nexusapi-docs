## Cần hỗ trợ?

Gửi cho bộ phận hỗ trợ:

- Tên phần mềm đang dùng.
- Thời gian, mô hình và nhóm.
- Nguyên văn lỗi hoặc ảnh, kèm Request ID nếu có.

**Che khóa API đầy đủ trong ảnh. Không gửi mật khẩu hoặc mã xác minh.** Thông tin chưa rõ không cần đoán; cứ gửi lỗi đang thấy trước.
