## Ba thông tin cần để kết nối

| Thông tin | Lấy ở đâu | Mục đích |
| --- | --- | --- |
| Base URL | Tài liệu này | Gửi yêu cầu đến NexusAPI |
| API Key | Bảng điều khiển → Quản lý token | Xác định bên gọi và các nhóm khả dụng |
| Model ID | Bảng điều khiển → Chợ mô hình | Chỉ định mô hình cần gọi |

<Warning>
Không để lộ API Key trong hội thoại, ảnh chụp màn hình, kho mã frontend hoặc cấu hình công khai. Nếu nghi ngờ bị lộ, hãy xóa hoặc đặt lại Key ngay trong bảng điều khiển.
</Warning>

## Khi cần hỗ trợ, hãy gửi kèm

- Thời điểm xảy ra lỗi và múi giờ
- Model ID, endpoint và có sử dụng streaming hay không
- Toàn bộ thông báo lỗi và Request ID
- Bước tái hiện tối thiểu đã thử

Các thông tin này giúp tránh trao đổi qua lại và tìm nguyên nhân nhanh hơn.
