## 1. Chọn phần mềm

Đã cài phần mềm thì mở đúng hướng dẫn; chưa cài thì làm phần cài đặt trước. CC Switch giúp quản lý cấu hình thay vì sửa tệp, nhưng không thay thế Claude Code hoặc Codex CLI.

| Bạn dùng | Hướng dẫn |
| --- | --- |
| Claude Code | [Cấu hình](/vi/tools/claude-code) |
| Codex CLI | [Cấu hình](/vi/tools/codex-cli) |
| CC Switch | [Cấu hình](/vi/tools/cc-switch) |
| VS Code / Cursor | [Cấu hình](/vi/tools/cursor-vscode) |
| Chương trình tự viết | [Cấu hình](/vi/developer/code-examples) |

## 2. Trước khi bắt đầu

1. Chuẩn bị [khóa API](/vi/guide/api-key) của bạn.
2. Sao chép địa chỉ và mô hình từ đúng hướng dẫn. Không trộn cấu hình của các phần mềm.
3. Sao lưu cấu hình cũ trước. Không xóa cả thư mục cấu hình.

Không thấy phần mềm bạn đang dùng trong danh sách? Gửi tên và ảnh cài đặt cho hỗ trợ, nhớ che khóa.

## 3. Chọn mô hình tương thích

| Cách dùng | Chọn gì |
| --- | --- |
| Claude Code hoặc tiện ích của nó | Với bộ hướng dẫn này, chọn mô hình Claude trong nhóm có hỗ trợ Claude Code |
| Codex CLI | Mô hình GPT và nhóm đã xác nhận hỗ trợ Codex; không phải mọi nhóm GPT đều phù hợp |
| CC Switch | Chọn theo ứng dụng Claude Code hoặc Codex bên trong, không theo tên CC Switch |
| Chương trình tự viết | Chọn giao diện theo [giao thức mô hình](/vi/developer/model-protocols) |

Tên chính xác xem ở [giao thức đề xuất](/vi/developer/model-protocols). Thấy mô hình trên trang không có nghĩa khóa dùng được nó trong mọi phần mềm. Chưa rõ thì gửi phần mềm, mô hình và nhóm cho hỗ trợ, không gửi khóa đầy đủ.
