Extension Claude Code chính thức có chat, xem trước diff, tham chiếu tệp và lời nhắc quyền. VS Code và Cursor dùng chung cấu hình cấp người dùng của Claude Code.

## 1. Cài extension chính thức

Hoàn thành [thiết lập Claude Code](/vi/tools/claude-code) trước. Trong Extensions, tìm **Claude Code** và xác nhận publisher là **Anthropic**. Có thể xem thêm [hướng dẫn VS Code chính thức](https://code.claude.com/docs/en/vs-code).

<Warning>
Có thể có extension bên thứ ba giống tên. Chỉ dùng extension do Anthropic phát hành và không dán key vào bảng cài đặt của bên thứ ba.
</Warning>

## 2. Dùng chung cấu hình NexusAPI

Extension đọc cùng `~/.claude/settings.json` như CLI (hoặc đường dẫn tương ứng trong hồ sơ Windows). Không lưu lặp key trong cài đặt workspace của VS Code hay Cursor.

Nếu editor vẫn yêu cầu đăng nhập: mở Settings, tìm `Claude Code login`, bật **Disable Login Prompt** nếu có, rồi khởi động lại hoàn toàn editor. Nếu editor mở từ desktop không nhận môi trường, chạy `code .` từ terminal đã cấu hình.

## 3. Kiểm tra an toàn

Mở Claude Code từ sidebar hoặc Command Palette và yêu cầu: “Giải thích tệp hiện tại làm gì, không sửa tệp.” Sau khi thành công, kiểm tra bản ghi tương ứng trong nhật ký NexusAPI.

Khi có lỗi, cập nhật editor, extension và Claude Code, khởi động lại hoàn toàn, lưu lỗi và Request ID rồi làm [tự kiểm tra](/vi/faq/self-check). Không gửi key đầy đủ, secret của workspace hoặc mã nguồn riêng tư.
