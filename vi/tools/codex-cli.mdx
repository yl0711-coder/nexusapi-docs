Dùng khóa NexusAPI, không dùng mật khẩu ChatGPT.

## 1. Cài Codex

Windows mở PowerShell, Mac mở Terminal. Chỉ dùng lệnh đúng hệ điều hành. Đã cài thì bỏ qua.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```
</Tab>
</Tabs>

Mở lại terminal và xem phiên bản. Không tìm thấy lệnh thì xử lý cài đặt trước.

```bash
codex --version
```

## 2. Lưu địa chỉ và mô hình

[Tạo khóa](/vi/guide/api-key), chọn cùng nhóm trong [Quảng trường mô hình](https://nexusapi.link/pricing), sao chép tên dùng cho Codex / Responses. Mở cấu hình người dùng:

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.codex" | Out-Null
notepad "$env:USERPROFILE\.codex\config.toml"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.codex
nano ~/.codex/config.toml
```
</Tab>
</Tabs>

Nano dùng `Ctrl + O`, Enter để lưu, `Ctrl + X` để thoát. Notepad dùng `Ctrl + S`. Tên phải là `config.toml`, không thêm `.txt`.

Dán vào file trống, chỉ thay `YOUR_MODEL_ID`:

```toml
model_provider = "nexusapi"
model = "YOUR_MODEL_ID"

[model_providers.nexusapi]
name = "NexusAPI"
base_url = "https://nexusapi.link/v1"
env_key = "NEXUSAPI_API_KEY"
wire_api = "responses"
```

Sao lưu cấu hình cũ. Đặt `model`, `model_provider` ở đầu file, thêm hoặc sửa một phần `[model_providers.nexusapi]`, không trùng phần. Có thể dùng [CC Switch](/vi/tools/cc-switch). Không điền khóa vào file này.

## 3. Đặt và lưu khóa API

Chỉ thay `YOUR_API_KEY`. Lệnh Windows đặt cả terminal hiện tại lẫn biến người dùng lâu dài.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
$env:NEXUSAPI_API_KEY = "YOUR_API_KEY"
[Environment]::SetEnvironmentVariable("NEXUSAPI_API_KEY", $env:NEXUSAPI_API_KEY, "User")
```
</Tab>
<Tab title="macOS (Zsh)">
```bash
touch ~/.zshrc
nano ~/.zshrc
```

Thêm dòng sau ở cuối file; đã có biến cùng tên thì thay giá trị cũ, không thêm trùng. Lưu rồi mở lại terminal.

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
<Tab title="Linux / WSL (Bash)">
```bash
nano ~/.bashrc
```

Thêm dòng sau ở cuối file; đã có biến cùng tên thì thay giá trị cũ, không thêm trùng. Lưu rồi mở lại terminal.

```bash
export NEXUSAPI_API_KEY='YOUR_API_KEY'
```
</Tab>
</Tabs>

Ví dụ dùng Zsh mặc định trên Mac và Bash trên Linux. Shell khác dùng file khởi động tương ứng; chưa rõ thì hỏi hỗ trợ. Không đưa khóa vào dự án hay ảnh.

## 4. Khởi động kiểm tra

Mở terminal trong dự án của bạn và chạy:

```bash
codex
```

Dùng `/status` xem đúng mô hình và nhà cung cấp NexusAPI. Gửi “Chỉ trả lời: kết nối thành công. Không sửa file.” Nhận đủ câu trả lời và có [nhật ký](https://nexusapi.link/usage-logs/common) là được. Lượt thử này tiêu thụ một lượng nhỏ số dư.

## 5. Lỗi hay gặp

`Missing environment variable`: làm lại bước 3. Mô hình không dùng được: sao chép lại tên hỗ trợ Codex trong nhóm. Lỗi khác xem [tự kiểm tra](/vi/faq/self-check).

Trên Mac, mở trình soạn thảo từ Dock có thể không nhận biến terminal. Thử CLI trước; dùng tiện ích Codex thì mở từ terminal đã cấu hình bằng `code .` hoặc `cursor .`. Không đưa khóa vào cài đặt dự án.

Cài đặt và cấu hình chính thức: [Codex CLI](https://learn.chatgpt.com/docs/cli) · [Custom providers](https://learn.chatgpt.com/docs/config-file/config-advanced#custom-model-providers).
