Dùng khóa NexusAPI cho các lượt gọi này, không cần đăng nhập tài khoản Claude chính thức.

## 1. Chuẩn bị và cài đặt

[Tạo khóa](/vi/guide/api-key), chọn cùng nhóm trong [Quảng trường mô hình](https://nexusapi.link/pricing), sao chép mô hình dùng cho Claude Code / Messages. Windows tìm `PowerShell` ở Start; Mac dùng `Command + Space`, tìm Terminal.

Chỉ chạy lệnh đúng hệ điều hành. Đã cài Claude Code thì bỏ qua phần cài.

<Tabs>
<Tab title="Windows PowerShell">
```powershell
irm https://claude.ai/install.ps1 | iex
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
</Tab>
</Tabs>

Mở lại terminal và kiểm tra phiên bản. Nếu không tìm thấy lệnh, mở lại lần nữa; vẫn lỗi thì gửi lỗi cài đặt cho hỗ trợ.

```bash
claude --version
```

## 2. Mở file cấu hình

Dùng lệnh đúng hệ điều hành để mở cấu hình người dùng:

<Tabs>
<Tab title="Windows PowerShell">
```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude" | Out-Null
notepad "$env:USERPROFILE\.claude\settings.json"
```
</Tab>
<Tab title="macOS / Linux / WSL">
```bash
mkdir -p ~/.claude
nano ~/.claude/settings.json
```
</Tab>
</Tabs>

Trong nano: `Ctrl + O`, Enter để lưu, rồi `Ctrl + X` để thoát. Notepad Windows dùng `Ctrl + S`. Tên file phải là `settings.json`, không thành `.json.txt`.

## 3. Điền khóa và mô hình

Nếu file trống, dán toàn bộ bên dưới. Thay `YOUR_API_KEY` bằng khóa đầy đủ và `YOUR_MODEL_ID` bằng mô hình đã sao chép. Giữ dấu ngoặc kép và dấu phẩy.

```json
{
  "model": "YOUR_MODEL_ID",
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "YOUR_API_KEY",
    "ANTHROPIC_BASE_URL": "https://nexusapi.link"
  }
}
```

File đã có nội dung thì sao lưu rồi chỉ gộp `model` và `env`, không xóa nội dung khác. Có thể dùng [CC Switch](/vi/tools/cc-switch) để quản lý. Không đưa khóa vào dự án hay ảnh.

## 4. Khởi động và kiểm tra

Lưu rồi mở lại terminal trong thư mục dự án và chạy:

```bash
claude
```

Nhập `/status`, kiểm tra `Anthropic base URL` là `https://nexusapi.link`, nguồn khóa là `ANTHROPIC_AUTH_TOKEN`, mô hình đúng tên vừa điền.

Gửi “Chỉ trả lời: kết nối thành công. Không sửa file.” Có đủ câu trả lời và bản ghi trong [nhật ký](https://nexusapi.link/usage-logs/common) là xong. Lượt thử này tiêu thụ một lượng nhỏ số dư.

Thấy `/login` hoặc lỗi khóa thì kiểm tra file người dùng, các giá trị đã thay và mở lại. Xem [tự kiểm tra lỗi](/vi/faq/self-check). Không xóa cả thư mục `.claude`.

Dự án chính thức: [Claude Code](https://github.com/anthropics/claude-code).
