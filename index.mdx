## 遇到问题

把下面这些发给客服：

- 用的什么软件。
- 发生时间、模型和分组。
- 报错原文或截图；有请求编号时一起提供。

**截图请遮盖完整 API Key，不要发送密码或验证码。** 拿不准的信息不用猜，先把看到的报错发过来。
