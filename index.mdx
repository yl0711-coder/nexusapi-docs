## 接入时需要的三项信息

| 信息 | 从哪里获得 | 作用 |
| --- | --- | --- |
| Base URL | 本文档 | 指定请求发送到 NexusAPI 的地址 |
| API Key | 控制台 → 令牌管理 | 识别调用身份与可用分组 |
| 模型 ID | 控制台 → 模型广场 | 指定要调用的模型 |

<Warning>
请勿在聊天记录、截图、前端代码仓库或公开配置中泄露 API Key。怀疑泄露时，请立即在控制台删除或重置该 Key。
</Warning>

## 需要支持时，请一并提供

- 发生时间和时区
- 模型 ID、请求接口和是否使用流式响应
- 完整错误原文与 Request ID
- 已完成的最小复现步骤

这些信息足以避免反复追问，也能更快定位问题。
