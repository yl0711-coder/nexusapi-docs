## 遇到问题

已有服务群，请回原服务群反馈；没有服务群，请联系为你开通账号的对接人。还没开始配置，可先发软件名称和想用的模型，确认分组后再操作。

把下面这些发给客服：

- 用的什么软件。
- 发生时间、模型和分组。
- 报错原文或截图；有请求编号时一起提供。

**截图请遮盖完整 API Key，不要发送密码或验证码。** 拿不准的信息不用猜，先把看到的报错发过来。
